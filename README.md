# Python и нейросети для детей — EdisonGames

Учебный сайт курса для школьников 8–14 лет. Открывается как обычный HTML — точка входа [`index.html`](index.html).

В этой публикации — **первые 25 уроков, кроме урока 12** (24 урока, модули 1–8). Каждый урок состоит из презентации и методички.

## Структура

- `index.html` — главная страница со списком уроков и поиском
- `presentations/урок_NN.html` — презентации уроков
- `metodichki/урок_NN.html` — методички уроков

## Локальный просмотр

Просто откройте `index.html` в браузере, либо поднимите статический сервер:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)`.
Файл `.nojekyll` отключает обработку Jekyll, чтобы файлы с кириллическими именами отдавались как есть.
