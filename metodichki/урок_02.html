Урок 2

Что такое переменные и как с ними работать

Отдел: Математических основ

Неделя: 2

Возраст: 8–14 лет

Формат: Презентация + урок (60 мин)

🎯 Цель занятия

Ребёнок умеет создавать, переопределять переменные и выполнять с ними арифметические операции, узнавая тип данных через type().

📚 Образовательные результаты

  • Ученик понимает: как определить переменную; как переопределять переменные; как использовать операторы присваивания; как разделять разряды с помощью нижнего подчёркивания; как узнать тип данных с помощью type(); как производить арифметические операции — умножение, деление, целочисленное деление, вычитание, возведение в степень.
  • Ученик умеет / может: производить арифметические операции с переменными.

🛠️ Материалы и инструменты

  • ПО: GigaIDE Desktop / Google Colab
  • ИИ-помощники: GigaChat (для демо, не для решения)
  • Файлы-заготовки: variables.py

⚙️ Технические требования

  • Python 3.11+, проверенная установка с урока 1.

🕐 Поминутный план (60 мин)

0–5 мин. Разбор ДЗ и приветствие

  • Что говорит преподаватель: «Покажи свою "Визитку". Так, классно — ты добавил 3 строки! А теперь представь: визитку надо менять каждый раз, когда тебе исполняется день рождения. Делать 100 файлов? Нет. Сегодня — про переменные».

5–15 мин. Теория-демо

  • Метафора: переменная — это коробка с наклейкой. Наклейка — имя переменной, внутри — значение.
  • Словарь:

- Переменная — именованная ячейка памяти.

- Присваивание — знак =, кладёт значение в коробку.

- Тип данных — что внутри: число (int, float), текст (str).

- type() — функция, которая «вскрывает коробку» и говорит, что там.

- Арифметика: + - / // % *.

- Разделитель разрядов _: 1_000_000 — читаемее, чем 1000000.

  • Живой код:
  age = 10
  name = "Миша"
  print(type(age), type(name))
  age = age + 1  # переопределение
  print(age ** 2, 10 // 3, 10 % 3)

15–45 мин. Практика под руководством

  • Задание 1 (7 мин): создать 4 переменные — имя, возраст, рост в см, рост в метрах. Вывести каждую.

- Что говорит преподаватель: «Имя — в кавычках, это строка. Возраст — без кавычек, это число. Не путай».

  • Задание 2 (12 мин): калькулятор дня рождения. Переменная year_now = 2026, year_born = 2016. Посчитать возраст, возраст через 10 лет, сколько дней прожито (age * 365). Использовать _: days_in_year = 365.
  • Задание 3 (10 мин): мини-физика. distance = 100, time = 20, speed = distance / time. Вывести со словами через print и запятую.

45–55 мин. Мини-проект урока — «Паспорт персонажа»

  • Ребёнок придумывает персонажа из любимой игры: имя, уровень, здоровье, атака, стоимость в золоте (1_000_000). Через переменные считает «урон в секунду» и «сколько монет стоит 5 таких».

55–60 мин. Демо и рефлексия

  • Ученик показывает «Паспорт персонажа».
  • Вопросы: «Что такое переменная простыми словами? Зачем нам type()?»
  • Похвала: «Бейдж "Мастер переменных" — твой!»

💬 Ключевые фразы преподавателя

  1. «Переменная — это коробка с наклейкой. Имя — снаружи, значение — внутри».
  2. «Знак равно — не "равно", а "положи в коробку"».
  3. «Тип данных Python определяет сам, но ты можешь спросить через type()».
  4. «1_000_000 — подчёркивания для нас, для Python это просто миллион».
  5. «Если красным — читаем ошибку вслух. Там обычно написано, что случилось».
  6. «Попробуй сам 5 минут — получится, не получится, я помогу».
  7. «Отлично, ты уже умеешь считать программой, как калькулятор!»
  8. «В программировании имена переменных пишем английскими буквами и без пробелов: my_age, не мой возраст».
  9. «Переопределить переменную — это заменить то, что в коробке. Старое забывается».
  10. «Молодец! Вижу, как ты начинаешь думать как программист».

🎨 Мини-проект урока

  • Название: «Паспорт персонажа»
  • Что получится: программа с 5–6 переменными и 2–3 вычислениями про любимого персонажа игры.
  • Где показать: скрин в чат, можно с описанием героя.

🏠 Домашнее задание (≤ 20 минут)

Создай 3 переменные: любимое число, твой возраст, твой рост в см. Выведи их произведение, сумму и возведение в квадрат своего возраста. Пришли скриншот.

✅ Критерии успешного занятия

  • Ученик создаёт минимум 4 переменные с разными типами.
  • Ученик использует минимум 3 арифметических оператора.
  • Ученик знает, что такое type() и показывает его в работе.
  • Ученик переопределяет переменную и объясняет, что при этом происходит.

⚠️ Типичные сложности и решения

  1. Путает = и == → объясняем: = — положить, == — сравнить (встретим позже).
  2. Имена переменных кириллицей → да, так можно, но в профи-коде — нет. Договариваемся на английский.
  3. Забывает кавычки у строк → ошибка NameError: ... is not defined. Читаем вместе.
  4. Путает / и // → / — всегда с запятой, // — целая часть, % — остаток. Разбираем на конфетах: 10 конфет разделить на 3 — по 3 каждому (//), 1 лишняя (%).
  5. Минусует неправильно: a - = 5 → пробелы между - и = ломают оператор.

🎁 Бонус для опережающих

Напиши программу, которая считает площадь и периметр 3 разных прямоугольников. Используй переменные для сторон и выведи всё красиво в столбик.
