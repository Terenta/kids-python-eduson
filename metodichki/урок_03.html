Урок 3

Как добавить в код ввод и вывод

Отдел: Математических основ

Неделя: 3

Возраст: 8–14 лет

Формат: Презентация + урок (60 мин)

🎯 Цель занятия

Ребёнок умеет запрашивать данные у пользователя через input(), красиво выводить их через print() и f-строки, комментирует свой код.

📚 Образовательные результаты

  • Ученик понимает: как выводить текст с помощью print(); как добавлять пользовательский ввод с помощью input(); как выводить текст и результаты арифметических операций; как комментировать код; как переносить строки; как использовать f-строки.
  • Ученик умеет / может: использовать print() и input(), чтобы производить арифметические операции с переменными.

🛠️ Материалы и инструменты

  • ПО: GigaIDE / Colab
  • ИИ-помощники: GigaChat (для демо)
  • Файлы-заготовки: io_demo.py

⚙️ Технические требования

  • Python 3.11+, работающая IDE.

🕐 Поминутный план (60 мин)

0–5 мин. Разбор ДЗ

  • Что говорит преподаватель: «Покажи произведение любимого числа на рост. Ух ты, круто. А теперь — твоя программа будет разговаривать с пользователем. Реально».

5–15 мин. Теория-демо

  • Ключевая идея: программа становится живой, когда спрашивает и отвечает.
  • Словарь:

- input() — вопрос пользователю; всегда возвращает строку.

- int(), float() — превращают строку в число.

- f-строка — f"Привет, {name}!" — подставляет значение переменной.

- Комментарий — # это не код, это для человека.

- \n — перевод строки внутри print.

- sep, end — параметры print.

  • Живой код:
  name = input("Как тебя зовут? ")
  age = int(input("Сколько тебе лет? "))
  print(f"Привет, {name}! Через 10 лет тебе будет {age + 10}.")

15–45 мин. Практика под руководством

  • Задание 1 (8 мин): «Диалог»: программа спрашивает имя и любимый цвет, отвечает комплиментом. Добавить комментарии к каждой строке.
  • Задание 2 (12 мин): «Калькулятор»: спрашивает 2 числа, выводит сумму, разность, произведение, частное через f-строки. Ошибка: не забыть обернуть input в int().

- Что говорит преподаватель: «Запомни: input всегда возвращает строку. Чтобы сложить — переведи в число через int()».

  • Задание 3 (8 мин): «Конвертер температуры»: запрос градусов Цельсия, вывод в Фаренгейтах (C * 9/5 + 32).

45–55 мин. Мини-проект урока — «Анкета нового ученика»

  • Программа спрашивает: имя, возраст, город, любимый предмет, мечта. Выводит красивую карточку через f-строки с \n.

55–60 мин. Демо и рефлексия

  • Ученик показывает «Анкету» на себе и на маме.
  • Вопросы: «Почему input всегда возвращает строку? Что делают f-строки?»
  • Похвала: «Следующий урок — большой проект. Ты готов!»

💬 Ключевые фразы преподавателя

  1. «Программа сама спрашивает и отвечает — это называется интерактивность».
  2. «input() всегда возвращает СТРОКУ, даже если ты ввёл число. Запомни навсегда».
  3. «f-строки — это магия подстановки. f"{name}" — и переменная внутри текста».
  4. «Комментарии — это записки самому себе через полгода».
  5. «Не торопись с кодом — сначала продумай, что спрашиваешь».
  6. «Попробуй сам 5 минут — не получилось, посмотри на ошибку, прочитай вслух».
  7. «Красный текст снизу — не злой. Он говорит, на какой строке проблема».
  8. «Ты сделал программу, которая общается с человеком. Это уже приложение».
  9. «Запомни: красивый вывод — половина успеха программы».
  10. «Через один урок — твой первый большой проект. Готовимся».

🎨 Мини-проект урока

  • Название: «Анкета нового ученика»
  • Что получится: интерактивная программа из 5–6 вопросов, выводящая красивую карточку.
  • Где показать: запусти маме/папе — пусть заполнят свою анкету.

🏠 Домашнее задание (≤ 20 минут)

Доделай калькулятор: спроси 2 числа и операцию словом (пока что только покажи 4 результата — +, –, *, /). Пришли скриншот работы.

✅ Критерии успешного занятия

  • Ученик использует минимум 3 input() в одной программе.
  • Ученик корректно преобразует строку в число (int, float).
  • Ученик применяет f-строки минимум 2 раза.
  • Ученик пишет минимум 3 смысловых комментария.

⚠️ Типичные сложности и решения

  1. TypeError: can only concatenate str and int → забыл обернуть в int(). Разбираем, что input — всегда строка.
  2. f-строка без f → "{name}" не работает, нужно f"{name}". Проверяем первую букву.
  3. Ученик вводит буквы вместо цифр → ошибка ValueError. Говорим: на следующем модуле научимся это ловить через условия.
  4. Забывает закрыть кавычку в prompt input → читаем traceback вместе.
  5. Не понимает, куда девается введённое значение → рисуем: «твой ввод идёт в коробку name».

🎁 Бонус для опережающих

Сделай программу, которая спрашивает имя и год рождения, а потом выводит год, в котором ученику исполнится 100 лет.

🤖 Где подключаем ИИ

На этом уроке ИИ помогает придумать красивый текст для «Анкеты». Преподаватель показывает: «Смотри, спросим GigaChat: "Придумай 5 интересных вопросов для анкеты школьника"». Пример промпта: «Придумай 5 нестандартных вопросов для анкеты школьника 10 лет, чтобы узнать про его мечты и хобби».
