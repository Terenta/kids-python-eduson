Урок 5

Как работать со строками

Отдел: Системных данных

Неделя: 5

Возраст: 8–14 лет

Формат: Презентация + урок (60 мин)

🎯 Цель занятия

Ребёнок умеет создавать строки разными способами, узнавать их длину, получать символы по индексу, объединять и повторять строки.

📚 Образовательные результаты

  • Ученик понимает: что такое строка и для чего она используется; как создавать строки с одинарными и двойными кавычками; что такое длина строки и как узнать её через len(); что такое индексация и с какого числа она начинается; как объединять строки через +; как повторять строки через *; что строки — неизменяемый тип данных.
  • Ученик умеет / может: создавать строки; выводить их через print(); определять длину через len(); получать символы по индексу; объяснять, почему нумерация с нуля; объединять строки через +; повторять через *; сохранять в переменные; использовать в input/print.

  • ИИ-помощники: GigaChat (для генерации смешных строк)

⚙️ Технические требования

Python 3.11+, IDE.

🕐 Поминутный план (60 мин)

0–5 мин. Разбор ДЗ

  • «Покажи Электронного помощника. Чётко! Сегодня мы дадим твоим текстам суперсилы».

5–15 мин. Теория-демо

  • Словарь:

- Строка (str) — текст в кавычках. Может быть пустой "", длинной, с пробелами, с эмодзи.

- len() — длина строки в символах.

- Индекс — порядковый номер символа. В Python — с 0.

- Конкатенация + — склейка строк.

- Повторение * — умножаем строку на число.

- Неизменяемость — строку нельзя менять на месте, только создать новую.

  • Живой код:
  s = "Привет"
  print(len(s))         # 6
  print(s[0], s[-1])    # 'П' 'т'
  print(s + ", мир!")   # конкатенация
  print("Ха" * 5)       # ХаХаХаХаХа

15–45 мин. Практика под руководством

  • Задание 1 (7 мин): создать 5 строк (любимая книга, город, мама, питомец, мечта). Вывести длину каждой через len().
  • Задание 2 (12 мин): «Первая и последняя буква»: программа спрашивает слово, выводит первую, последнюю и длину.
  • Задание 3 (10 мин): «Эхо»: спрашивает фразу, число повторов, выводит фраза число. Добавить пробел между: (phrase + " ") n.

45–55 мин. Мини-проект урока — «Анализатор имени»

  • Программа спрашивает имя и фамилию, выводит:

- полное имя = name + " " + surname

- инициалы: name[0] + ". " + surname[0] + "."

- длина полного имени без пробела.

55–60 мин. Демо и рефлексия

  • Показ Анализатора.
  • Вопросы: «Почему нумерация с 0? Что значит "строки неизменяемы"?»
  • Похвала: «Скоро ты сделаешь настоящий дневник».

💬 Ключевые фразы преподавателя

  1. «Строка — это цепочка символов, как бусы. Каждая бусина на своём месте».
  2. «Индексация с нуля — потому что 0 — это тоже число, и так удобнее для компьютера».
  3. «Отрицательный индекс — это "с конца". -1 — последняя буква».
  4. «len() — как линейка для текста».
  5. «Строки нельзя менять "на месте". Это как печать на бумаге — только переписать заново».
  6. «"а" * 10 — это не умножение математическое, это повторение».
  7. «Будь внимателен: "2" + "3" = "23", а не 5! Это строки».
  8. «Чем длиннее строка, тем медленнее *. Пока это не важно, но запомни».
  9. «Попробуй сам: 5 минут без подсказок».
  10. «Бейдж "Строковед" ждёт после следующих уроков».

🎨 Мини-проект урока

  • Название: «Анализатор имени»
  • Что получится: программа печатает полное имя, инициалы, длину.
  • Где показать: скрин в чат курса.

🏠 Домашнее задание (≤ 20 минут)

Напиши программу, которая спрашивает 3 любимых слова, выводит каждое в обратном порядке (слово[::-1] — дадим бонус-намёк), считает общую длину трёх слов.

✅ Критерии успешного занятия

  • Ученик создаёт строки с "" и '' и объясняет, когда какие удобнее.
  • Ученик использует len() и индексацию по положительным и отрицательным индексам.
  • Ученик применяет + и * корректно.
  • Ученик объясняет «неизменяемость» строк на примере.

⚠️ Типичные сложности и решения

  1. IndexError при обращении к s[100] → читаем ошибку: «индекс вне диапазона». Проверяем len.
  2. Путает "5" + 3 → TypeError. Обсуждаем: нужно int("5") + 3 или "5" + str(3).
  3. Двойные кавычки внутри двойных → показываем, как экранировать \" или чередовать '..."..."..'.
  4. Не понимает s[-1] → рисуем на доске: слева 0, 1, 2, справа −3, −2, −1.
  5. s[0] = "А" — ошибка → учебный момент неизменяемости.

🎁 Бонус для опережающих

Познакомься с срезами: s[0:3] — первые 3 буквы, s[::-1] — строка задом наперёд. Напиши программу, которая превращает слово в палиндром: s + s[::-1].
