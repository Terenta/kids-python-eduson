Урок 6

Как работать со списками

Отдел: Системных данных

Неделя: 6

Возраст: 8–14 лет

Формат: Презентация + урок (60 мин)

🎯 Цель занятия

Ребёнок умеет создавать списки, получать и изменять элементы по индексу, хранить в списке данные разных типов.

📚 Образовательные результаты

  • Ученик понимает: что такое список и зачем он нужен; разницу между одной переменной и списком значений; как создавать списки; что элементы списка имеют порядок; что такое индекс элемента списка; что индексация списка начинается с 0; что список может хранить элементы разных типов; что списки — изменяемый тип данных.
  • Ученик умеет / может: создавать списки; выводить список целиком; получать элементы списка по индексу; изменять элементы списка; сохранять данные пользователя в список; использовать список для хранения нескольких значений.

🛠️ Материалы и инструменты

  • ПО: GigaIDE / Colab
  • ИИ: GigaChat (для генерации тестовых списков)
  • Файлы-заготовки: lists_demo.py

⚙️ Технические требования

Python 3.11+.

🕐 Поминутный план (60 мин)

0–5 мин. Разбор ДЗ

  • «Покажи обратные слова. Сегодня — новая структура: список. Это когда много значений в одной коробке».

5–15 мин. Теория-демо

  • Метафора: список — как контейнер с пронумерованными ячейками. Можно добавить, достать, поменять ячейку.
  • Словарь:

- Список (list) — упорядоченная коллекция элементов.

- Индекс — позиция, с 0.

- Изменяемость — список можно менять по месту (в отличие от строки).

- Разнотипность — внутри списка могут быть и числа, и строки, и даже другие списки.

  • Живой код:
  fruits = ["яблоко", "банан", "груша"]
  print(fruits[0])    # яблоко
  fruits[1] = "вишня" # замена
  mixed = [10, "Вася", 3.14, True]

15–45 мин. Практика под руководством

  • Задание 1 (7 мин): 3 списка — любимые фильмы, оценки за неделю, покупки. Выведи каждый.
  • Задание 2 (12 мин): «Топ-5 песен»: создать список из 5 песен, вывести 1-ю и последнюю, заменить 3-ю.
  • Задание 3 (10 мин): «Ответы на анкету»: спросить имя, город, возраст и записать в список. Вывести через f-строку с индексами.

45–55 мин. Мини-проект урока — «Дневник оценок»

  • Программа спрашивает 5 оценок через input, кладёт в список, выводит каждую по индексу и «Средний балл пока считать не умеем — научимся через 2 урока».

55–60 мин. Демо и рефлексия

  • Показ дневника.
  • Вопросы: «Чем список отличается от 5 переменных? Можно ли в списке держать разные типы?»

💬 Ключевые фразы преподавателя

  1. «Список — это упорядоченный контейнер. 5 значений в одной переменной».
  2. «Индекс — как номер квартиры. list[0] — первая квартира».
  3. «Список можно менять. Строку — нельзя. Запомни».
  4. «В списке могут быть разные типы. Это гибкость Python».
  5. «list[5] при длине 3 — IndexError. Проверяй len».
  6. «Списки — это главная коллекция Python. С ней будешь работать всегда».
  7. «Попробуй сам, потом покажу лайфхак».
  8. «Отлично, теперь ты можешь хранить много данных компактно!»
  9. «Следующий урок — методы. Это встроенные суперсилы списков и строк».
  10. «Список + input + цикл — и ты пишешь приложения. Но циклы — впереди».

  • Название: «Дневник оценок»
  • Что получится: программа хранит 5 оценок и выводит их по индексам.
  • Где показать: скрин в чат.

🏠 Домашнее задание (≤ 20 минут)

Сделай список из 7 дней недели. Выведи через [0] понедельник, через [-1] — воскресенье, замени один день на «выходной».

✅ Критерии успешного занятия

  • Ученик создаёт минимум 3 списка с разным содержимым.
  • Ученик читает и изменяет элементы по индексу.
  • Ученик объясняет разницу между списком и переменной.
  • Ученик показывает список смешанных типов.

⚠️ Типичные сложности и решения

  1. IndexError → обсуждаем: индексы от 0 до len(x)-1.
  2. Путает () и [] → списки строго []. Кортежи (круглые) будут позже.
  3. Забывает запятые внутри списка → SyntaxError. Читаем.
  4. Ввод пользователя в список: lst = input() → объясняем, что получится строка, а не список. Пока что добавляем через lst.append(...) или lst = [input(), input()...].
  5. Путает изменение и переопределение → lst[0] = "x" — меняем элемент, lst = [1,2,3] — новый список.

🎁 Бонус для опережающих

Вложенный список: board = [["X","O","X"], ["O","X","O"], ["X","O","X"]]. Попробуй вывести элементы по-умному — board[1][1].
