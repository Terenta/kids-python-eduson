Урок 7

Как использовать методы для работы со списками и строками

Отдел: Системных данных

Неделя: 7

Возраст: 8–14 лет

Формат: Презентация + урок (60 мин)

🎯 Цель занятия

Ребёнок умеет применять основные методы строк (upper, lower, strip, replace) и списков (append, remove, pop, sort).

📚 Образовательные результаты

  • Ученик понимает: зачем нужны методы для строк и списков; назначение основных методов строк — upper(), lower(), strip(), replace(); назначение основных методов списков — append(), remove(), pop(), sort().
  • Ученик умеет / может: применять методы строк для изменения текста; очищать и изменять введённый пользователем текст; добавлять элементы в список; удалять элементы из списка; сортировать список.

  • ИИ: GigaChat (для тестовых данных)
  • Файлы-заготовки: methods_demo.py

⚙️ Технические требования

Python 3.11+.

🕐 Поминутный план (60 мин)

0–5 мин. Разбор ДЗ

  • «Покажи дни недели. Сегодня — методы. Это когда у строки и списка есть "встроенные кнопки"».

5–15 мин. Теория-демо

  • Метафора: метод — это кнопка на самом объекте. list.append(x) — нажал кнопку «добавить».
  • Словарь:

- Метод — функция, вызываемая через точку на объекте.

- upper() — ВЕРХНИЙ регистр.

- lower() — нижний регистр.

- strip() — обрезает пробелы по краям.

- replace(a, b) — заменить a на b.

- append(x) — добавить в конец списка.

- remove(x) — удалить первое вхождение x.

- pop() — вытащить последний элемент (и вернуть).

- sort() — отсортировать на месте.

  • Живой код:
  s = "  Привет, Мир!  "
  print(s.strip().upper().replace("МИР", "Python"))
  lst = [3, 1, 2]
  lst.append(10)
  lst.sort()
  lst.pop()
  lst.remove(2)
  print(lst)

15–45 мин. Практика под руководством

  • Задание 1 (10 мин): «Очиститель ввода»: спросить фразу, вывести её strip().lower().
  • Задание 2 (12 мин): «Цензор»: спросить предложение, заменить 2 слова на «[скрыто]». Подсказка: .replace().
  • Задание 3 (10 мин): «Список покупок»: пустой список, 5 раз input → append, в конце sort(), вывести, pop() последний, вывести снова.

45–55 мин. Мини-проект урока — «Редактор заметок»

  • Программа спрашивает заметку, очищает пробелы, делает ВСЕ БУКВЫ ПРОПИСНЫМИ первое слово (через срез и .upper()), заменяет «плохо» на «отлично». Добавляет в список notes. Выводит сортированный список.

55–60 мин. Демо и рефлексия

  • Показ редактора.
  • Вопросы: «Метод меняет объект сам или возвращает новый? (у строк — возвращает новый, у списков — меняет)».
  • Бейдж «Строковед» — после защиты.

💬 Ключевые фразы преподавателя

  1. «Метод — это встроенная кнопка объекта. Точка — и название метода».
  2. «Важно: у СТРОК методы ВОЗВРАЩАЮТ новую строку (строки неизменяемы). У списков — МЕНЯЮТ сам список».
  3. «Цепочка методов: s.strip().lower() — сначала обрежь, потом в нижний регистр».
  4. «sort() — ничего не возвращает! print(lst.sort()) выведет None. Сортирует на месте».
  5. «pop() — возвращает то, что удалил. Удобно».
  6. «remove(x) удаляет первое вхождение. Если x нет — ValueError».
  7. «В профи-коде всегда очищают input().strip() — чтобы убрать лишние пробелы».
  8. «Попробуй сам. 5 минут».
  9. «Отлично! Скоро большой проект — дневник».
  10. «Эти методы ты будешь использовать каждый день в разработке».

🏠 Домашнее задание (≤ 20 минут)

Программа: спроси 5 имён, заппенди в список, отсортируй, выведи ПЕРВОЕ заглавными (.upper()) и ПОСЛЕДНЕЕ строчными (.lower()).

✅ Критерии успешного занятия

  • Ученик применяет минимум 3 метода строк и 3 метода списков.
  • Ученик объясняет разницу: метод строки возвращает, метод списка меняет.
  • Ученик использует цепочку методов .strip().lower().
  • Ученик правильно обрабатывает пользовательский ввод через .strip().

⚠️ Типичные сложности и решения

  1. print(lst.sort()) выдаёт None → объясняем: sort ничего не возвращает.
  2. s.upper() не меняет s → нужно s = s.upper().
  3. remove на несуществующем → ValueError. Ловим позже, когда условия.
  4. Путают append и extend → extend (разберём на уроке 8) — добавляет несколько.
  5. Вкладывают метод в метод криво → шаг за шагом: сначала .strip(), потом .lower().
