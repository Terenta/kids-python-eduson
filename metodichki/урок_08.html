Урок 8

Проект «Электронный помощник ч.2: личный дневник» + генерация текста ИИ

Отдел: Системных данных

Неделя: 8

Возраст: 8–14 лет

Формат: Проект (60 мин)

🎯 Цель занятия

Ребёнок пишет программу-дневник с добавлением, сортировкой и форматированным выводом записей, использует ИИ для генерации тестовых записей.

📚 Образовательные результаты

  • Ученик умеет / может: создавать пустой список и добавлять в него элементы; объединять элементы в список с помощью extend(); сортировать список по алфавиту; форматировать и выводить данные в читаемом виде; использовать f-строки для динамического вывода данных; объединять несколько операций над списком (ввод, сортировка, форматирование, вывод) в одну программу; использовать ИИ для генерации текста.

🛠️ Материалы и инструменты

  • ПО: GigaIDE / Colab
  • ИИ: YandexGPT / GigaChat — для генерации тестовых записей дневника
  • Файлы-заготовки: diary_template.py

⚙️ Технические требования

Python 3.11+, открытый YandexGPT.

🕐 Поминутный план (60 мин)

0–5 мин. Разбор ДЗ и анонс проекта

  • «Сегодня — большой проект. Твой личный цифровой дневник. В конце программа будет помнить 5-10 твоих записей и выводить их красиво».

5–15 мин. Разбор ТЗ + демо эталона

  • Показываем работу готового дневника: приветствует, спрашивает 5 записей, сортирует, выводит.
  • Объясняем extend(): «как append, но для нескольких элементов сразу».
  • Демо: как попросить GigaChat сгенерировать 5 записей для теста.

15–45 мин. Самостоятельная разработка

  • Шаг 1 (10 мин): пустой список diary = []. Цикл-заглушка (пока что — 5 копипаст строк с input и .append(), без цикла).
  • Шаг 2 (10 мин): пользователь вводит заголовок записи и текст. Формат: diary.append(f"[{title}] {text}").
  • Шаг 3 (10 мин): после 5 ввода — diary.sort(). Красивый вывод через f-строки и нумерацию (print(f"Запись 1: {diary[0]}") × 5).
  • Шаг 4 (5 мин): extend() — добавить ещё 2 «заготовки», сгенерированные ИИ.

45–55 мин. ИИ-генерация тестовых записей

  • Промпт в YandexGPT: «Сгенерируй 5 коротких записей для дневника школьника 10 лет: что он ел, с кем гулял, что изучал. Формат [заголовок] текст. Каждая запись в отдельной строке».
  • Копируем 2–3 записи, вручную превращаем в Python-список, вставляем через diary.extend([...]).

55–60 мин. Защита проекта

  • Защита по шаблону (5 пунктов).
  • Бейдж «Автор дневника».

💬 Ключевые фразы преподавателя

  1. «Сегодня — второй большой проект. Дневник».
  2. «Правило 5 минут — в силе. Сначала сам».
  3. «append — по одному, extend — списком. Запомни».
  4. «Отсортированный список — это плюс UX. Профи всегда так делают».
  5. «ИИ — не для списывания, а для генерации тестовых данных. Почувствуй разницу».
  6. «Промпт к ИИ — часть задачи. Хороший промпт = хороший результат».
  7. «Копируй результат ИИ не слепо — адаптируй под свой код».
  8. «Защита 5 минут. Готов? Тренировались».
  9. «Вау, твой дневник работает! Второй проект в портфолио».
  10. «Следующий модуль — условия. Программа начнёт принимать решения сама».

🎨 Мини-проект урока

  • Название: «Личный дневник»
  • Что получится: программа принимает 5 записей + 2–3 из ИИ, сортирует, красиво выводит.
  • Где показать: в чат курса с родителями.

🏠 Домашнее задание (≤ 20 минут)

Добавь в дневник ещё одну функцию: перед сортировкой выведи «самый длинный заголовок» через max(diary, key=len) (это бонус-подсказка для опережающих, обычным — просто добавить ещё 2 записи через extend).

✅ Критерии успешного занятия

  • Программа использует append и extend минимум по одному разу.
  • Программа сортирует список и выводит его форматированно через f-строки.
  • Ученик написал минимум 1 промпт в ИИ и использовал результат.
  • Ученик защитил проект по шаблону.

⚠️ Типичные сложности и решения

  1. extend принимает не то → напоминаем: extend() хочет итерируемый объект (список, кортеж), не одну строку.
  2. ИИ генерирует с форматированием markdown → разбираем: как попросить «просто текст без звёздочек».
  3. sort() ломается на смешанных типах → следим, чтобы в списке были только строки.
  4. Копипаст ИИ выдаёт синтаксическую ошибку → читаем traceback, находим кавычку не ту.
  5. Ученик ленится писать сам, копирует всё из ИИ → мягко возвращаем к правилу «5 минут подумай сам».

🎁 Бонус для опережающих

Реализуй команду «покажи запись №N»: ученик вводит число, программа выводит diary[N-1].

🤖 Где подключаем ИИ

На этом уроке ИИ — генератор контента. Промпт: «Ты — школьник 10 лет. Напиши 5 коротких записей для своего личного дневника. Формат каждой: [Заголовок] Текст до 20 слов. Отдельными строками, без markdown и звёздочек». Учитель показывает, как адаптировать полученное под код.
