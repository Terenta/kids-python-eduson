Урок 9

Как работать с условиями с помощью if и else

Отдел: Игровой логики

Неделя: 9

Возраст: 8–14 лет

Формат: Презентация + урок (60 мин)

🎯 Цель занятия

Ребёнок умеет писать программы с ветвлением через if/else, использует операторы сравнения и значения True/False.

📚 Образовательные результаты

  • Ученик понимает: что такое условие и зачем оно нужно; как работает конструкция if; как работает ветка else; что программа выполняет разные действия в зависимости от условия; что такое логическое выражение; что такое значения True и False; назначение операторов сравнения ==, !=, <, >, <=, >=; что код внутри if и else выделяется отступами; что отступы в Python имеют значение.
  • Ученик умеет / может: писать простые условия; использовать конструкцию if/else; проверять ввод пользователя; создавать простые программы с выбором действий (вопрос-ответ, проверка).

  • ИИ: GigaChat (для проверочных сценариев)

⚙️ Технические требования

Python 3.11+.

🕐 Поминутный план (60 мин)

0–5 мин. Разбор ДЗ

  • «Покажи дневник. Сегодня программа научится ДУМАТЬ — принимать решения сама. Модуль "Игровая логика" — твой любимый будет».

5–15 мин. Теория-демо

  • Метафора: if/else — как светофор. Условие True — едем, False — стоим.
  • Словарь:

- Условие — вопрос, на который ответ True или False.

- if — если условие True, выполни блок.

- else — иначе выполни другое.

- True / False — булевы значения (логические).

- Операторы сравнения: == (равно), != (не равно), <, >, <=, >=.

- Отступ (4 пробела) — единственный способ сказать Python «этот блок внутри if».

  • Живой код:
  age = int(input("Возраст: "))
  if age >= 18:
      print("Можно водить машину")
  else:
      print("Ещё рано")

15–45 мин. Практика под руководством

  • Задание 1 (8 мин): «Тёплый или холодный»: спроси температуру, скажи «одевайся теплее» если < 10, иначе «футболка ок».
  • Задание 2 (12 мин): «Угадай число»: в переменной secret = 7. Спроси ввод. Если == — «молодец», иначе — «мимо».
  • Задание 3 (10 мин): «Пароль»: password = "python123". Спроси ввод. Если совпал — «добро пожаловать», иначе «доступ запрещён».

45–55 мин. Мини-проект урока — «Турникет метро»

  • Программа спрашивает возраст. Если <7 — «бесплатно». Если >=7 и <=100 — «пройдите, приложите карту». Если >100 — «вы рекордсмен!».
  • Внимание: пока без elif — через вложенные if, как задание на внимательность к отступам.

55–60 мин. Демо и рефлексия

  • Показ Турникета.
  • Вопросы: «Что выведет 5 == "5"? Зачем ==, а не =?»

💬 Ключевые фразы преподавателя

  1. «Сегодня программа учится думать. Решать сама».
  2. «Условие — это вопрос. Ответ — True или False».
  3. «= — присвоить. == — сравнить. Две большие разницы».
  4. «Отступ в Python — не декорация. Это СИНТАКСИС. 4 пробела».
  5. «Tab или пробелы — не мешай. Держись одного».
  6. «if без else — можно. else без if — нельзя».
  7. «Сравнивать можно числа, строки и много чего. Python умный».
  8. «"5" == 5 — это False. Типы разные».
  9. «Попробуй сам. 5 минут».
  10. «Скоро сделаешь базу данных игры с паролем — настоящую программу».

🎨 Мини-проект урока

  • Название: «Турникет метро»
  • Что получится: программа с 2–3 ветвлениями решает, пропустить или нет.
  • Где показать: скрин в чат.

🏠 Домашнее задание (≤ 20 минут)

Напиши программу «Светофор»: спроси цвет (red/yellow/green), если red — «Стой», если green — «Иди», иначе — «Приготовься». Через вложенные if-else (без elif).

✅ Критерии успешного занятия

  • Ученик пишет минимум 2 разных if/else.
  • Ученик использует минимум 3 оператора сравнения.
  • Отступы корректны (4 пробела, без смешения табов и пробелов).
  • Ученик объясняет, чем = отличается от ==.

⚠️ Типичные сложности и решения

  1. IndentationError → проверяем отступы, все одинаковые (4 пробела).
  2. if age = 10 → синтаксическая ошибка. Напоминаем про ==.
  3. "5" == 5 → False. Обсуждаем типы, учимся переводить через int().
  4. else в неправильном месте → else относится к последнему if. Рисуем дерево.
  5. Забыл двоеточие : после условия → SyntaxError. Разбираем.
