Урок 11

Как работают вложенные и каскадные условия

Отдел: Игровой логики

Неделя: 11

Возраст: 8–14 лет

Формат: Презентация + урок (60 мин)

🎯 Цель занятия

Ребёнок умеет использовать if/elif/else и вложенные условия, понимает разницу и выбирает подходящий вариант под задачу.

📚 Образовательные результаты

  • Ученик понимает: что внутри одного условия if может находиться другой if; разницу между вложенными условиями и каскадными if/elif/else; зачем использовать elif, если условий больше двух; что условия проверяются сверху вниз; что выполняется только первая подошедшая ветка; что порядок условий важен; в каких случаях лучше вложенные, в каких — каскадные; что вложенные условия усложняют код.
  • Ученик умеет / может: писать каскадные условия с if/elif/else; создавать вложенные условия; выбирать подходящий тип; проверять несколько сценариев; читать код с вложенными условиями; находить ошибки в порядке условий; упрощать вложенные if через elif; создавать программы с несколькими вариантами развития событий.

⚙️ Технические требования

Python 3.11+.

🕐 Поминутный план (60 мин)

0–5 мин. Разбор ДЗ

  • «Покажи регистрацию. Сегодня — вложенные и каскадные условия. elif. Это когда вариантов не 2, а 5 или 10».

5–15 мин. Теория-демо

  • Словарь:

- elif — «else if», следующая ветка каскада.

- Каскадное условие — if ... elif ... elif ... else.

- Вложенное условие — if внутри if.

- Порядок ветвей — проверяются сверху вниз, первая True выполняется, остальные пропускаются.

  • Живой код (каскад):
  grade = int(input("Оценка: "))
  if grade == 5:
      print("Отлично")
  elif grade == 4:
      print("Хорошо")
  elif grade == 3:
      print("Удовлетворительно")
  else:
      print("Нужно подтянуть")
  • Живой код (вложенное):
  if logged_in:
      if is_admin:
          print("Админ-панель")
      else:
          print("Обычный пользователь")
  else:
      print("Войдите в систему")

15–45 мин. Практика под руководством

  • Задание 1 (10 мин): «Оценка сочинения» (1–5). Выводит разные фразы для 5, 4, 3, 2, 1 через elif.
  • Задание 2 (12 мин): «Сезон года»: месяц (1–12) → весна/лето/осень/зима. Через elif.
  • Задание 3 (8 мин): «Банк-идентификация»: сначала проверка пин (вложенный if), потом внутри — проверка суммы.

45–55 мин. Мини-проект урока — «Квест на 4 концовки»

  • Программа: «Ты у развилки. Налево, направо, прямо или назад?». 4 ветки elif. В ветке «налево» — вложенный if: «Встретил дракона. Сражаться или бежать?».
  • Итог — 5–6 разных концовок.

55–60 мин. Демо и рефлексия

  • Ученик показывает квест, проходит 2 разные концовки.
  • Вопросы: «Зачем elif? Когда выбрать вложенные?»

🏠 Домашнее задание (≤ 20 минут)

Программа «Калькулятор с выбором операции»: op = input("+/-/*//?: "). Через elif — 4 ветки. Что-то другое — «неизвестная операция».

✅ Критерии успешного занятия

  • Ученик использует elif минимум 2 раза.
  • В программе есть минимум одно вложенное условие.
  • Ученик объясняет, почему порядок elif важен.
  • Ученик упрощает вложенные if → elif там, где возможно.

⚠️ Типичные сложности и решения

  1. elif без if → ошибка. elif всегда идёт после if.
  2. Неправильный порядок elif → более общее условие перехватывает частное. Обсуждаем на примере.
  3. Забыл отступы вложенного блока → IndentationError.
  4. elif vs цепочка if — разбираем: цепочка каждую проверяет, elif — только до первого True.
  5. «Пирамида смерти» — 5 уровней вложенности → учим выравнивать через early return / elif.

🎁 Бонус для опережающих

Реализуй «калькулятор с двойной операцией»: a op1 b op2 c. Например 2 + 3 * 4. Учти приоритет операций через вложенные if.
