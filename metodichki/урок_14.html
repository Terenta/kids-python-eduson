Урок 14

Как работать с циклом while

Отдел: 4. Автоматизации Неделя: 14 Возраст: 8–14

Отдел: 4. Автоматизации Неделя: 14 Возраст: 8–14

🎯 Цель

Освоить цикл while как «цикл-пока»: научить описывать повторение, у которого число итераций заранее неизвестно; объяснить роль условия, счётчика и ловушки бесконечного цикла.

📚 Результаты (из источника)

Ученик понимает: когда удобнее while; чем for отличается от while; что while выполняется, пока условие истинно; отличие от if; что условие проверяется перед каждой итерацией; что такое счётчик; что такое бесконечный цикл и почему он возникает. Ученик может: писать простые while, использовать условие, менять переменную внутри цикла, останавливать цикл, создавать программы с повторениями.

🛠️ Инструменты

GigaIDE, Python 3.11, YandexGPT (для объяснения ошибок и «почему цикл не останавливается»).

⚙️ Техтребования

Как в уроке 13. Важно: научить ребёнка нажимать Ctrl+C в терминале, чтобы остановить бесконечный цикл.

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие. Проверка ДЗ (чётные числа, суммы). Показ одной задачки из ДЗ на экране.
  • 5–15. Теория. Сравниваю: «for — знаю, сколько раз. while — не знаю, делаю, пока условие не выполнится. Как поездка на лифте: нажал кнопку — едешь, пока не приедешь». Демо: n = 1; while n <= 5: print(n); n += 1. Отдельно — «чем while НЕ является» — это не if. Показываю, что будет, если забыть n += 1 (бесконечный цикл — ломаем Ctrl+C).
  • 15–45. Практика.

1. Игра «Угадай число» (урезанная версия без random): загадано secret = 7, пользователь вводит число в цикле while guess != secret, программа отвечает «больше/меньше».

2. Счётчик до первого введённого «стоп»: while True: cmd = input(); if cmd == "стоп": break — аккуратно вводим break, подробнее на уроке 15.

3. Обратный отсчёт от 10 до 0 с шагом -1.

  • 45–55. Мини-проект «Банкомат». Баланс = 1000. В цикле пользователь вводит сумму снятия; программа вычитает, пока баланс больше 0; выводит «Баланс исчерпан».
  • 55–60. Итог + ДЗ. Показываю «что будет на следующем уроке» — break, continue, else.

💬 Ключевые фразы преподавателя

  1. «for — это пробежка 10 кругов. while — бежишь, пока не устал».
  2. «Цикл проверяет условие НА ВХОДЕ, каждый круг заново».
  3. «Если while True: — это цикл-навсегда. Ломается только изнутри».
  4. «Счётчик — это переменная, которую ты сам двигаешь: n += 1».
  5. «Забыл n += 1? Python будет крутиться вечно. Ctrl+C спасает».
  6. «if — это вопрос один раз. while — это вопрос перед каждым шагом».
  7. «Проверь условие: при каком значении цикл остановится?».
  8. «"Пока пользователь не ввёл стоп" — классический while».
  9. «Условие цикла читай как "пока это верно — крути"».
  10. «while guess != 7: — "пока не угадал, продолжай спрашивать"».

🎨 Мини-проект

«Банкомат» (описан выше) — закрепляет обновление переменной внутри цикла и условие остановки.

🏠 ДЗ (≤20 мин)

  1. Угадай число от 1 до 20 (загадано в коде), дать 5 попыток через while attempts < 5.
  2. Ввести в цикле слова, завершить по пустой строке, в конце вывести количество слов.
  3. Написать таблицу удвоения: начинаем с 1, удваиваем, пока число меньше 1000 (должно вывести 1, 2, 4, 8, 16, …, 512).

✅ Критерии успеха

Ребёнок различает for и while и объясняет словами; самостоятельно пишет счётчик и не забывает его обновлять; знает, как остановить бесконечный цикл.

⚠️ Сложности и решения

  1. Бесконечный цикл. Тренируем Ctrl+C и проверку: «где я меняю условие?».
  2. Путают = и ==. Показываю: n = 5 — присваивание, n == 5 — сравнение.
  3. Пишут while (n <= 5) со скобками как в C++. Скобки не нужны, не ошибка, но объясняю стиль Python.
  4. Не понимают n += 1. Раскладываю: это то же самое, что n = n + 1.
  5. Делают while там, где достаточно for. Учу выбору: знаешь число повторений → for.

🎁 Бонус для опережающих

«Сумма цифр числа»: даём число n = 12345; в while n > 0 отрываем последнюю цифру через n % 10 и складываем, потом n //= 10. Ответ 15.

🤖 Где подключаем ИИ

Если ребёнок поймал бесконечный цикл и не понимает почему — копируем код в YandexGPT с промптом «Найди в этом коде причину бесконечного цикла, объясни 10-летнему». Разбираем ответ: ИИ указывает, что переменная не меняется. Учимся критически читать ответ.
