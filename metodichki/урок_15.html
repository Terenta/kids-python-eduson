Урок 15

Как работать с операторами continue, break, else

Отдел: 4. Автоматизации Неделя: 15 Возраст: 8–14

Отдел: 4. Автоматизации Неделя: 15 Возраст: 8–14

🎯 Цель

Освоить управляющие операторы цикла: break (выйти), continue (пропустить шаг), else (сработать, если цикл дошёл до конца без break). Научить читать и писать код с досрочным завершением.

📚 Результаты (из источника)

Ученик понимает: что такое управление выполнением цикла; назначение break; назначение continue; что делает else в цикле; когда выполняется else у цикла; как break влияет на else. Ученик может: прерывать цикл break; пропускать итерацию continue; использовать else в цикле; писать программы с досрочным завершением; читать код с управляющими операторами.

🛠️ Инструменты

GigaIDE, Python 3.11, YandexGPT.

⚙️ Техтребования

Обычный сет. Подготовить живые примеры: поиск элемента в списке, фильтрация чисел.

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие + разбор ДЗ (угадай число, удвоение).
  • 5–15. Теория с метафорами. break — «я понял, дальше не надо, выхожу из комнаты». continue — «этот шаг пропускаю, иду к следующему». else у цикла — «если цикл спокойно закончился без break, сделай это». Демо:
  for n in range(1, 11):
      if n == 5:
          break
      print(n)

Вывод: 1 2 3 4. Потом меняем break на continue — 5 пропускается, остальные печатаются.

  • 15–45. Практика.

1. Найти первое чётное число в списке [1, 3, 5, 8, 9, 12] — break при находке. Если не нашли — else: print("Нет чётных").

2. Вывести все числа от 1 до 30, пропустить кратные 3 (if n % 3 == 0: continue).

3. Проверка пароля: в цикле for _ in range(3) запрашиваем пароль, при совпадении break, else — «Доступ заблокирован».

  • 45–55. Мини-проект «Умный калькулятор». В цикле while True принимаем выражения вида 5 + 3. Если пользователь вводит exit — break. Если вводит пустую строку — continue. Используем .split() для разбора.
  • 55–60. Итог + ДЗ. Анонс проекта «Лабиринт».

💬 Ключевые фразы преподавателя

  1. «break — это пожарный выход из цикла. Нажал — сразу на улицу».
  2. «continue — это "этот шаг мне неинтересен, бегу дальше"».
  3. «else у цикла — это "фух, цикл прошёл чисто, без break"».
  4. «Если сделал break — else НЕ сработает. Это главное правило».
  5. «continue не останавливает цикл, а только прерывает ТЕКУЩУЮ итерацию».
  6. «Часто break используют в поиске: нашёл — выходи».
  7. «else у цикла — это редкая, но полезная штука. В Python так можно, в других языках — нет».
  8. «Вложенный break выходит только из ОДНОГО цикла — из самого близкого».
  9. «Используй continue, чтобы избежать глубоких if внутри цикла».
  10. «Опять же — сначала напиши на бумаге, какие числа должны вывестись».

🎨 Мини-проект

«Умный калькулятор» с exit и пропуском пустых строк (описан выше).

🏠 ДЗ (≤20 мин)

  1. В списке оценок [5, 4, 3, 2, 5, 4] найти первую двойку через break, вывести её индекс; else — «двоек нет».
  2. Вывести числа от 1 до 50, пропустить кратные 7 через continue.
  3. Программа-хранитель: в цикле спрашивает «пароль». Даёт 5 попыток, пароль python123. После успеха break и «Добро пожаловать», else — «Доступ запрещён».

✅ Критерии успеха

Ребёнок уверенно объясняет словами разницу break/continue; правильно использует else у цикла; пишет код поиска элемента с break и фразой «не нашли» через else.

⚠️ Сложности и решения

  1. Путают break и continue. Визуально на листе рисую «выход» и «пропуск шага».
  2. Думают, что else у цикла — как у if. Прямо проговариваю: «это "если цикл прошёл ДО КОНЦА без break"».
  3. Используют break там, где достаточно правильного условия. Показываю оба варианта, обсуждаем читаемость.
  4. Забывают, что continue не работает в if без цикла. Напоминаю: «эти слова — только внутри цикла».
  5. В вложенных циклах break выходит только из одного. Разбираем на листе кто «сосед».

🎁 Бонус для опережающих

«Поиск простого числа». Функция-пока-не-функция: цикл for d in range(2, n), если делится — break, else — печатать «n простое». Это подготовка к уроку 17.
