Урок 16

Проект: «Лабиринт» + генерация ASCII-графики

Отдел: 4. Автоматизации Неделя: 16 Возраст: 8–14

Отдел: 4. Автоматизации Неделя: 16 Возраст: 8–14

🎯 Цель

Свести всё, что было в уроках 13–15 (циклы, условия, списки), в первый серьёзный интерактивный проект — консольный лабиринт, где двумерный список хранит карту, а игрок ходит по командам WASD. Закрепить работу с двумерными структурами и использовать ИИ как генератор уровней.

📚 Результаты (из источника)

Ученик может: создавать двумерные списки и инициализировать значениями; преобразовывать строки в списки символов; использовать for для обработки элементов; использовать while для повторяющихся действий; объединять элементы списка в строку и выводить; использовать переменные для состояния; подсчитывать количество элементов по условию; комбинировать циклы, условия, списки и ввод пользователя для интерактивной программы.

🛠️ Инструменты

GigaIDE (основной), Google Colab (резервный), Python 3.11, YandexGPT через Алису — для генерации ASCII-карт лабиринта, Kandinsky — для обложки проекта.

⚙️ Техтребования

Как обычно. Отдельно: подготовить шаблон «пустой» карты 7×10 и 2 готовых примера лабиринтов в виде списка строк.

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие. Демонстрация готового лабиринта от преподавателя (запустил, прошёл 3 шага, врезался в стену, нашёл выход). «Сегодня сделаешь это сам».
  • 5–15. Теория-демо. Показываю двумерный список как «список списков»:
  maze = [
      list("#########"),
      list("#P  #   #"),
      list("# # # # #"),
      list("#   #  E#"),
      list("#########"),
  ]

Печать карты через вложенный for row in maze: print("".join(row)). Объясняю, как найти позицию P через двойной цикл. Показываю движение: запрос команды, проверка стены.

  • 15–45. Практика — собираем проект поэтапно.

1. Печать карты через вложенные циклы.

2. Функция-пока-через-while True: запрос команды, движение игрока, проверка # и E (выход). Используем break, continue.

3. Счётчик ходов steps. Подсчёт свободных клеток через двойной цикл.

  • 45–55. Мини-проект. Генерируем лабиринт через Алису/YandexGPT: промпт «Нарисуй ASCII-лабиринт 7×10, символ # — стена, пробел — проход, P — игрок, E — выход. Только текст». Вставляем в код. Проходим.
  • 55–60. Защита проекта (3–5 мин): ребёнок демонстрирует лабиринт, объясняет логику движения. Выдача бейджа «Бесконечный цикл». ДЗ.

💬 Ключевые фразы преподавателя

  1. «Двумерный список — это просто лист в клеточку: строка и столбец».
  2. «maze[y][x] — сначала строка (y), потом столбец (x). Как шахматы».
  3. «list("#####") превращает строку в список символов — так мы сможем менять клетки».
  4. «"".join(row) собирает список обратно в строку для печати».
  5. «Игрок — это пара координат (x, y). Всё, что ты делаешь — меняешь эти числа».
  6. «Стена — это #. Перед ходом проверь: "в новой клетке не #?"».
  7. «while True + break при выходе — стандартный игровой цикл».
  8. «Не делай всё сразу. Сначала карта, потом печать, потом ввод, потом проверка».
  9. «Алиса отлично рисует ASCII — только попроси "только текст, без объяснений"».
  10. «Это первый настоящий проект. Не расстраивайся, если с первой попытки криво».

🎨 Мини-проект

Сам урок — мини-проект «Лабиринт». Результат: консольный лабиринт 5–7 строк × 9–11 столбцов, игрок ходит W/A/S/D, программа печатает карту после каждого хода, считает шаги и останавливается на E.

🏠 ДЗ (≤20 мин)

  1. Сделать лабиринт побольше (10×15), используя промпт к Алисе.
  2. Добавить «монетки» *: при наступании монетка исчезает, счётчик монет растёт. В конце — «Собрано 5 из 5!».
  3. Подготовить 3-минутную защиту для следующего урока.

✅ Критерии успеха

Лабиринт запускается, игрок двигается, стены работают, программа считает шаги, выход завершает игру. Ребёнок на защите объясняет, где циклы, где условия, где списки.

⚠️ Сложности и решения

  1. Путают x/y в maze[y][x]. Рисую координаты на листе в клеточку.
  2. Забывают проверку стены — игрок проходит сквозь #. Разбираем порядок: сначала проверяем новую клетку, потом двигаем.
  3. Печать карты без join — выводится список. Показываю разницу print(row) vs print("".join(row)).
  4. Вышли за границы карты → IndexError. Добавляем проверку 0 <= new_y < len(maze) и 0 <= new_x < len(maze[0]).
  5. Карта от Алисы «косая» (строки разной длины). Учим проверять глазами и подправлять руками.

🎁 Бонус для опережающих

Добавить «врага», который случайным образом двигается на 1 клетку каждый ход. Использовать random.choice(["W", "A", "S", "D"]). Это подготовка к модулю функций и к PyGame Zero.

🤖 Где подключаем ИИ

Активное использование. YandexGPT — генератор лабиринтов: ребёнок сам составляет промпт («сделай ASCII-лабиринт с одним выходом, 7 строк»). Учимся критически проверять результат — бывает кривая сетка. Kandinsky — сгенерировать «обложку» проекта для демо. Разбираем: ИИ нарисовал карту, но КОД движения ребёнок написал сам.
