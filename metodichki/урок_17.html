Урок 17

Что такое функция и как создать функцию без параметров

Отдел: 5. Функциональных механик Неделя: 17 Возраст: 8–14

Отдел: 5. Функциональных механик Неделя: 17 Возраст: 8–14

🎯 Цель

Ввести понятие функции как именованного блока кода, который можно запустить многократно. Научить объявлять функцию через def, различать объявление и вызов, видеть, как функция избавляет от копипасты.

📚 Результаты (из источника)

Ученик понимает: что такое функция и зачем она нужна; что функции избавляют от повторов; как объявляется функция через def; что тело функции выполняется только при вызове; роль отступов; чем функция отличается от обычного кода; разницу между объявлением и вызовом. Ученик может: создавать функции без параметров; вызывать функции; писать простые функции для повторяющихся действий (приветствие, вывод меню); организовывать код компактно.

🛠️ Инструменты

GigaIDE, Python 3.11, YandexGPT.

⚙️ Техтребования

Стандартный сет. Подготовить код лабиринта с «копипастой» (чтобы показать мотивацию ввода функций).

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие + защиты «Лабиринта». Выдача бейджа «Бесконечный цикл».
  • 5–15. Теория. Мотивация: открываю код лабиринта, показываю, что печать карты дублируется 3 раза. «Копипаста — зло. Функция — это кнопка, которую нажал и получил действие». Демо:
  def greet():
      print("Привет, мир!")
      print("Как дела?")

  greet()
  greet()
  greet()

Разбираю: def — объявление, greet() — вызов. Тело функции выполняется только при вызове. Функцию можно вызывать сколько угодно раз.

  • 15–45. Практика.

1. def print_menu(): — вывести меню из 3 пунктов («Начать игру», «Правила», «Выход»). Вызвать 2 раза.

2. def draw_line(): — печатает "-" * 40. Использовать в 3 местах для красивого оформления вывода.

3. Переделать часть кода из «Лабиринта»: вынести печать карты в def show_map(): (используем глобальный maze — пока договоримся, что это ок, параметры будут на уроке 18).

  • 45–55. Мини-проект «Меню видеоигры». Пишем 4 функции: start_game(), show_rules(), show_credits(), quit_game(). Связка: в while True пользователь вводит цифру 1–4, мы вызываем нужную функцию.
  • 55–60. Итог + ДЗ.

💬 Ключевые фразы преподавателя

  1. «Функция — это имя для кучки кода. Назвал — можешь звать сколько хочешь».
  2. «def — это "я готовлю рецепт". Вызов greet() — "испеки по рецепту"».
  3. «Объявление функции НЕ выполняет её. Пока не вызвал — ничего не произойдёт».
  4. «Назови функцию глаголом: show_map, print_menu, draw_line».
  5. «Тело функции — всё, что с отступом. Без отступа — уже не функция».
  6. «Круглые скобки () — это место для "входных данных". Пока пусто. Со следующего урока появятся».
  7. «Если копируешь код второй раз — стоп, пиши функцию».
  8. «Читай код так: "объявил рецепт, объявил рецепт, а теперь делаю звонки"».
  9. «Имя функции — латиницей, нижним регистром, со подчёркиванием: show_credits, не ShowCredits».
  10. «Один урок назад ты писал цикл. Теперь ты пишешь функции. Ты растёшь».

🎨 Мини-проект

«Меню видеоигры» — описан выше. Закрепляет: def, вызов, связку с циклом и условиями.

🏠 ДЗ (≤20 мин)

  1. Функция print_logo(), которая печатает ASCII-логотип твоего проекта (3–5 строк). Вызвать в начале и в конце программы.
  2. Функция ask_name() — просит ввести имя и печатает приветствие. Вызвать 3 раза подряд (будет 3 разных приветствия).
  3. Взять код из урока 12 (база по игре) и вынести печать карточки персонажа в функцию show_card().

✅ Критерии успеха

Ребёнок объявляет функцию без подглядывания, вызывает её несколько раз, понимает, что объявление не выполняет код. Видит, где в старом коде была бы полезна функция.

⚠️ Сложности и решения

  1. Забывают () при вызове. greet — не запускает функцию, а «указывает на неё». Показываю, что выводится.
  2. Пишут def greet: без (). Разбираем синтаксис, говорю «скобки обязательны».
  3. Не ставят двоеточие в конце def. Лечится через traceback — читаем вместе.
  4. Объявили функцию, но не вызвали — удивляются, что не работает. Повторяю: «рецепт есть, а блинов — нет».
  5. Тело функции без отступа → IndentationError. Возвращаемся к правилам отступов.

🎁 Бонус для опережающих

Функция ascii_banner(), которая печатает имя ребёнка огромными ASCII-буквами. Получить буквы через Алису: «нарисуй ASCII-арт букв "МАКС", каждая буква 5 строк высотой».

🤖 Где подключаем ИИ

YandexGPT отвечает на вопрос «Зачем в настоящих программах нужны функции?» — ребёнок читает, пересказывает своими словами. Плюс Алиса генерирует ASCII-баннеры для print_logo(). Правило: ИИ генерирует контент, ребёнок пишет функцию.
