Урок 18

Как использовать функции с параметрами

Отдел: 5. Функциональных механик Неделя: 18 Возраст: 8–14

Отдел: 5. Функциональных механик Неделя: 18 Возраст: 8–14

🎯 Цель

Научить передавать в функцию данные через параметры — «функция теперь может работать с РАЗНЫМИ входами». Ввести различие параметр/аргумент, роль порядка, передачу разных типов.

📚 Результаты (из источника)

Ученик понимает: что такое параметры и зачем они нужны; разницу между параметрами и аргументами; что значения передаются в параметры; что функция использует данные; роль позиции и порядка; что можно передавать числа, строки, списки; как передавать несколько аргументов. Ученик может: создавать функции с параметрами; вызывать функцию с разными аргументами; использовать параметры для вычислений и вывода; писать функции однотипных действий с разными данными; комбинировать с условиями и циклами.

🛠️ Инструменты

GigaIDE, Python 3.11, YandexGPT.

⚙️ Техтребования

Стандарт.

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие + разбор ДЗ (логотипы, карточка персонажа).
  • 5–15. Теория. «Вчера функция greet() всегда здоровалась одинаково. А что если я хочу поздороваться с Аней, Борей, Витей — по-разному?». Демо:
  def greet(name):
      print(f"Привет, {name}!")

  greet("Аня")
  greet("Боря")
  greet("Витя")

Объясняю: name — параметр (в определении), "Аня" — аргумент (при вызове). Показываю функции с 2 и 3 параметрами: def add(a, b): print(a + b).

  • 15–45. Практика.

1. def print_rectangle(width, height, symbol): — печатает прямоугольник из symbol размера width × height. Вызвать 3 раза с разными параметрами.

2. def describe_pet(name, age, species): — печатает «Знакомьтесь: {name}, {species}, {age} лет». Вызвать для 3 зверей.

3. Переделать show_map() из прошлого урока: теперь show_map(maze) принимает карту как параметр. Так уходим от глобальных переменных.

  • 45–55. Мини-проект «Генератор квадратов ASCII». Функция draw_square(size, fill, border) рисует квадрат заданного размера с указанными символами границы и заливки. Ребёнок вызывает 5 раз с разными параметрами, получает «галерею».
  • 55–60. Итог + ДЗ.

💬 Ключевые фразы преподавателя

  1. «Параметр — это имя, которое стоит в скобках при def. Аргумент — значение, которое ты туда кладёшь при вызове».
  2. «Параметры — это "входы" у функции. Как входные двери у дома».
  3. «Передавать можешь всё: число, строку, список, даже другую функцию. Но это попозже».
  4. «Порядок важен: greet("Аня", "Боря") — это не то же самое, что greet("Боря", "Аня")».
  5. «Называй параметры по смыслу: width, name, pet_age — не a, b, c в сложных функциях».
  6. «Одна функция — одно действие. Не пытайся впихнуть 5 задач в одну do_everything()».
  7. «Параметр живёт только внутри функции. Снаружи его нет».
  8. «f-строка с {name} — твой друг: динамический вывод».
  9. «Поняв параметры, ты можешь писать show_map(maze1), show_map(maze2) — одна функция, два лабиринта».
  10. «Это шаг к чистому коду. Программы теперь будут короче и понятнее».

🎨 Мини-проект

«Генератор квадратов ASCII» — закрепляет 3 параметра, тип-строка, тип-число.

🏠 ДЗ (≤20 мин)

  1. Функция say_hi(name, times) — печатает «Привет, {name}!» times раз (использует for).
  2. Функция count_letter(text, letter) — считает, сколько раз letter встречается в text, печатает число.
  3. Функция show_card(hero) принимает словарь-заглушку (дам пример {"name": "Зорро", "hp": 100}), печатает карточку. Это тизер урока 27.

✅ Критерии успеха

Ребёнок уверенно пишет функции с 1–3 параметрами, вызывает их с разными аргументами, объясняет разницу параметр/аргумент.

⚠️ Сложности и решения

  1. Путают параметр и аргумент. Аналогия: «параметр — почтовый ящик, аргумент — письмо, которое ты кидаешь».
  2. При вызове забывают передать все аргументы. TypeError: missing argument — читаем вместе.
  3. Передают в неправильном порядке. Показываю на print_rectangle(3, "#", 5) — некрасиво выводится, разбираем.
  4. Изменяют параметр внутри функции, ожидая, что снаружи тоже изменится. Пока не углубляемся, говорю «это отдельная коробка, снаружи не видно».
  5. Список в аргументах — а здесь сюрприз, он может меняться. Предупреждаю, подробнее на уроке 19.

🎁 Бонус для опережающих

Функция draw_triangle(size) — рисует прямой треугольник из . Попробовать для size=5 получить 5 строк: , , …, *. Потом — зеркальный вариант.

🤖 Где подключаем ИИ

YandexGPT — для генерации «списка смешных зверей» к describe_pet: «Придумай 5 питомцев с именами, возрастом и видом, в формате Python-списка кортежей». Ребёнок копирует, циклом перебирает и вызывает describe_pet(pet). Тут же обсуждаем, что такое распаковка — короткое знакомство.
