Урок 19

Как работать с функциями с возвратом значения

Отдел: 5. Функциональных механик Неделя: 19 Возраст: 8–14

Отдел: 5. Функциональных механик Неделя: 19 Возраст: 8–14

🎯 Цель

Научить функции ВОЗВРАЩАТЬ значение через return, отличать «функцию-действие» от «функции-вычислителя», сохранять результат в переменную, использовать в выражениях, условиях и циклах.

📚 Результаты (из источника)

Ученик понимает: что такое возврат значения через return; что функция может вернуть результат; разницу «выполняет действие» vs «возвращает результат»; как сохранить результат в переменную; как использовать значение в выражениях, функциях, условиях; как использовать несколько return; как создавать вложенные функции. Ученик может: создавать функции с возвратом; сохранять результат; использовать в арифметике, условиях, циклах; комбинировать функции всех трёх типов; писать сложные интерактивные программы (калькулятор, игры с очками).

🛠️ Инструменты

GigaIDE, Python 3.11, YandexGPT.

⚙️ Техтребования

Стандарт. Подготовить шаблон будущего «Морского боя» (пустая карта 5×5 для урока 20).

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие + разбор ДЗ (say_hi, count_letter, show_card).
  • 5–15. Теория. Ключевой момент. «До сегодня функции говорили print. А что если я хочу функцию, которая вычисляет, но не печатает, — а отдаёт результат мне?». Демо:
  def add(a, b):
      return a + b

  s = add(3, 5)
  print(s)           # 8
  print(add(10, 20)) # 30

Различие print vs return на доске. Несколько return:

  def sign(n):
      if n > 0: return "плюс"
      if n < 0: return "минус"
      return "ноль"

Упомянуть вложенные функции (коротко).

  • 15–45. Практика.

1. Калькулятор-модуль: add, sub, mul, div — все с return. Главная функция спрашивает операцию и числа, вызывает нужную.

2. def is_even(n): return n % 2 == 0 — используем в цикле: for n in range(10): if is_even(n): print(n).

3. def max_of(lst): … своими руками (без встроенного max). Возвращает максимум списка через for + if.

  • 45–55. Мини-проект «Счёт в игре». Функция calc_score(hits, misses) возвращает очки по формуле hits10 - misses3. Цикл из 5 раундов: спрашиваем попадания/промахи, складываем счёт, в конце — итог.
  • 55–60. Итог + ДЗ. Анонс проекта «Морской бой».

💬 Ключевые фразы преподавателя

  1. «print — сказал вслух. return — отдал в руку».
  2. «После return функция сразу заканчивается. Код ниже return не выполнится».
  3. «Результат return можно положить в переменную: s = add(3, 5)».
  4. «Можно подставить прямо: print(add(3, 5) * 2) — всё внутри скобок посчитается».
  5. «Несколько return в одной функции — это нормально. Каждый — отдельный выход».
  6. «Функция-действие (show_map) ничего не возвращает. Функция-вычислитель (add) возвращает значение».
  7. «Если нет return, Python возвращает None. Это не ошибка, но знать полезно».
  8. «Функция без return — это приказ. Функция с return — это вопрос, на который ты получил ответ».
  9. «Хорошее правило: одна функция — либо делает что-то, либо возвращает. Смешивать — плохо».
  10. «Теперь ты почти готов к "Морскому бою" — там без функций никуда».

🎨 Мини-проект

«Счёт в игре» (описан выше). Сочетает параметры, return и цикл.

🏠 ДЗ (≤20 мин)

  1. def is_prime(n) — возвращает True/False. Используется в цикле for n in range(2, 30): if is_prime(n): print(n).
  2. def average(lst) — возвращает среднее арифметическое списка.
  3. Мини-игра «Кости»: def roll_dice() возвращает случайное число 1–6 (подсказка: random.randint(1, 6) — используем import random). Цикл из 10 бросков, считаем, сколько раз выпала шестёрка.

✅ Критерии успеха

Ребёнок различает функции-действия и функции-значения; умеет сохранять результат в переменную и использовать в выражениях; пишет функцию с несколькими return под условия.

⚠️ Сложности и решения

  1. Пишут print вместо return. «Ты хочешь увидеть значение или использовать его дальше?» — разбираем разницу.
  2. Код после return не выполняется — удивляются. Показываю, что return — выход.
  3. Сохраняют результат, но не используют: add(3, 5) без присвоения. «Ты получил ответ, но выбросил».
  4. Путают return и break. Разные слова, разные задачи: return — из функции, break — из цикла.
  5. Вложенные функции кажутся магией. Объясняю коротко, не заставляю использовать.

🎁 Бонус для опережающих

Функция fibonacci(n) — возвращает n-е число Фибоначчи через цикл. Для опережающих — рекурсивный вариант (с оговоркой, что это забегание вперёд).
