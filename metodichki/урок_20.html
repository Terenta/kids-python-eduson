Урок 20

Проект: «Морской бой» + генерация ASCII-графики / видео для игры

Отдел: 5. Функциональных механик Неделя: 20 Возраст: 8–14

Отдел: 5. Функциональных механик Неделя: 20 Возраст: 8–14

🎯 Цель

Сделать самый сложный проект модуля: консольный «Морской бой» на двоих игроков. Применить ВСЁ из модулей 4–5: циклы, условия, списки (двумерные), функции с параметрами и return. Научить организовывать код через функции-блоки.

📚 Результаты (из источника)

Ученик может: создавать и инициализировать двумерные списки для поля; хранить и изменять координаты кораблей; считывать координаты от пользователя; отображать состояние поля; реализовать постановку кораблей для каждого игрока; обработку выстрелов с попаданиями и промахами; подсчёт оставшихся палуб и определение победителя; организацию игрового цикла с чередованием ходов; комбинацию функций, циклов, условий и списков в одной программе.

🛠️ Инструменты

GigaIDE (основной), Python 3.11, YandexGPT — для генерации ASCII-графики заставки и идей видео-тизера, Kandinsky / YandexArt — для обложки/промо-картинки.

⚙️ Техтребования

Стандарт. Отдельно: подготовить шаблон с пустыми функциями (чтобы сэкономить время на печатание).

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие + разбор ДЗ (is_prime, average, roll_dice).
  • 5–15. Теория-демо. Запускаю свой готовый «Морской бой» на 2 игроков — показываю всю игру за 90 секунд. Показываю структуру кода на экране:
  def create_board(size): ...
  def draw_board(board, hide_ships=True): ...
  def place_ships(board, count): ...
  def shoot(board, x, y): ...
  def is_defeated(board): ...
  def switch_player(current): ...

«Каждая функция — одна ответственность. В этом сила».

  • 15–45. Практика — собираем по блокам.

1. create_board(5) — возвращает двумерный список 5×5 из точек ..

2. draw_board(board) — печатает с заголовками колонок (A–E) и строк (1–5). С параметром hide_ships скрывает S, показывая ..

3. place_ships(board, 3) — ставит 3 корабля случайно через random.randint.

4. shoot(board, x, y) — возвращает "hit", "miss" или "repeat".

  • 45–55. Мини-проект — игровой цикл. while True чередует игроков, вызывает shoot, проверяет is_defeated, поздравляет победителя. Запускаем тестовую партию.
  • 55–60. Защита (2–3 мин): ребёнок демонстрирует, объясняет 3 функции. Бейдж «Функциональный герой». ИИ-бонус: генерация идеи видео-тизера (через YandexGPT — сценарий 15 сек).

💬 Ключевые фразы преподавателя

  1. «Первое правило сложных проектов: разбей на функции ДО того, как начнёшь писать код».
  2. «Двумерный список — это поле. board[y][x] — клетка».
  3. «Состояния клетки: . — вода, S — корабль, X — попадание, O — промах. Всё».
  4. «Функция shoot возвращает результат — это классика return из прошлого урока».
  5. «Координаты A1 превращаются в (y=0, x=0). Запоминай: буква — колонка, цифра — строка».
  6. «Чередование игроков — current = 1 - current. Было 0, стало 1, и обратно».
  7. «hide_ships=True при печати поля соперника — ты же не показываешь свои корабли ему».
  8. «Когда зависнешь — НЕ переписывай всё. Печатай board для отладки».
  9. «Это твой 5-й проект. Смотри, ты уже не боишься двумерных списков».
  10. «Защита — 3 минуты. Покажи игру, назови любимую функцию, расскажи, где было сложно».

🎨 Мини-проект

Весь урок = проект. Результат: рабочий «Морской бой» 5×5 на двоих с чередованием ходов, скрытием чужих кораблей, подсчётом попаданий и объявлением победителя. Код — в 6–8 функциях.

🏠 ДЗ (≤20 мин)

  1. Увеличить поле до 7×7 и количество кораблей до 5.
  2. Добавить функцию ascii_splash(), которая печатает заставку «МОРСКОЙ БОЙ» из ASCII-арта (сгенерировать через Алису).
  3. Сценарий 15-секундного видео-тизера игры — написать от руки 5 кадров (для урока по ИИ дальше).

✅ Критерии успеха

Игра запускается, два игрока ходят по очереди, попадания отмечаются, программа корректно определяет победителя. Код разбит минимум на 5 функций. Ребёнок на защите уверенно показывает, какая функция за что отвечает.

⚠️ Сложности и решения

  1. Путают координаты (y, x) и (x, y). Всегда рисую оси на листе до кода.
  2. Корабли ставятся на одну клетку. Добавляем проверку if board[y][x] == "." перед постановкой.
  3. Игра не завершается — забыли is_defeated. Разбираем игровой цикл, добавляем вызов.
  4. Ввод A1 → ошибка. Парсим: letter = s[0].upper(); num = int(s[1:]). Проверяем границы.
  5. Функции слишком большие. Учу: «если функция длиннее 15 строк — разбей».

🎁 Бонус для опережающих

Добавить режим «одиночная игра против бота» — второй игрок заменяется функцией bot_shoot(board), которая стреляет случайно и помнит свои промахи.

🤖 Где подключаем ИИ

Активно. YandexGPT — генерация ASCII-баннера «МОРСКОЙ БОЙ», сценария видео-тизера. Kandinsky — генерация промо-арта (корабль в шторме). Обсуждаем: код ребёнка — игра, вклад ИИ — обложка/заставка/промо. Защищаем свой вклад отдельно от ИИ-вклада.
