Что такое модули и как их использовать

Отдел: 6. Интеграции Неделя: 21 Возраст: 8–14

Отдел: 6. Интеграции Неделя: 21 Возраст: 8–14

🎯 Цель

Открыть ребёнку мир стандартной библиотеки Python. Научить подключать готовый код через import, использовать math, random, time, различать import module и from module import func.

📚 Результаты (из источника)

Ученик понимает: что такое модуль и зачем он нужен; что модули позволяют использовать готовый код; как импортировать через import; как использовать функции через точку; разницу полного импорта и импорта отдельной функции; что в стандартной библиотеке много полезных модулей. Ученик может: импортировать модули; использовать несколько в одной программе; писать программы с модулями (случайные числа, математика); комбинировать модули с циклами и условиями.

🛠️ Инструменты

GigaIDE, Python 3.11, YandexGPT (для знакомства с модулями).

⚙️ Техтребования

Стандарт. Отдельно: открыть https://docs.python.org/3/library/ — показать детям «это огромная библиотека готовых решений».

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие + защиты «Морского боя», выдача бейджа «Функциональный герой».
  • 5–15. Теория. «Модуль — это файл с готовым кодом, который написали другие программисты. Python поставляется с сотнями таких. Ты не обязан писать корень квадратный с нуля — его уже написали».
  import math
  print(math.sqrt(16))   # 4.0
  print(math.pi)         # 3.14...

  import random
  print(random.randint(1, 6))
  print(random.choice(["орёл", "решка"]))

  import time
  time.sleep(1)
  print("Прошла секунда")

Разница:

  from random import randint
  print(randint(1, 6))   # без префикса random.
  • 15–45. Практика.

1. «Угадай число» теперь по-настоящему: secret = random.randint(1, 100). Играем.

2. «Случайный герой»: список 5 имён, random.choice возвращает героя дня.

3. «Таймер обратного отсчёта»: for i in range(5, 0, -1): print(i); time.sleep(1); print("СТАРТ!").

  • 45–55. Мини-проект «Броски костей». Функция roll_dice(n) бросает n костей через random.randint, возвращает список результатов. Пользователь вводит n, программа бросает, печатает сумму и среднее через sum() и len(). Бонус: math.floor — округление.
  • 55–60. Итог + ДЗ. Анонс: «Файлы — уже завтра».

🎨 Мини-проект

«Броски костей» с random + math — описан выше.

🏠 ДЗ (≤20 мин)

  1. secret_word = random.choice(["кот", "пёс", "птица", "рыба", "лев"]) — заложить основу будущей «Виселицы» (урок 28).
  2. math.sin(math.pi / 2) — проверить, что получается 1.0. Написать 3 таких примера.
  3. time.sleep + print — сделать «диктор», который печатает 3 новости с паузой в 2 секунды между ними.

✅ Критерии успеха

Ребёнок уверенно импортирует math, random, time; вызывает функции через точку; понимает from ... import; использует random.randint, random.choice, time.sleep, math.sqrt.

⚠️ Сложности и решения

  1. Забывают import. NameError: name 'random' is not defined — разбираем.
  2. Импортируют с ошибкой: import Random. Python регистрозависим, поправляю.
  3. Пишут random(1, 6) без .randint. TypeError: module is not callable — объясняю.
  4. Путают randint(1, 6) и randrange(1, 6). randint включает 6, randrange — нет. Запоминаем.
  5. Ставят time.sleep(1000) и ждут вечность. sleep — в секундах, не миллисекундах.

🎁 Бонус для опережающих

Сыграть в «камень-ножницы-бумага» против компьютера. random.choice(["камень", "ножницы", "бумага"]) + проверка правил через if/elif.
