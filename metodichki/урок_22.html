Урок 22

Как работать с файлами. Часть 1

Отдел: 6. Интеграции Неделя: 22 Возраст: 8–14

Отдел: 6. Интеграции Неделя: 22 Возраст: 8–14

🎯 Цель

Впервые выйти за пределы оперативной памяти программы. Научить открывать файл, читать, писать, дописывать, использовать with для безопасного закрытия.

📚 Результаты (из источника)

Ученик понимает: зачем нужны файлы и чем отличаются от переменных; что такое режимы r, w, a; что w удаляет, a дописывает; как использовать open(), read(), write(), close(); роль with; что файл можно читать построчно или целиком. Ученик может: открывать и закрывать файлы; читать и выводить текст; записывать; дописывать; использовать with; создавать программы с сохранением данных.

🛠️ Инструменты

GigaIDE, Python 3.11, YandexGPT (для генерации начального текста).

⚙️ Техтребования

Стандарт + отдельная рабочая папка lesson_22 на рабочем столе. Объяснить, где физически создаются файлы.

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие + разбор ДЗ (секретное слово, time.sleep, math).
  • 5–15. Теория. «Когда ты закрываешь программу, ВСЕ данные в переменных исчезают. Файлы — это способ сохранить что-то навсегда. Это как тетрадка — закрыл и положил в портфель, завтра откроешь». Демо:
  # Чтение
  with open("notes.txt", "r", encoding="utf-8") as f:
      content = f.read()
      print(content)

  # Запись (перезаписывает!)
  with open("notes.txt", "w", encoding="utf-8") as f:
      f.write("Первая строка\n")

  # Дописывание
  with open("notes.txt", "a", encoding="utf-8") as f:
      f.write("Вторая строка\n")

Важно: encoding="utf-8" — чтобы кириллица не билась. Объясняю разницу r / w / a.

  • 15–45. Практика.

1. Создать notes.txt через код, записать 3 заметки через a.

2. Прочитать и вывести на экран через read().

3. Прочитать построчно через for line in f: print(line.strip()).

  • 45–55. Мини-проект «Дневник 2.0». Программа в цикле спрашивает: 1) добавить запись (a), 2) показать все записи (r), 3) очистить (w с пустой строкой), 4) выйти. Всё сохраняется в diary.txt.
  • 55–60. Итог + ДЗ. Предупреждение: «Если откроешь с w, старое удалится. Это классическая детская ошибка».

💬 Ключевые фразы преподавателя

  1. «Файл — это тетрадка. Переменная — это запоминалка в голове».
  2. «with open(...) as f: — золотой стандарт. Открывается, делается, автоматически закрывается».
  3. «r — read — читать. w — write — писать с нуля. a — append — дописывать».
  4. «w — это бульдозер. Старое содержимое сносится».
  5. «encoding="utf-8" — ставь ВСЕГДА, иначе кириллица сломается».
  6. «f.write не добавляет \n сам. Пиши его руками».
  7. «f.read() читает всё. f.readline() — одну строку. Цикл for line in f — по строкам».
  8. «line.strip() убирает \n в конце. Иначе выводится лишний пробел».
  9. «Открыл — должен закрыть. with делает это за тебя».
  10. «Файл физически лежит в папке рядом с твоим .py. Проверь в проводнике».

🎨 Мини-проект

«Дневник 2.0» (описан выше) — закрепляет r/w/a в одной программе, возвращает к дневнику из урока 8, но теперь с ПОСТОЯННЫМ хранением.

🏠 ДЗ (≤20 мин)

  1. Создать файл todo.txt, через программу добавить 5 задач (через a).
  2. Прочитать файл, посчитать, сколько в нём строк.
  3. Прочитать todo.txt, вывести задачи с номерами: «1. Купить хлеб» и т.д.

✅ Критерии успеха

Ребёнок открывает файл в трёх режимах, уверенно использует with, понимает разницу w и a, делает encoding="utf-8".

⚠️ Сложности и решения

  1. Открыли w, потеряли данные. Важно проговорить: w удаляет! Учимся к a.
  2. Забыли encoding → кракозябры. Всегда utf-8, это правило.
  3. Не понимают, где лежит файл. Показываю в проводнике рядом с .py. Обсуждаем абсолютный vs относительный путь.
  4. Пишут без \n — всё в одну строку. Учим добавлять \n в конце.
  5. FileNotFoundError при r. Учим: сначала проверь, что файл существует; либо try/except (на уроке 23).

🎁 Бонус для опережающих

Программа-парсер: читает notes.txt, считает количество слов (через .split()), выводит топ-5 самых длинных слов.

🤖 Где подключаем ИИ

YandexGPT — генератор стартовых заметок для дневника: «Напиши 5 коротких заметок школьника о сегодняшнем дне, в формате списка строк на Python». Ребёнок копирует, сохраняет через w, затем играет в «Дневник». Это связка «ИИ = генератор данных, код = пользователь».
