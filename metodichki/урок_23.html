🎯 Цель

Углубить работу с файлами: методы readlines(), writelines(), seek(), tell(); бинарные режимы rb/wb; режим x (создание нового файла); обработка ошибок через try/except.

📚 Результаты (из источника)

Ученик может: читать и записывать файлы целиком и построчно; перемещать курсор; работать с бинарными файлами; обрабатывать ошибки; комбинировать файлы с циклами, условиями и функциями; сохранять сложные данные.

🛠️ Инструменты

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие + разбор ДЗ (todo-список).
  • 5–15. Теория. Новые методы:
  with open("notes.txt", "r", encoding="utf-8") as f:
      lines = f.readlines()        # список строк с \n
      print(lines)

  with open("notes.txt", "w", encoding="utf-8") as f:
      f.writelines(["a\n", "b\n", "c\n"])

Курсор:

  with open("notes.txt", "r", encoding="utf-8") as f:
      print(f.tell())   # 0
      f.read(5)
      print(f.tell())   # 5
      f.seek(0)
      print(f.read())

Бинарный режим:

  with open("cat.png", "rb") as src, open("cat_copy.png", "wb") as dst:
      dst.write(src.read())

try/except:

  try:
      with open("no_such.txt", "r") as f:
          print(f.read())
  except FileNotFoundError:
      print("Файла нет, создам новый")

Режим x — «создать, если нет; упасть, если есть». Полезно для инициализации.

  • 15–45. Практика.

1. readlines + цикл: пронумеровать и вывести строки notes.txt.

2. Копирование cat.png в cat_copy.png бинарно — открыть в папке, убедиться, что картинка отображается.

3. try/except вокруг чтения: если файл не найден — вывести «Файла нет, создаю» и создать пустой через x.

  • 45–55. Мини-проект «Лог игры». Каждый запуск программы дописывает в game_log.txt строку вида «2026-04-20 14:32 — запущено». Время — через time.strftime. Перед чтением — try/except. Вывод числа запусков.
  • 55–60. Итог + ДЗ. Анонс «Квиз в консоли».

💬 Ключевые фразы преподавателя

  1. «readlines — одна команда, список всех строк. Удобно для структурированных данных».
  2. «Курсор — это "указка" в файле. tell — где я стою; seek — переместись».
  3. «Бинарный режим rb/wb — для картинок, музыки, всего не-текстового».
  4. «try/except — это ремень безопасности программы. Файла нет? Не падаем, разбираемся».
  5. «except FileNotFoundError — ловим КОНКРЕТНУЮ ошибку. Голый except — плохой стиль».
  6. «Режим x — страховка: не хочу случайно переписать готовый файл».
  7. «time.strftime("%Y-%m-%d %H:%M") — форматирование времени. Запомни паттерн».
  8. «Не забывай encoding="utf-8" в текстовых режимах. В бинарных — не надо».
  9. «readlines возвращает строки СО символом \n — не забывай .strip()».
  10. «Теперь ты умеешь сохранять навсегда и не бояться ошибок. Пора делать квиз».

🏠 ДЗ (≤20 мин)

  1. Скопировать любую картинку с рабочего стола через rb/wb. Убедиться, что копия открывается.
  2. Написать программу: если todo.txt отсутствует — создать через x и предложить добавить задачу; иначе — показать задачи.
  3. Посчитать количество строк в любимой книге в виде .txt файла (попросить Алису сгенерировать 30 строк любой сказки).

✅ Критерии успеха

Ребёнок использует readlines/writelines; ловит FileNotFoundError через try/except; копирует бинарный файл; понимает роль seek/tell.

⚠️ Сложности и решения

  1. Голый except — ловит всё. Учим писать конкретный: except FileNotFoundError.
  2. Открывают картинку в текстовом режиме. Получают UnicodeDecodeError — разбираем.
  3. Забывают закрыть файл и думают, что данные сохранились. Всегда with, напоминаю.
  4. seek(-1) без флага в текстовом режиме — ошибка. Показываю, переходим в rb при необходимости.
  5. Не знают, где файлы лежат. Визит в проводник обязателен.
