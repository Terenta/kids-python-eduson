Урок 24

Проект: «Квиз в консоли» + генерация вопросов

Отдел: 6. Интеграции Неделя: 24 Возраст: 8–14

Отдел: 6. Интеграции Неделя: 24 Возраст: 8–14

🎯 Цель

Собрать финальный проект модуля «Интеграции» и модулей 4–6 целиком: квиз, который читает вопросы из файла, ведёт счёт, сохраняет результат, использует функции, циклы и ИИ для генерации контента. Это первый проект, где ИИ — полноценный участник пайплайна.

📚 Результаты (из источника)

Ученик может: создавать функцию загрузки данных из файла; считывать данные из нескольких файлов в списки; использовать вложенные списки для опций; реализовать основной цикл с выводом вопросов и ответов; считывать ответы и сохранять в список; проверять ответы и подсчитывать очки; выводить результаты читаемо; сохранять результаты в файл; использовать ИИ для генерации текста; комбинировать функции, циклы, условия и файлы.

🛠️ Инструменты

GigaIDE (основной), Python 3.11, YandexGPT — для генерации базы вопросов, Kandinsky — для обложки квиза.

⚙️ Техтребования

Стандарт + подготовленный questions.txt шаблон формата:

Столица России?|Москва|Минск|Киев|Казань|1

(текст вопроса | 4 варианта | номер правильного).

🕐 Поминутный план (60 мин)

  • 0–5. Приветствие + разбор ДЗ (шифровальщик, лог). Демо готового квиза — запускаю, отвечаю на 3 вопроса, показываю итог.
  • 5–15. Теория-архитектура. Сначала на листе — структура:
  def load_questions(path): ...      # читает файл, возвращает список вопросов
  def ask_question(question): ...     # задаёт 1 вопрос, возвращает True/False
  def save_result(name, score): ...   # дописывает в results.txt
  def main(): ...

Формат файла questions.txt: одна строка на вопрос, разделитель |. Разбираем через split("|").

  • 15–45. Практика — сборка.

1. load_questions: open с r, readlines, split("|"), strip(), сбор списка словарей/кортежей.

2. Главный цикл: for q in questions: ask_question(q). Внутри — вывод вопроса, 4 вариантов, input, проверка.

3. Подсчёт очков, вывод «Результат: 7/10».

4. save_result(name, score) — дописывает в results.txt: «Макс — 7/10».

  • 45–55. Мини-проект — генерация вопросов через ИИ. Ребёнок пишет в Алису промпт: «Сгенерируй 10 вопросов для школьного квиза по космосу в формате: текст|вариант1|вариант2|вариант3|вариант4|номерправильного. Один вопрос в строке». Копирует, вставляет в questions.txt, запускает свой квиз. Работает!
  • 55–60. Защита проекта (3–5 мин). Бейдж «Хранитель файлов». Демо истории результатов (читаем results.txt). ДЗ (на модуль 7).

💬 Ключевые фразы преподавателя

  2. «Структуру проекта мы рисуем на бумаге ДО кода. Функции — заголовки глав».
  3. «Разделитель | в файле — удобно для split. Точка или запятая хуже — они встречаются в тексте».
  4. «Формат файла — это договор. Нарушил формат — квиз ломается. Всегда try/except вокруг парсинга».
  5. «load_questions возвращает список — это твой боевой актив. Каждый вопрос — кортеж или словарь».
  6. «ИИ — генератор вопросов. Твой код — движок квиза. Это разные роли».

  10. «Это твой 6-й бейдж. На курсе осталось меньше половины. Поздравляю».

🎨 Мини-проект

Весь урок = проект. Результат: рабочий консольный квиз на 10 вопросов, загружает из файла, сохраняет результат, имеет 4 функции минимум. Генерация вопросов через YandexGPT. Файлы: questions.txt, results.txt.

🏠 ДЗ (≤20 мин)

  1. Сгенерировать через Алису 2 новые темы квизов (динозавры, любимые фильмы), сохранить в questions_dinos.txt, questions_movies.txt. В main() — выбор темы.
  2. Добавить топ-3 результатов: читать results.txt, сортировать по score, выводить топ.
  3. Подготовить 3-минутную защиту модуля 6.

✅ Критерии успеха

Квиз запускается, читает из файла, задаёт вопросы, сохраняет результат. Код структурирован в 4+ функции. Ребёнок уверенно объясняет архитектуру и вклад ИИ.

⚠️ Сложности и решения

  1. Формат от Алисы сломан (лишние строки, текст, кавычки). Учим try/except при парсинге + ручная чистка.
  2. Пользователь вводит «1» вместо 1 (число). int(input()) с try/except ValueError.
  3. save_result перезаписывает — открыли с w. Чиним на a.
  4. Забыли encoding="utf-8" → вопросы на кириллице кракозябрами. Напоминаю правило.
  5. Все функции в одном файле — каша. Учим: всё, что не main(), идёт вверх; main() — вниз; вызов внизу через if __name__ == "__main__": main() — коротко знакомлю.

🎁 Бонус для опережающих

Режим «битва двух игроков»: ввод двух имён, чередование вопросов, в конце сравнение результатов, вывод победителя. Сохранение в battle_results.txt.

🤖 Где подключаем ИИ

Максимально активно. YandexGPT — основной генератор базы вопросов. Kandinsky — обложка квиза. Ребёнок формулирует промпт для генерации, проверяет и чистит результат, вставляет в файл. В защите отдельно объясняет: «Вот промпт, вот что вернулось, вот что я поправил, вот мой код». Это ключевое портфолио-умение для следующих курсов и для Vibe Coding Step 2.
