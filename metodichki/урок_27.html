Урок 27

Как работать со словарями

Отдел: Проектирование структур. Неделя: 7. Возраст: 8–14.

Отдел: Проектирование структур. Неделя: 7. Возраст: 8–14.

🎯 Цель

Открыть ребёнку самую мощную структуру данных Python — словарь. Показать, что это ключ → значение, как настоящий словарь, телефонная книга или карточка героя в игре.

📚 Результаты (из источника)

Ученик понимает:

— что такое словарь и как он хранит пары ключ → значение;

— что ключи должны быть уникальными, а значения могут повторяться;

— как создавать словари с помощью фигурных скобок;

— как получать значение по ключу;

— что словарь можно изменять: добавлять, удалять и изменять пары;

— методы словарей: keys(), values(), items(), get();

— что словари удобны для структурированных данных (контакты, оценки).

Ученик может:

— создавать словари;

— получать значения по ключу;

— добавлять и изменять пары ключ-значение;

— удалять элементы из словаря;

— перебирать словарь с помощью цикла for;

— использовать словари для хранения и поиска структурированных данных.

🕐 Поминутный план (60 мин)

  • 0–5. Проверка ДЗ по множествам. Демо: программа «Карточка героя» — вводишь «маг», показывает HP, MP, урон.
  • 5–15. Теория. Метафора: бумажный словарь. Слово — ключ, перевод — значение. hero = {"name": "Маг", "hp": 100, "mp": 80}. Показываем hero["name"]. Плюс — словарь как карточка в настоящей игре.
  • 15–25. Совместный кодинг. Создаём словарь-справочник «Русский → Английский». Показываем три способа получить значение: d["cat"], d.get("cat"), d.get("tiger", "нет в словаре"). Объясняем, почему get безопаснее.
  • 25–45. Самостоятельная задача. Программа «Мои друзья». Ключ — имя, значение — возраст. Пользователь может: добавить друга, посмотреть возраст, удалить, показать всех через цикл for name, age in friends.items().
  • 45–55. Разбор + усложнение. Словарь словарей: heroes = {"Маг": {"hp": 100, "mp": 80}, "Воин": {"hp": 150, "mp": 20}}. Достаём heroes["Маг"]["hp"]. Здесь же — YandexGPT генерирует словарь столиц: «Россия» → «Москва», 10 стран.
  • 55–60. Итог. 3 пункта: словарь — ключ/значение; {} с парами через двоеточие; .get() безопаснее []. ДЗ — «Моя коллекция».

💬 Ключевые фразы преподавателя

  1. «Словарь — как настоящий толковый словарь: слово — объяснение».
  2. «Ключ уникальный, значение — любое».
  3. «Хочешь карточку персонажа в игре? Словарь идеален».
  4. «Пиши пары через двоеточие: "hp": 100, а не равно».
  5. «d["x"] падает, если ключа нет. d.get("x") возвращает None».
  6. «.keys() — все ключи, .values() — все значения, .items() — пары».
  7. «Цикл for key, value in d.items(): запомни, ты будешь писать его миллион раз».
  8. «Значением может быть что угодно — число, строка, список, даже другой словарь».
  9. «Ключом обычно берут строку, иногда число. Список ключом быть не может».
  10. «Все настоящие игры хранят героев в словарях или объектах — мы почти там».

🎨 Мини-проект

«Записная книжка». Меню из 4 пунктов: добавить контакт, найти телефон, удалить, показать всех. Сохраняем в словарь contacts = {}.

contacts = {}
while True:
    cmd = input("1-доб, 2-найти, 3-удалить, 4-все, 0-выход: ")
    if cmd == "1":
        name = input("Имя: ")
        phone = input("Телефон: ")
        contacts[name] = phone
    elif cmd == "2":
        name = input("Чьё? ")
        print(contacts.get(name, "Нет такого"))
    elif cmd == "0":
        break

🏠 ДЗ (≤20 мин)

«Моя коллекция». Создать словарь из 5 любимых игр (ключ — название, значение — оценка 1–10). Вывести красиво через цикл. Бонус: попросить YandexGPT назвать жанр каждой игры и добавить как второй словарь.

✅ Критерии успеха

Ребёнок создаёт словарь, читает по ключу, добавляет пару, перебирает через .items(), различает [] и .get().

⚠️ Сложности и решения

  • Пытается получить по индексу d[0]. Объясняем: индексов нет, только ключи.
  • Забывает двоеточие внутри пары. Смотрим SyntaxError вместе.
  • Делает одинаковые ключи и удивляется потере данных. Показываем, что второе значение затёрло первое.
  • Путает .keys() и .values(). Рассказываем мнемонику: «keys сверху, values снизу» — как в карточке.
  • for x in d даёт ключи — ребёнок ждёт пару. Объясняем: для пар нужен .items().

🎁 Бонус

Звёздная задача: парсинг расписания. Словарь {"пн": ["матем", "русский", "ИЗО"], "вт": ["физра", "англ"]}. Пользователь вводит день — программа выводит уроки по порядку.
