🕐 Поминутный план (60 мин)

  • 0–5. Демо готовой «Виселицы» у преподавателя. Ребёнок видит цель.
  • 5–15. Разбор архитектуры на листочке. words — кортеж слов (неизменяемый). secret — случайное из них. guessed — множество угаданных букв. stats — словарь {"победы": 0, "поражения": 0}. Рисуем поток: выбор слова → пока есть жизни → буква → проверка → обновление.
  • 15–25. Совместный кодинг. Пишем функцию show(word, guessed) — возвращает строку «к _ т _ к». Пишем выбор слова через random.choice.
  • 25–45. Самостоятельная задача. Ребёнок пишет главный цикл while: жизни (6), ввод буквы, валидация, обновление множества, условия победы/поражения. Преподаватель помогает наводящими.
  • 45–55. Тесты и фиксы. Играем 2 раза. Зовём YandexGPT: «объясни вот этот баг» / «помоги написать красивую функцию вывода виселицы ASCII-артом».
  • 55–60. Генерация презентации через ИИ. Промпт: «Напиши короткую презентацию из 5 слайдов про мою игру "Виселица" на Python для ребёнка 12 лет. Выдели, что я использовал множество, словарь, кортеж». Защита — 2 минуты. ДЗ — добавить темы слов.

💬 Ключевые фразы преподавателя

  1. «Это капстоун отдела — проверка, что ты ВСЁ понял».
  2. «Сначала план на бумаге, потом код. Всегда».
  3. «Слова — кортеж, потому что список слов не должен меняться во время игры».
  4. «Угаданные буквы — множество, чтобы нельзя было засчитать одну букву дважды».
  5. «Статистика — словарь: "победы" → число, "поражения" → число».
  6. «random.choice(words) вернёт одно случайное слово».
  7. «Если игрок уже вводил букву — скажи ему, не наказывай жизнью».

  9. «Повесил? Покажи слово целиком, пусть ребёнок увидит, что ему загадали».
  10. «В конце обязательно спроси — ещё раз? И обновляй словарь статистики».

🎨 Мини-проект

Файл hangman.py, ~70–100 строк.

import random

WORDS = ("python", "кортеж", "множество", "словарь", "виселица")

def play():
    secret = random.choice(WORDS)
    guessed = set()
    lives = 6
    while lives > 0:
        shown = " ".join(c if c in guessed else "_" for c in secret)
        print(shown, f"жизни: {lives}")
        if "_" not in shown:
            print("Победа! Слово было:", secret); return True
        letter = input("Буква: ").lower().strip()
        if letter in guessed:
            print("Уже было"); continue
        guessed.add(letter)
        if letter not in secret:
            lives -= 1
    print("Поражение. Слово было:", secret)
    return False

stats = {"победы": 0, "поражения": 0}
while True:
    if play(): stats["победы"] += 1
    else: stats["поражения"] += 1
    print(stats)
    if input("Ещё? д/н: ") != "д": break

🏠 ДЗ (≤20 мин)

Добавить темы слов: словарь {"животные": (...), "города": (...)}, игрок выбирает тему. Запросить у YandexGPT 20 слов по каждой теме.

✅ Критерии успеха

Игра запускается, не падает на повторных буквах, корректно завершается победой/поражением, статистика копится.

⚠️ Сложности и решения

  • Забывает .lower() — игрок ввёл «А», слово — «а». Разбираем.
  • Не учитывает повтор буквы — тратятся жизни зря. Чиним через if letter in guessed.
  • random.choice на списке одного элемента — работает, ребёнок боится. Успокаиваем.
  • Путает множество и список. Напоминаем: дубликаты нам не нужны.
  • Пишет бесконечный цикл без break. Ctrl+C + разбор.
