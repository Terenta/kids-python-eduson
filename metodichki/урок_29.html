Урок 29

Что такое ООП, класс и объект

Отдел: Классы. Неделя: 8. Возраст: 8–14.

Отдел: Классы. Неделя: 8. Возраст: 8–14.

🎯 Цель

Ввести самую «взрослую» концепцию курса — объектно-ориентированное программирование — через метафору. Научить писать первый класс, создавать объекты, задавать атрибуты и методы.

📚 Результаты (из источника)

Ученик понимает:

— что такое объектно-ориентированное программирование и зачем оно нужно;

— что такое класс как шаблон для создания объектов;

— что такое объект как экземпляр класса;

— что объект хранит свойства (атрибуты) и умеет выполнять действия (методы);

— разницу между классом и объектом.

Ученик может:

— создавать простой класс;

— создавать объект класса;

— присваивать значения атрибутам объекта;

— вызывать методы объекта;

— использовать объекты для моделирования простых предметов или персонажей.

🛠️ Инструменты

GigaIDE, Colab. YandexGPT — для объяснения, «зачем вообще классы».

⚙️ Техтребования

Python 3.11+.

🕐 Поминутный план (60 мин)

  • 0–5. Разбор ДЗ к «Виселице». Демо: класс Dog — создаём двух собак, у каждой своё имя и голос.
  • 5–15. Теория через метафору. Класс — чертёж дома, объект — дом по этому чертежу. По одному чертежу можно построить много домов, разных цветов и этажности. Показываем: до ООП мы хранили героя в словаре, теперь — в классе.
  • 15–25. Совместный кодинг. Пишем:
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    def bark(self):
        print(f"{self.name} говорит: Гав!")

rex = Dog("Рекс", 3)
bim = Dog("Бим", 1)
rex.bark(); bim.bark()

Объясняем self — «эта собака, к которой мы обращаемся». Объясняем __init__ — «рождение объекта».

  • 25–45. Самостоятельная задача. Создать класс Student: имя, класс, оценки (список). Метод average() — средняя оценка, метод introduce() — «Меня зовут ..., я учусь в ... классе».
  • 45–55. Разбор. Разница между классом и объектом повторяется трижды разными словами. Зовём YandexGPT: «объясни, что такое self, ребёнку 10 лет».
  • 55–60. Итог. 3 пункта: класс — чертёж, объект — конкретная вещь, self — эта конкретная вещь. ДЗ — «Книга в библиотеке».

💬 Ключевые фразы преподавателя

  1. «Класс — это чертёж, объект — здание по чертежу».
  2. «По одному чертежу строим много зданий — по одному классу создаём много объектов».
  3. «Атрибут — это что у объекта ЕСТЬ. Метод — что объект УМЕЕТ делать».
  4. «self — это слово "я" для объекта. self.name — "моё имя"».
  5. «__init__ — конструктор, момент рождения объекта».
  6. «Ты пишешь класс один раз, а объектов можешь сделать хоть 100».
  7. «Словари — хорошо, но классы — ещё лучше, когда у вещи есть действия».
  8. «Имя класса с большой буквы: Dog, а не dog».
  9. «Метод — это функция внутри класса, первый параметр всегда self».
  10. «Скоро ты напишешь Тамагочи — реально живого питомца в коде».

🎨 Мини-проект

Класс Student с 3 объектами, вывод списка с средними оценками.

🏠 ДЗ (≤20 мин)

Класс Book: название, автор, страницы. Метод info(). Создать 3 книги, вывести их. Бонус — попросить YandexGPT сгенерировать 5 классических книг с автором для списка.

✅ Критерии успеха

Ребёнок пишет class X: с __init__ и одним методом, создаёт 2 объекта, вызывает метод, различает класс и объект на слух.

⚠️ Сложности и решения

  • Забывает self в методе. Показываем TypeError, запоминаем.
  • Пишет name = "Рекс" внутри класса, ожидая атрибут. Объясняем разницу между атрибутом класса и экземпляра.
  • Не вызывает метод — rex.bark вместо rex.bark(). Объясняем, что без скобок — это просто указание на функцию.
  • Путает __init__ с init. Двойные подчёркивания обязательны.
  • «Зачем это всё, если есть словари?» Отвечаем: методы — действия вместе с данными.

🎁 Бонус

Добавить в класс Dog метод birthday(), который увеличивает возраст на 1. Это первый переходик к «изменение состояния через метод».
