Урок 30

Как работают инкапсуляция, наследование и полиморфизм

Отдел: Классы. Неделя: 8. Возраст: 8–14.

Отдел: Классы. Неделя: 8. Возраст: 8–14.

🎯 Цель

Познакомить с тремя «страшными» словами ООП, разложив их на детские понятия. Наследование — как родственники, полиморфизм — как разговор на одном языке, инкапсуляция — как личный дневник с замочком.

📚 Результаты (из источника)

Ученик понимает:

— что такое инкапсуляция — скрытие деталей реализации и защита данных;

— как создавать закрытые атрибуты и методы с помощью _ и __;

— что такое наследование — создание нового класса на основе существующего;

— как дочерний класс получает атрибуты и методы родительского класса;

— что такое полиморфизм — объекты разных классов имеют одинаковые методы, но выполняют их по-своему;

— зачем эти принципы нужны для упрощения и организации кода.

Ученик может:

— использовать закрытые атрибуты и методы;

— создавать дочерние классы, наследующие свойства родителя;

— переопределять методы в дочерних классах (полиморфизм);

— писать программы с простыми иерархиями классов (транспорт → автомобиль/велосипед).

🕐 Поминутный план (60 мин)

  • 0–5. Повторение: что такое класс и объект. Демо: два класса-наследника (Cat, Dog) с общим предком Animal.
  • 5–15. Теория.

Наследование. Семья: от папы-Animal унаследовали метод eat(). Пишем class Cat(Animal):.

Полиморфизм. Оба умеют speak(), но кот говорит «мяу», пёс — «гав». Одно слово, разные действия.

Инкапсуляция. У каждого есть личный дневник _diary (предупреждение «лучше не трогай») и секретный __password (скрывается через name mangling).

  • 15–25. Совместный кодинг.
class Animal:
    def __init__(self, name):
        self.name = name
    def eat(self):
        print(f"{self.name} ест")
    def speak(self):
        print("...")

class Cat(Animal):
    def speak(self):
        print(f"{self.name}: мяу")

class Dog(Animal):
    def speak(self):
        print(f"{self.name}: гав")

for a in [Cat("Барсик"), Dog("Рекс")]:
    a.eat(); a.speak()
  • 25–45. Самостоятельная задача. Иерархия транспорта. Vehicle → Car, Bike. У каждого свой метод move(). Добавить приватный _fuel и метод refuel().
  • 45–55. Разбор. Показываем, что цикл for a in animals работает одинаково и для котов, и для собак — это и есть сила полиморфизма.
  • 55–60. Итог. 3 пункта: наследование — родственники; полиморфизм — один метод, разное поведение; инкапсуляция — защита данных. ДЗ.

🎨 Мини-проект

🏠 ДЗ (≤20 мин)

Создать Vehicle с методом move(), два наследника Car и Bike с переопределением. Добавить приватный _speed. Бонус — попросить YandexGPT придумать 3 необычных транспорта и сделать для них классы.

✅ Критерии успеха

Пишет класс-наследник, переопределяет метод, понимает, что _ — договорённость, а __ — сильнее.

⚠️ Сложности и решения

  • Забывает вызвать super().__init__(). Атрибуты родителя теряются — разбираем.
  • Думает, что _ реально запрещает доступ. Объясняем: это только соглашение.
  • Переопределяет метод с другим именем и удивляется, почему не работает. Должно быть точь-в-точь.
  • Путает метод класса и атрибут. Смотрим: метод — со скобками.
  • «А зачем три слова сразу?» — разбираем каждое по одной минуте отдельно.

🎁 Бонус

Три уровня иерархии: Animal → Mammal → Dog. Посмотреть, как наследование работает через несколько этажей.
