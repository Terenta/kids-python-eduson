Проект: «Игра-тамагочи с питомцем» + генерация видео

Отдел: Классы. Неделя: 8. Возраст: 8–14.

🎯 Цель

Капстоун отдела ООП. Ребёнок создаёт виртуального питомца с эмоциями, здоровьем, сытостью. Класс Pet, наследники Cat/Dog с переопределением. Игровой цикл «тик времени». В конце — видео-презентация питомца через ИИ.

📚 Результаты (из источника)

Ученик может:

— создавать простой класс с атрибутами и методами;

— создавать объекты класса и работать с ними;

— использовать атрибуты объектов для хранения состояния;

— вызывать методы объектов для выполнения действий;

— создавать наследуемый класс и добавлять новые методы;

— изменять состояние объекта через методы;

— использовать условные конструкции внутри методов;

— считывать текстовый ввод и сравнивать строки;

— комбинировать классы, объекты, методы и ввод/вывод.

🛠️ Инструменты

GigaIDE. YandexGPT + Kandinsky (https://fusionbrain.ai) — для генерации аватара питомца. YandexArt — для короткого видео-представления.

⚙️ Техтребования

Python 3.11+. Доступ к Kandinsky через браузер.

🕐 Поминутный план (60 мин)

  • 0–5. Демо готового Тамагочи у преподавателя. Смотрим: кормим, играем, укладываем спать — мимика меняется.
  • 5–10. Проект на бумаге. Атрибуты Pet: hunger (0–10), happiness, energy. Методы: feed, play, sleep, status, tick. Наследники: Cat (ленивый, меньше тратит энергии), Dog (активный, быстрее хочет играть).
  • 10–30. Совместный кодинг основного класса.
class Pet:
    def __init__(self, name):
        self.name = name
        self.hunger = 5
        self.happiness = 5
        self.energy = 5
    def feed(self):
        self.hunger = max(0, self.hunger - 3)
        print(f"{self.name} поел")
    def play(self):
        if self.energy < 2:
            print(f"{self.name} слишком устал"); return
        self.happiness = min(10, self.happiness + 2)
        self.energy -= 2
    def sleep(self):
        self.energy = 10
        print(f"{self.name} спит")
    def tick(self):
        self.hunger = min(10, self.hunger + 1)
        self.happiness = max(0, self.happiness - 1)
    def status(self):
        face = ":)" if self.happiness > 5 else ":("
        print(f"{self.name} {face} hunger={self.hunger} happ={self.happiness} energy={self.energy}")
  • 30–45. Самостоятельная задача. Ребёнок пишет Cat(Pet) и Dog(Pet) с разным поведением + главный цикл с меню: кормить/играть/спать/статус/выйти. После каждой команды вызывается tick().
  • 45–55. Тестируем, правим. Генерируем аватар питомца в Kandinsky: «милый мультяшный кот-тамагочи с большими глазами, 8-битный пиксель-арт». Сохраняем картинку в папку проекта.
  • 55–60. Генерируем короткое видео-представление через YandexArt или описание для YandexGPT. Защита 2 минуты. ДЗ — добавить Parrot.

💬 Ключевые фразы преподавателя

  1. «Тамагочи — это 4 отдела курса в одном проекте».
  2. «Каждое действие меняет состояние — это и есть живой объект».
  3. «tick() — время идёт, питомец хочет есть и грустит».
  4. «min и max удерживают значение в диапазоне 0–10».
  5. «Статус выводим строкой с эмодзи — пусть будет видно настроение».
  6. «Кот ленивее — пусть play() у него тратит меньше энергии».
  7. «Собака голоднее — пусть tick() у неё добавляет 2 к голоду, а не 1».
  8. «Меню — это while True с input. Классика».
  9. «Заключительный кадр — состояние питомца после 10 ходов».
  10. «Картинку для тамагочи сделаем через Kandinsky, это бесплатно и без VPN».

🎨 Мини-проект

Файл tamagotchi.py, 100–130 строк. Два питомца на выбор (кот или собака), консольное меню, реакции.

🏠 ДЗ (≤20 мин)

Добавить третьего наследника — Parrot. Особенность: метод talk(), который повторяет введённое слово. Сгенерировать ему аватар в Kandinsky.

✅ Критерии успеха

Программа запускается, меню работает, состояние меняется, хотя бы 2 класса-наследника работают, защита 2 минуты получается.

⚠️ Сложности и решения

  • Атрибуты вылезают за диапазон. Решение — min/max.
  • Забывает tick() — питомец вечно счастлив. Вставляем в конец каждой итерации.
  • Наследник не наследует __init__. Добавляем super().__init__(name).
  • «Слишком много кода, теряюсь». Делим файл комментариями: # ===== CLASS =====, # ===== GAME =====.
  • Kandinsky выдаёт «не то». Переписываем промпт, добавляя «пиксель-арт, 8-бит, чёрный фон».

🎁 Бонус

Сохранение состояния питомца в файл (pickle или JSON), загрузка при запуске — это мостик к модулю 9 и реальным приложениям.

🤖 Где подключаем ИИ

1) Kandinsky — аватар питомца. 2) YandexGPT — промпт для видео-презентации: «сгенерируй короткое описание видео (10 сек) для моего проекта Тамагочи: представь, что это реклама игры про виртуального кота. 3 фразы, весело, для детей». 3) YandexGPT — ревью кода перед сдачей.
