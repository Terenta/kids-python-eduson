Урок 34

ИИ-ассистенты в разработке: YandexGPT, Perplexity

Отдел: Искусственный интеллект. Неделя: 9. Возраст: 8–14.

Отдел: Искусственный интеллект. Неделя: 9. Возраст: 8–14.

🎯 Цель

Показать, как ИИ помогает писать код: объясняет ошибки, даёт подсказки, пишет шаблоны. Ввести базу prompt engineering для детей — «контекст, роль, формат».

📚 Результаты (из источника)

Ученик понимает:

— что такое ИИ-ассистент для разработки;

— какие задачи решают ассистенты вроде YandexGPT и Perplexity (генерация кода, подсказки, документация);

— как ИИ-ассистенты помогают экономить время разработчика;

— что ИИ-ассистент не заменяет разработчика полностью, а выступает как помощник;

— основные принципы взаимодействия: формулировка вопросов, проверка кода.

Ученик может:

— использовать ИИ-ассистентов для написания простого кода;

— проверять и корректировать код, предложенный ИИ;

— комбинировать работу ИИ с ручным программированием;

— объяснять, какие задачи лучше решать с помощью ИИ.

🛠️ Инструменты

YandexGPT (ya.ru/alisa), GigaChat (giga.chat), Perplexity (perplexity.ai), GigaIDE Desktop.

⚙️ Техтребования

Браузер + IDE для проверки.

🕐 Поминутный план (60 мин)

  • 0–5. Проверка ДЗ-эссе. Демо: ребёнок даёт плохой промпт «напиши код» vs хороший промпт — получаем небо и землю.
  • 5–20. Теория. Формула промпта для детей: КОНТЕКСТ + РОЛЬ + ЗАДАЧА + ФОРМАТ.

- Контекст: «Я учусь Python, мне 12 лет».

- Роль: «Ты — добрый учитель программирования».

- Задача: «Объясни ошибку IndexError: list index out of range».

- Формат: «Сначала простыми словами, потом пример. Не больше 5 строк».

Показываем плохой промпт («помоги») и хороший — сравниваем ответы.

  • 20–40. Практика. 5 задач с ИИ-ассистентом:

1. Объяснить ошибку из своего старого проекта.

2. Попросить сгенерировать 10 имён героев для игры.

3. Попросить написать функцию is_prime(n) и САМОМУ проверить её.

4. Попросить Perplexity найти документацию по random.sample (с ссылкой на python.org).

5. Попросить YandexGPT придумать 3 варианта усложнения для Тамагочи.

  • 40–55. Разбор и анти-паттерны. Когда ИИ врёт: несуществующие методы, устаревший синтаксис, неправильный импорт. Проверяем ВСЁ, что ИИ выдал, запуском в IDE.
  • 55–60. Итог. 3 правила: КРФЗ-формула, проверяй запуском, «своим мозгом сначала». ДЗ — багфикс.

💬 Ключевые фразы преподавателя

  1. «ИИ-ассистент — как друг-старшеклассник, который пишет код. Иногда ошибается».
  2. «Плохой промпт = плохой ответ. Мусор на входе — мусор на выходе».
  3. «Формула: КОНТЕКСТ, РОЛЬ, ЗАДАЧА, ФОРМАТ. Запомни эти 4 слова».
  4. «Всегда говори, что ты ребёнок 12 лет — ответ будет проще».
  5. «Perplexity даёт источники — не ленись, проверяй по ссылке».
  6. «Если ИИ дал код — запусти его. Работает? Хорошо. Нет? Разбирайся».
  7. «ИИ иногда придумывает методы, которых нет. Это называется галлюцинация».
  8. «Попроси объяснить построчно — это учит».
  9. «Никогда не отдавай ИИ пароли, адрес, телефон».
  10. «Правило: сначала 5 минут сам, потом ИИ».

🎨 Мини-проект

«Сборник промптов». Ребёнок делает документ из 10 своих лучших промптов для программиста на Python и сохраняет в Яндекс.Документах.

🏠 ДЗ (≤20 мин)

Взять свой код из проекта «Виселица» или «Тамагочи», попросить YandexGPT найти 3 улучшения (без переписывания). Применить хотя бы одно. Записать в комментарии # совет ИИ: ....

✅ Критерии успеха

Ребёнок пишет промпт по формуле КРФЗ. Обнаруживает и объясняет хотя бы одну галлюцинацию ИИ. Проверяет код ИИ запуском.

⚠️ Сложности и решения

  • Копирует код ИИ без проверки. Правило: запусти → убедись.
  • Даёт слишком короткие промпты. Тренируем длинные с контекстом.
  • Верит ИИ слепо. Каждый ответ — «а ты проверил?».
  • Пишет промпт по-английски, если боится. Разрешаем, но показываем, что русский работает отлично в YandexGPT.
  • Путает YandexGPT и Perplexity. Напоминаем: Perplexity — про факты с ссылками, YandexGPT — про генерацию и объяснение.

🎁 Бонус

Сравнить ответы YandexGPT и GigaChat на один и тот же сложный промпт. Кто лучше? Субъективно.

🤖 Где подключаем ИИ

Весь урок — ИИ-ассистенты для кода. Ребёнок пишет 5+ промптов, каждый проверяет результат.
