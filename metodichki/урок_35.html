Урок 35

ИИ-автокомплитеры, ИИ-IDE и ИИ-платформы

Отдел: Искусственный интеллект. Неделя: 9. Возраст: 8–14.

Отдел: Искусственный интеллект. Неделя: 9. Возраст: 8–14.

🎯 Цель

Показать следующий уровень ИИ — автокомплит прямо в редакторе и ИИ-IDE типа Cursor. Познакомить с платформой Lovable.dev / Readdy.ai как подготовкой к финальному проекту (урок 36).

📚 Результаты (из источника)

Ученик понимает:

— что такое автокомплитеры на базе ИИ и как они ускоряют написание кода;

— как работают ИИ-IDE и какие возможности они предоставляют (подсказки, рефакторинг, генерация тестов);

— что такое ИИ-платформы для обучения и разработки (например, Lovable);

— что ИИ-инструменты помогают изучать язык быстрее и проверять идеи;

— ограничения ИИ-платформ и необходимость контроля со стороны человека.

Ученик может:

— использовать автокомплитеры для ускорения написания кода;

— работать с ИИ-IDE для генерации, тестирования и отладки кода;

— применять ИИ-платформы для изучения Python или создания проектов;

— оценивать результат работы ИИ и корректировать.

🛠️ Инструменты

GigaIDE Desktop с ИИ-автокомплитом (встроенный GigaChat), Cursor (https://cursor.com), Lovable.dev, Readdy.ai.

⚙️ Техтребования

GigaIDE уже установлен. Cursor — demo-аккаунт. Lovable.dev — регистрация по Google/Яндекс через родителя.

🕐 Поминутный план (60 мин)

  • 0–5. Разбор ДЗ-багфикса. Демо: преподаватель печатает def fibo — GigaIDE дописывает функцию целиком.
  • 5–20. Теория и демонстрация.

ИИ-автокомплит. Это как T9, но умный. В GigaIDE после установки и входа в аккаунт Сбера — встроенный помощник. Печатаешь начало, жмёшь Tab — получаешь продолжение. Показываем.

ИИ-IDE. Cursor — редактор на базе VS Code с встроенным ИИ. Ctrl+K — «перепиши эту функцию». Ctrl+L — чат. Для детей — пока знакомство, основной редактор — GigaIDE.

ИИ-платформы. Lovable.dev и Readdy.ai — ты описываешь сайт словами, платформа генерирует HTML/CSS/JS. Для завтрашнего урока 36.

  • 20–40. Практика. Ребёнок в GigaIDE печатает начало кода («функция приветствия, которая спрашивает имя и возраст») — видит предложения. Принимает/отклоняет. Пишет 3 функции с автокомплитом, 3 — без, сравнивает ощущения.
  • 40–55. Заглядываем в Lovable.dev. Регистрация с родителем. Пишем первый промпт: «Создай простой сайт-визитку для школьника Пети, увлекающегося Python. Тёмный фон, зелёный акцент, секции: Обо мне, Проекты, Контакт». Смотрим, что получилось. Это разминка к уроку 36.
  • 55–60. Итог. 3 пункта: автокомплит ускоряет, не думает за тебя; ИИ-IDE — следующий уровень; платформы типа Lovable — для быстрого прототипа. ДЗ.

💬 Ключевые фразы преподавателя

  1. «Автокомплит — это быстрее, но ты всё равно должен понимать, что приняла IDE».
  2. «Никогда не принимай Tab не читая. Иногда ИИ подсовывает ерунду».
  3. «Cursor — взрослый редактор, мы играем. Рабочий инструмент — GigaIDE».
  4. «Ctrl+K — рефакторинг, Ctrl+L — чат. Запомни эти две комбинации в Cursor».
  5. «Lovable.dev — ты пишешь словами, он делает сайт. Волшебство».
  6. «Платформа = быстро, но результат надо чистить».
  7. «Хороший промпт для сайта = 3–5 секций + стиль + цвет + аудитория».
  8. «Завтра (урок 36) — твой сайт-визитка. Сегодня — репетиция».
  9. «Ты всё равно главный. ИИ — подмастерье».
  10. «Проверяй сгенерированный код запуском всегда».

🎨 Мини-проект

Мини-скетч сайта-визитки в Lovable.dev. Просто увидеть, ощутить, обсудить, что можно улучшить.

🏠 ДЗ (≤20 мин)

Написать на бумаге (или в заметках) план сайта-визитки, который будем делать завтра. 5 секций: имя, фото/аватар, обо мне, мои проекты Python (из курса), контакт. Собрать список своих проектов (Виселица, Тамагочи, и т.д.).

✅ Критерии успеха

Ребёнок пользуется автокомплитом в GigaIDE. Запускает Cursor хотя бы один раз. Открывает Lovable.dev и генерирует первый прототип.

⚠️ Сложности и решения

  • Слепо принимает все подсказки автокомплита. Тренируем — читай, потом Tab.
  • Cursor на английском пугает. Переключаем язык, показываем Ctrl+L.
  • Lovable генерирует не то. Переписываем промпт подробнее.
  • Регистрация через родителя — задержка. Готовим демо-аккаунт преподавателя.
  • «Зачем учиться, если ИИ всё пишет?» — показываем, что ИИ ошибается, ты должен уметь чинить.
