Знакомство с PyGame Zero + сквозной проект #1, часть 1

Отдел: Разработки Неделя: 19 Возраст: 8-14

Отдел: Разработки Неделя: 19 Возраст: 8-14

🎯 Цель

Показать ребёнку, что «настоящая игра» — это не магия, а две функции draw() и update(), которые вызываются 60 раз в секунду. За урок запустить окно, нарисовать фон и первый спрайт-корзинку сквозного проекта «Поймай яблоко».

📚 Результаты

Ученик знает, что такое PyGame Zero, чем он отличается от «взрослого» PyGame, какие части у игры (окно, логика, объекты), что такое игровой цикл. Ученик умеет создать файл game.py, задать WIDTH и HEIGHT, нарисовать фон через screen.fill() или картинкой, вывести спрайт через объект Actor, запустить всё командой pgzrun game.py.

🛠️ Инструменты

GigaIDE Desktop (основной), Python 3.11, pip install pgzero, Kandinsky (https://fusionbrain.ai) для фонового неба и картинки корзинки, YandexGPT для идеи вариации игры.

⚙️ Техтребования

Python 3.11 установлен ещё на уроке 1. Сегодня делаем pip install pgzero (pygame подтянется автоматически). Создаём папку basket_apple/ с подпапкой images/. В неё кладём 2 png: basket.png (корзинка) и background.png (небо+трава). Картинки — в Kandinsky, стиль «плоская детская иллюстрация, прозрачный фон, 200×200».

🕐 Поминутный план (60 мин)

0-5: разбор ДЗ с урока 36 (сайт-визитка), показ финальной игры «Поймай яблоко» в готовом виде — ученик видит, куда идём.

5-10: теория. Что такое игровой цикл, чем draw() отличается от update(), зачем 60 fps. Рисую на бумаге: «PyGame Zero 60 раз в секунду спрашивает — что нарисовать? что обновить?».

10-20: совместный кодинг. Пишем минимум: WIDTH = 800, HEIGHT = 600, пустая draw() со screen.fill('skyblue'). Запускаем через терминал pgzrun game.py. Окно открылось — первая победа.

20-35: идём в Kandinsky. Ребёнок сам формулирует промпт «корзина для яблок, вид спереди, мультяшная, прозрачный фон, 200×200». Сохраняем в images/basket.png. Создаём basket = Actor('basket'), в draw() вызываем basket.draw(), задаём basket.pos = (400, 520).

35-50: самостоятельно. Ребёнок добавляет второй Actor — облако на фоне, ставит на позицию (200, 100), подбирает картинку в Kandinsky. Проверка: в окне есть небо, корзинка внизу, облачко сверху.

50-58: усложнение. Добавляем в update() строку basket.x += 1 — корзинка поехала! Обсуждаем, почему так. Вводим переменную speed = 2 для скорости.

58-60: итог + ДЗ.

💬 Ключевые фразы преподавателя

«PyGame Zero — это тренажёр для игр, в настоящем PyGame надо писать в 3 раза больше кода». «draw() — рисует, update() — думает. Они дружат, но не лезут в дела друг друга». «Координата 0,0 — это верхний левый угол, а не как на уроке математики». «Если спрайт не видно, на 99% дело в пути к картинке — PyGame Zero сам ищет в папке images». «Actor — это такая волшебная коробка: знает свою картинку, свои координаты, свой угол». «Запускаем не через F5, а через терминал: pgzrun game.py». «Если написал в draw() print(...) — увидишь в консоли поток сообщений: это значит, draw() работает 60 раз в секунду». «Ошибка No such file — посмотри регистр: Basket.png и basket.png это разные файлы». «Никаких while True в PyGame Zero — за тебя уже написали». «Уже сейчас ты смотришь на игру так же, как инженеры в Riot Games».

🎨 Мини-проект / этап сквозного проекта

Сквозной проект #1, часть 1. Игра «Поймай яблоко»: экран 800×600, голубой фон, корзинка внизу по центру. Пока просто статичная сцена.

🏠 ДЗ (≤20 мин)

  1. Сгенерировать в Kandinsky свою картинку яблока (200×200, прозрачный фон) и положить в images/apple.png. 2. Добавить Actor яблока, поставить в точке (400, 50). 3. В update() сделать apple.y += 2 — яблоко должно падать. 4. Отправить скрин в чат курса.

✅ Критерии успеха

Ребёнок самостоятельно запускает pgzrun game.py. На экране — фон, корзинка, облако. В update-цикле есть минимум одно изменение координаты. Ребёнок объясняет словами, что делает draw() и что — update().

⚠️ Сложности и решения

«Не запускается, пишет pgzrun не найден» — python -m pgzero game.py, либо проверяем, что папка Python добавлена в PATH. «Спрайт огромный/крошечный» — Kandinsky рисует 1024×1024, надо пересохранить в 200×200 через Paint или прямо на платформе. «Картинка с фоном, а не прозрачная» — в промпте жёстко «transparent background, PNG». «Ошибка ModuleNotFoundError: pgzero» — установка в не ту версию Python, смотрим python --version.

🎁 Бонус

«Звёздная задача»: сделать так, чтобы корзинка плавно качалась влево-вправо синусоидой (math.sin(...)) — это опережает урок 17-20, но мотивированные дети справляются.
