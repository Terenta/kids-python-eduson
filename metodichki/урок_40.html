Урок 40

Как добавлять игровые состояния в PyGame Zero + сквозной проект #1, часть 4

Отдел: Разработки Неделя: 20 Возраст: 8-14

Отдел: Разработки Неделя: 20 Возраст: 8-14

🎯 Цель

Завершить сквозной проект #1. Добавить игровые состояния (меню / игра / пауза / проигрыш), счёт, жизни. Ребёнок получает ПОЛНОЦЕННУЮ игру, которую можно защитить.

📚 Результаты

Ученик знает, что «игровое состояние» — это строковая переменная, которая определяет поведение draw() и update(). Понимает паттерн if game_state == 'playing': .... Умеет рисовать текст через screen.draw.text(), обрабатывать клавишу «пробел» для старта и паузы.

🛠️ Инструменты

GigaIDE, Python 3.11, PyGame Zero, Kandinsky для фонов меню и экрана проигрыша, YandexGPT для текстов-подсказок на экране.

⚙️ Техтребования

Файл game.py. Добавляем images/menu_bg.png и images/gameover_bg.png.

🕐 Поминутный план (60 мин)

0-5: разбор ДЗ. Смотрим 3 случайных вида яблок у разных учеников.

5-15: теория. Рисую на доске «карту состояний»: menu → playing → paused → gameover → menu. Объясняю, что одна и та же функция draw() может выглядеть по-разному в зависимости от состояния.

15-30: совместный кодинг. Вводим переменную game_state = 'menu', score = 0, lives = 3. Переписываем draw() — первым делом if game_state == 'menu': ...; elif game_state == 'playing': .... Для меню: фон + надпись «Нажми ПРОБЕЛ чтобы начать». Обработчик on_key_down(key): если key == keys.SPACE и состояние menu — переход в playing.

30-45: самостоятельно. Ребёнок реализует логику проигрыша: если золотое яблоко пропущено (ушло за нижний край), lives -= 1. Если lives == 0 — game_state = 'gameover'. На экране проигрыша — счёт и надпись «Пробел — заново».

45-55: усложнение. Пауза: клавиша P. В паузе — рисуется полупрозрачный экран, update() пропускает логику. Счёт отображается в playing в углу: screen.draw.text(f'Score: {score}', (10, 10), color='white', fontsize=40).

55-60: итог + защита сквозного проекта #1 (2-3 минуты). Ребёнок показывает игру и получает бейдж «Первый геймдев».

💬 Ключевые фразы преподавателя

«Состояние — это как настроение игры. В меню игра „спит“, в playing — „бежит“, в gameover — „плачет“». «Один экран — одна ветка if/elif». «Счёт — это просто число, которое растёт на +1 при ловле». «Жизни — тоже число, только идёт вниз». «Чтобы перезапустить игру, не перезапускаем программу — просто обнуляем переменные». «Текст в PyGame Zero: screen.draw.text, три аргумента — что, куда, каким цветом». «Теперь у тебя настоящая игра с меню, как в Steam».

🎨 Мини-проект / этап сквозного проекта

Сквозной #1, часть 4 — ФИНАЛ. Игра: меню → игра с падающими яблоками, счётом и тремя жизнями → экран проигрыша → рестарт. Всё на мыши и пробеле. Этот проект — один из 10 в портфолио.

🏠 ДЗ (≤20 мин)

  1. Добавить сохранение рекорда в файл highscore.txt (навык из урока 22). 2. На экране gameover вывести «Рекорд: N». 3. Записать 1-минутное видео с демонстрацией всех состояний и отправить в чат.

✅ Критерии успеха

Игра переключается между 4 состояниями. Счёт и жизни работают корректно. Проигрыш и рестарт без перезапуска программы. Защита 2 мин — ребёнок объясняет структуру состояний.

⚠️ Сложности и решения

«При рестарте яблоки остались от прошлой игры» — забыли обнулить apples.clear(). «Счёт не растёт» — score += 1 пишут внутри цикла удаления яблок, но после apples.remove, и print не срабатывает. Разбираем. «Текст не виден» — цвет совпадает с фоном.

🎁 Бонус

«Звёздная задача»: добавить таймер «выжить 60 секунд» — новое условие победы, game_state = 'win'.
