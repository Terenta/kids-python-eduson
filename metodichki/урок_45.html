Разработка итогового проекта, часть 1

Отдел: Финальный проект Неделя: 23 Возраст: 8-14

Отдел: Финальный проект Неделя: 23 Возраст: 8-14

🎯 Цель

Запустить финальный проект. Выбрать тему, декомпозировать её, завести репозиторий (или папку с версиями), написать прототип — «палки и камни», неглубоко, но работающий от начала до конца.

📚 Результаты

Ученик умеет выбрать реалистичную тему под оставшиеся 3 урока, разбить её на 5-7 подзадач, оценить сложность. Ученик знает, что такое MVP (minimum viable product) — первая версия без украшательств. Ученик завёл папку проекта с README.md, где описана идея и список задач.

🛠️ Инструменты

GigaIDE, Python 3.11, PyGame Zero (или tkinter — для не-игровых проектов: тренажёр, калькулятор, мини-приложение), YandexGPT для мозгового штурма идей и декомпозиции, GitHub Classroom (для 14+) или Yandex Disk (с согласия родителей).

⚙️ Техтребования

Папка final_project_<имя>/ в родительской eduson_kids/. Внутри: main.py, README.md, images/, sounds/ (если игра), notes.md (собственный дневник ошибок и идей).

🕐 Поминутный план (60 мин)

0-10: мозговой штурм. Вместе с ребёнком (или группой) обсуждаем идеи. Примеры для 8-10 лет: игра «космический спасатель», «котик на уроке» (уклоняется от родителей), «собери овощи». Для 11-14: квиз с таблицей лидеров, симулятор ухода за растением, платформер с 3 уровнями, тренажёр таблицы умножения. Используем YandexGPT для «дай мне 10 идей игр для python pygame zero уровень школьник».

10-20: выбор + декомпозиция. Ребёнок выбирает ОДНУ тему. На бумаге пишем 5-7 пунктов: «1) окно и фон; 2) главный герой; 3) препятствия/задания; 4) счёт; 5) экран проигрыша; 6) музыка; 7) меню». Обсуждаем, что реалистично успеть за 3 урока.

20-30: оформление README.md. Шаблон: «Название», «Идея (2 предложения)», «Как играть», «План задач (галочками)», «ИИ помогает (что сгенерировал сам, что ИИ)». Это будет артефактом защиты.

30-55: первый прототип. Ребёнок пишет скелет: окно открывается, есть главный объект, есть базовый ввод. НЕ графика, НЕ звук — только логика. Преподаватель — рядом, помогает наводящими вопросами.

55-60: итог. Ставим цель на урок 46: «К следующему занятию прототип должен играться хотя бы 30 секунд».

💬 Ключевые фразы преподавателя

«Лучше простая доделанная игра, чем сложная недоделанная». «Сначала думаем на бумаге, потом в коде — сэкономим час». «MVP — это минимально играбельная версия, без украшательств. Сначала сделай скелет». «Если идея требует 500 строк — режем пополам, потом ещё пополам». «Документ README — это твоя памятка и визитка для защиты». «У тебя есть 4 урока: сегодня — скелет, ещё 2 — мясо, последний — демо». «Спросить ИИ „дай 10 идей“ — это нормально. Спросить „напиши мне игру“ — нет».

🎨 Мини-проект / этап сквозного проекта

Финальный проект, этап 1. На выходе урока: папка проекта, README.md, скелет кода (30-50 строк), открытое окно с главным персонажем.

🏠 ДЗ (≤20 мин)

  1. Сгенерировать 3-4 главных спрайта в Kandinsky по теме. 2. Положить в images/. 3. Подключить главный спрайт в игре вместо фигуры. 4. Написать в notes.md три вопроса/сложности для урока 46.

✅ Критерии успеха

Тема выбрана и записана в README. План из 5-7 пунктов есть. Скелет кода запускается, показывает окно и базовый объект. Ребёнок может за 30 секунд объяснить идею игры.

⚠️ Сложности и решения

«Хочу сделать GTA» — мягко возвращаем к реальности, предлагаем «мини-GTA на одной карте с одним заданием». «Не могу выбрать» — голосуем в мини-группе или бросаем монетку. «Сделал на 30 минут, дальше не знаю что» — возвращаемся к декомпозиции, берём следующий пункт.

🎁 Бонус

Для двух-трёх мотивированных детей в мини-группе — возможность парной разработки: один пишет логику, второй делает графику и звук. Опыт командной работы.

🤖 Где подключаем ИИ

YandexGPT — мозговой штурм идей и помощь с декомпозицией («помоги разбить идею „Котик на уроке“ на 6 задач для программирования»). Kandinsky — генерация персонажа и фона.
