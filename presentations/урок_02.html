Переменные помогают Python хранить информацию

Переменная — это имя, которое мы даём значению, как бирку с надписью. Это нужно, чтобы не писать одно и то же число много раз в программе — достаточно использовать его имя.

Например, если написать age = 10, то дальше можно просто писать age, и программа сама подставит число 10.

В переменных могут быть не только числа, но и другие типы данных, например, текст.

age = 14    # Программа запомнит, что возраст пользователя — 14 лет

Как создать переменную

Используйте знак =. Слева напишите имя переменной, справа — значение.

Имя_переменной = значение

Например — age = 11 — переменной age присвоено значение 11.

age = 14    # Программа запомнит, что возраст пользователя — 14 лет

Значение в переменных можно изменять

Напишите имя переменной и новое число, чтобы изменить её значение. Например: height = 185. Теперь height указывает на это число.

Python
height = 172 height = 185 print(height)

Переменные нужно называть понятно

Разработчики договорились использовать единые правила языка Python. Он называется PEP8. Это документ, в котором описали, как нужно писать код на Python. Документ помогает программистам легко читать код друг друга.

VbeR = 5

Не понятно, что означает эта переменная.

age = 11

Теперь понятно, что в переменной лежит значение возраста.

Изучите первое правило PEP8

Пишите названия переменных маленькими буквами. Если название состоит из нескольких слов, их разделяют символом _, чтобы текст не сливался. Этот стиль называется snake_case.

Изучите, как правильно называть переменные на snake_case:

  • ✅  player_speed, age — это правильные названия переменных
  • ❌  PlayerSpeed — такие названия используют для классов, а не переменных
  • ❌  playerspeed — два слова слились в одно, такие переменные сложно читать

Изучите второе правило PEP8

Называйте переменные понятно. Имя переменной подсказывает, какие данные она хранит. Избегайте названий из одной буквы, чтобы другие люди понимали, что лежит в переменной.

Изучите примеры названия переменных:

  • ✅  age = 100 — другие разработчики поймут, что это возраст
  • ❌  a = 100, x = 5 — придётся гадать, что это за переменные
  • ❗  x, y, i — в математических задачах можно использовать

Изучите третье правило PEP8

Python различает большие и маленькие буквы. Для компьютера Level и level — это две разные переменные. Пишите имя переменной всегда одинаково.

Если вы создали переменную score, а потом используете Score, то программа выдаст ошибку или неверный результат.

score = 100
print(score) # 100 ✅

score = 100
print(Score) # NameError ❌

Изучите четвёртое правило PEP8

  • Нельзя начинать имя с цифры. Например, 1var не подойдёт, а var1 — подойдёт.
  • Нельзя использовать специальные символы: @, #, $, % или пробелы.
  • Нельзя использовать зарезервированные слова Python — он знает, что они означают.

Зарезервированные слова Python (использовать как имена переменных нельзя):

if   for   while   def   class   True   False   None   and   or   not

Если попробуете назвать переменную зарезервированным словом, программа выдаст ошибку.

Какие есть типы данных

В переменных могут храниться целые числа, дробные числа, слова и другие типы данных — например, списки или значения True и False.

Python определяет тип переменной по тому, что в неё записали. Если написать age = 10, то переменная будет ссылаться на целое число. Если написать name = "Саша", то переменная будет ссылаться на строку.

Одна и та же переменная может сначала хранить число — слово, если вы присвоите ей новое значение другого типа.

Переменным с целыми числами Python присваивает тип int

Integer, или int — это целое число. Этот тип данных означает, что в переменной лежит число без дробной части. Например: 1, 2, 3.

Вы также можете использовать этот тип, чтобы создать переменные для счётчиков, уровней или количества предметов. Например — level = 1, xp = 500.

age = 120    # В переменной лежит целое число — 120. Это переменная типа Integer

Переменным с дробными числами Python присваивает тип float

Float, или float — это число с плавающей точкой. Этот тип данных означает, что в переменной лежит дробное число. Разделителем целой и дробной части всегда является точка, а не запятая. Например — speed = 5.5, pi = 3.14.

damage = 15.5    # В переменной damage (урон) лежит число 15.5

Как перезаписать переменную

Вы можете сначала записать в переменную дробное число, а потом — целое. Переменная начнёт указывать на новое значение, и её тип изменится.

Например: x = 3.5, а потом x = 10 — теперь x указывает на целое число.

Python
speed = 5.5 # дробное число 5,5 speed = 5 # теперь целое число 5 print(speed)

Вы можете менять объект, на который ссылается переменная

Вы можете менять значение переменной сколько угодно раз. В Python имя может в разное время ссылаться на объекты разных типов.

Python
x = 5 print(x) x = 10 print(x) x = 100 print(x)

Код три раза меняет значение переменной X. Сначала переменная ссылалась на число 5, потом на 10, в конце на 100.

Переменная типа str, или string, ссылается на текст

String или строка — это цепочка символов. На языке Python переменные типа str используют, чтобы сослаться на текст.

Если значение переменной в кавычках — значит она ссылается на текст. В кавычках можно писать что угодно: буквы, цифры и знаки.

Python
name = "Алиса" # строка — переменная ссылается на текст «Алиса» message = "Error 404" # тоже строка, хотя содержит цифры print(name) print(message)

Переменная типа bool, или boolean, ссылается на логическое значение

Переменную типа bool используют, чтобы ссылаться на логическое значение — истина или ложь. Иногда надо сохранить не число или текст, а ответ на вопрос: «Да» или «Нет».

Переменная типа bool имеет два значения:

  1. True, или истина
  2. False, или ложь
is_day = True  # Сейчас день? Да — переменная is_day ссылается на True

Значения переменных можно складывать, вычитать, умножать и делить

Есть четыре операции с числами:

  1. «+» — сложение
  2. «-» — вычитание
  3. «*» — умножение
  4. «/» — деление
Python
x = 10 result = x + 5 print(result)

Изучите, как делить числа в Python

Результат всегда становится дробным, если делить числа:

  • 10 / 2 = 5.0
  • 10 / 5 = 2.0
  • 10 / 3 = 3.333...

Если вам по задаче нужен результат в виде целого числа — используйте int(). Эта функция отбрасывает дробную часть.

Python
x = 10 y = x / 3 print(y) # дробное число print(int(y)) # целое — дробная часть отброшена

Изучите порядок арифметических действий

Python сначала умножает и делит, а потом складывает и вычитает числа — как в математике. Скобки () меняют порядок — что в скобках, то считается первым.

Python
damage = 50 bonus = 1.5 total = 15 + damage * bonus # сначала умножение, потом сложение print(total)

Нельзя складывать текст и число

Числа складывают с помощью знака «+», например, 2+2. Строки с помощью знака «+» склеивают, например, "Вова" + "Крут" — получится "ВоваКрут".

Строки и числа нельзя складывать — Python выдаст ошибку.

Python
x = "10" # x ссылается на текст «10» y = 5 # y ссылается на число 5 result = x + y # Ошибка! Python не знает, что делать print(result)

Как превратить строку в число

С помощью int() и str() можно преобразовать текст в число и число в текст. Это называется «приведение типов»:

  • int() — превращает в целое число
  • str() — превращает в текст
Python
x = "10" # x ссылается на текст «10» y = int(x) # текст «10» превратился в число 10 result = y + 5 # теперь работает! print(result)

Как делить нацело без остатка

В Python есть три оператора деления — «/», «//» и «%». Их используют, чтобы поделить с остатком, нацело или найти остаток.

Python
first = 130 / 60 # обычное деление — float: 2.166... second = 130 // 60 # целочисленное деление — 2 third = 130 % 60 # остаток от деления — 10 print(first) print(second) print(third)

Как делить с помощью «//»

Операция «//» возвращает результат деления без остатка. Операция поможет ответить на вопрос: «сколько целых раз одно число помещается в другое?»

Python
result = 17 // 5 # 5 помещается в 17 ровно 3 раза print(result)

5 × 3 = 15 → 17 − 15 = 2 (остаток). Переменная result ссылается на число 3.

Как делить с помощью «%»

Операция «%» возвращает то, что осталось после деления на целое число.

Python
result = 130 % 60 # остаток от деления 130 на 60 print(result)

Если разделить 130 на 60, целое число 60 поместится в 130 дважды. Разница между исходным числом и полученным результатом составляет 130 − 120 = 10. Переменная result ссылается на число 10.

Выполните практическое задание, чтобы закрепить материал

Задача: напишите программу, которая посчитает общую сумму для любого количества гостей. Запишите цену комбо в переменную, количество друзей — в другую переменную и рассчитайте итоговую сумму.

Домашнее задание: напишите программу, которая считает сумму

Представьте, что вы часто заказываете товары в интернет-магазине — то наклейки для ноутбука, то значки, то стикеры. Каждый раз нужно считать: сколько штук заказать и хватит ли денег с учётом доставки.

Задача: напишите программу, которая будет считать итоговую стоимость для любого товара и любого количества. Запишите цену одной наклейки, количество штук и стоимость доставки в переменные, а потом рассчитайте общую сумму.

Изучите алгоритм, чтобы решить задание

  1. Запишите цену одной наклейки в переменную. Например, 50 ₽.
  2. Запишите количество наклеек в переменную. Например, 3 шт.
  3. Запишите стоимость доставки в переменную. Например, 150 ₽.
  4. Посчитайте стоимость всех наклеек — цена × количество.
  5. Прибавьте стоимость доставки.
  6. Выведите итоговую сумму.
