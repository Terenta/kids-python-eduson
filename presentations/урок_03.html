Используйте команду print() для вывода текста

  • Команда print() выводит информацию на экран. Она работает только в нижнем регистре, т.е. с маленькой буквы.
  • В скобках указывают данные, которые нужно вывести. Чаще всего выводят текст, который заключают в кавычки.
  • Print('Я учусь в школе') — программа выдаст ошибку
  • print('Я учусь в школе') — программа выведет: Я учусь в школе
Python
print('Я учусь в школе')

Для вывода текста используйте одинарные или двойные кавычки

Можно использовать одинарные кавычки '' или двойные кавычки "". Используй один вид кавычек — иначе команда не сработает. Текст начинается и заканчивается одинаковыми кавычками.

Python
print('Я говорю: "Спасибо!"') print("Я крутой!") # Этот код не выполнится (раскомментируй и попробуй): # print('Я говорю "Спасибо!)

Команда print() принимает и выводит несколько аргументов

  • Команда print() принимает несколько элементов через запятую — это позволяет выводить много информации за один раз.
  • Все слова выводятся в одной строке. Это работает и с числами.
Python
print('Я', 'умею', 'плавать') print('10', '9', '8', '7', '6')

Как соединить текст с помощью оператора +

Сложение строчек через + называется конкатенацией. С её помощью можно получить новую строку.

Консоль выдаст: Привет, друг!

Python
x = "Привет, " y = "друг!" print(x + y)

Оператор + соединяет числа

Выделяйте числа как строки кавычками, чтобы их объединить. Если этого не сделать, то Python сложит ваши числа.

Консоль выведет: 23  ·  Консоль выдаст: 5

Python
print("2" + "3") print(2 + 3)

Каждый print() выводит текст с новой строки

Начать текст с новой строки можно при использовании print() с новой строчки. Текст в консоли отобразится с новой строчки.

Python
print('Меня зовут Даниил!') print('Я люблю играть в Роблокс')

Пустой print() выведет пустую строку

Пустой print() используется, например, для создания отступов.

На консоли будет:

Меня зовут Даниил!

Я люблю играть в Roblox!
Python
print('Меня зовут Даниил!') print() print('Я люблю играть в Roblox!')

Текст переносится также с помощью \n

  • Символ \n внутри строки создаёт перенос — подходит для переноса так же, как и пустая команда print().
  • Консоль выдаст: Привет! и с новой строки Меня зовут Даниил
Python
print("Привет!\nМеня зовут Даниил")

Используйте f-строки для вставки данных в текст

  • f-строки вставляют значение прямо в текст. Для этого поставьте f перед строкой.
  • Значение переменной запишите в фигурных скобках {}.
  • Консоль выведет: Привет, Егор!
Python
name = "Егор" print(f"Привет, {name}!")

Как f-строки работают с текстом и числами

При работе с f-строками не нужно использовать запятые для пробелов и + для конкатенации строк. Не забудьте использовать кавычки.

Консоль выдаст: Сумма чисел: 8

Python
a = 5 b = 3 print(f"Сумма чисел: {a + b}")

Используйте комментарии для пояснений в коде

  • Всё, что написано после # — комментарий.
  • Их располагают на отдельной строке или после кода.
  • Python не выполняет комментарии — они нужны только для человека.
  • Консоль выдаст: Привет!
Python
# Это комментарий print("Привет!") # Выводим приветствие

Команда input() используется для ввода данных

  • input() вводит данные в программу от пользователя.
  • Программа ждёт ввод и нажатие Enter. Каждый вызов input() останавливает программу.
  • Консоль выведет вопрос «Как тебя зовут?», затем ввод. После «Паша» — выдаст: Привет, Паша
Python
print('Как тебя зовут?') x = input() print('Привет,', x)

Пишем текст внутри input()

Текст запроса передаётся в input(). Этот текст показывается пользователю как вопрос или подсказка. После этого программа ждёт ввод и нажатие Enter.

Консоль сначала выведет: Сколько тебе лет? После ввода «13» — выдаст: Ты ввёл: 13

Python
age = input("Сколько тебе лет? ") print("Ты ввёл:", age)

Команду input() можно вводить много раз

  • В одной программе можно использовать множество команд input().
  • Вывод будет текстом, даже если вы вводите число.
  • Введя вместо x и y числа 1 и 2, консоль выведет: Ты ввёл: 1 и 2
Python
x = input() y = input() print('Ты ввёл:', x, 'и', y)

Преобразуйте текст, чтобы работать с числами

Для этого необходимо воспользоваться командами int() — для целых чисел и float() — для чисел с плавающей точкой.

Пример кода для целого числа

Python
age = input("Сколько тебе лет? ") age_number = int(age) next_year = age_number + 1 print("В следующем году тебе будет", next_year)

Преобразуйте текст, чтобы работать с числами

Для этого необходимо воспользоваться командами int() — для целых чисел и float() — для чисел с плавающей точкой.

Пример кода для дробного числа

Python
price = input("Введите цену товара: ") price_number = float(price) total = price_number * 2 print("Цена за два товара:", total)

Управляйте выводом строк с помощью sep

  • Используйте параметр sep, чтобы задать разделитель между элементами при выводе нескольких значений.
  • Параметр sep работает между аргументами, а не внутри строки. Разделитель можно указать любой — включая пустую строку.
Python
# На консоли будет: А-Б-В print("А", "Б", "В", sep="-") # На консоли будет: АБВ print("А", "Б", "В", sep="")

Управляйте выводом строк с помощью end

Используйте параметр end, чтобы задать символы, которыми завершается вывод строки. Параметр управляет тем, как текст отображается на экране.

На консоли будет: Привет мир

Python
print("Привет", end=" ") print("мир")

Управляйте выводом строк с помощью end

  • end применяют, когда нужно вывести несколько элементов в одной строке, формируя вывод по шагам.
  • end работает только с текстом. В случае ввода числа будет ошибка.
Python
print("Hello", end=5)

Используйте параметры sep и end вместе

Параметры sep и end можно использовать вместе. Это даёт полный контроль над форматом вывода и часто применяется при форматировании отчётов и таблиц.

На консоли будет: 01-01-2026.

Python
print("01", "01", "2026", sep="-", end=".")

Однажды герой по имени имя героя был класс героя. Он отправился в место, чтобы сразиться с враг. В руках у него был предмет. Когда битва началась, герой закричал: боевой клич! Так родилась новая легенда.
