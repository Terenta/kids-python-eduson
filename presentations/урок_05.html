Что такое строка

Строка — текст, который написан в кавычках. Разработчики используют строки, чтобы хранить текст. Например: имена пользователей, сообщения, статусы, пароли.

Представьте, что вы заполняете анкету в личном кабинете. Всё, что вы вводите, Python считывает как строки.

Переменная name ссылается на слово «Артём», переменная school — на текст «Лицей №5», а переменная hobby — на слово «Компьютер».

name = "Артём"
school = "Лицей №5"
hobby = "Компьютер"
mood = "😊"

Как создать строку

Используйте одинарные ' ' или двойные " " кавычки, чтобы сохранить в переменной текст. Можно также использовать тройные кавычки """ """. Не смешивай кавычки — если начал с ' ', закончи ' '.

Если написать текст без кавычек, Python считает, что это имя переменной, а не текст.

Python
username = "Лёша" status = 'Онлайн' print(username) print(status)

Цифры могут быть и числом, и строкой

Важно помнить: всё, что записано в кавычках — это строка. Даже если переменная ссылается на цифры — это тоже строка.

Строка

Для Python это текст, а не число. Такую переменную нельзя делить или вычитать, но можно работать с ней как с текстом.

code = '123'

Число

Теперь переменная ссылается на число. Значит с ней можно проводить арифметические действия.

code = 123

Как создать пустую строку

Иногда нужно создать переменную для текста, но самого текста ещё нет. Например, поле «О себе» при регистрации в игре пустое. Это называется пустая строка. Напишите кавычки без символов между ними, чтобы её создать.

Внутри кавычек ничего нет, даже пробела.
Python
bio = '' print(bio) print(len(bio))

Что можно делать со строками

Строки можно создавать и хранить их в переменных. Но разработчики также изменяют и комбинируют строки. Изучите операции, которые можно совершать со строками:

  • склеивание — соединить несколько строк в одну;
  • дублирование — повторить текст несколько раз;
  • извлечение — выбрать отдельные символы или части текста;
  • измерение — подсчитать количество символов в строке.

Вы можете выполнять действия с текстом двумя способами

1. Внутри функции print()

Вы пишете выражение в скобках, Python вычисляет и выводит на экран. Переменную создавать не нужно.

print('Super' + 'User')

Программа склеит строки и выведет SuperUser.

2. С помощью переменной

Вы создаёте переменную, записываете в неё результат и потом используете её. Это удобно, если результат нужен дальше.

full_name = 'Ivan' + 'Petrov'
print(full_name)

Программа выведет: IvanPetrov.

Что такое конкатенация, или склеивание

Используйте оператор сложения +, чтобы объединить две строки в одну без пробелов. Если нужен пробел — добавьте его вручную внутри кавычек.

Python
print('Super' + "User") print('Super' + ' ' + 'User')

Первая команда выведет SuperUser.

Вторая команда выведет Super User.

Что такое дублирование

В языке Python дублирование строк — это операция, которая создаёт новую строку с помощью повторения исходной строки заданное количество раз.

Используйте оператор умножения *, чтобы повторить строку заданное количество раз.

Python
print('!' * 15) print(' ошибка входа ') print('!' * 15)

Команда '!' * 15 создаёт строку, в которой символ «!» повторяется 15 раз. Затем программа выводит текст «ошибка входа». В конце снова выводит 15 символов «!».

Строки можно складывать и умножать

Со строками работают не все математические правила, но некоторые знаки использовать можно:

  • Знак +. В программировании это конкатенация. + не считает сумму, а приклеивает одну строку к другой.
  • Знак *. Это дублирование. С помощью умножения можно создать копию текста столько раз, сколько вы укажете.
Другие знаки, например - и /, со строками не работают и вызывают ошибки.

Чего нельзя делать со строками

1. Нельзя сложить строку и число.

Оператор + работает только с одинаковыми типами данных — только со строками или только с числами.

level = 5
print('Уровень: ' + level)

Ошибка! Нельзя сложить текст и число напрямую.

2. Нельзя вычитать и делить строки.

Не получится вычесть одну букву из слова с помощью минуса или разделить слово на два.

print('Messages' - 's')

Ошибка! Строки нельзя вычитать.

Зачем и как считать длину строки

В приложениях часто есть ограничения на длину строки. Например, пароль должен быть длиннее 8 символов, а пост — не более 280. Чтобы проверить это, компьютер считает символы.

Используйте функцию len(), чтобы узнать количество символов в строке. Она считает всё, что находится внутри кавычек: буквы, цифры, знаки препинания. Затем len() возвращает целое число.

Python
print(len('Python'))

С помощью этой команды можно узнать, что в слове Python 6 символов.

Пробел тоже считается символом

Для Python пробел — это такой же символ, как «А» или «Б». Поэтому len() всегда считает пробелы.

Python
greeting = 'Hi !' print(len(greeting))

Переменная greeting содержит 4 символа — 2 буквы, восклицательный знак и пробел.

Как найти адрес символа

Разработчикам часто бывает необходимо работать не с целым текстом, а с отдельными символами внутри него.

Например, нужно зашифровать пароль в Telegram, но оставить подсказку — показать только первый и последний символы.

Для решения таких задач разработчикам важно уметь обращаться к каждому символу отдельно.

Как устроена строка внутри

Представьте, что строка — это цепочка элементов. У каждого элемента есть свой номер — индекс. По этому номеру можно найти нужную букву. Рассмотрите это на примере слова FRIEND.

012345
FRIEND

Индексация строки начинается с 0

Обратите внимание на таблицу: первая буква F имеет индекс 0. Вторая — 1, и так далее. Это правило работает почти во всех языках программирования.

0 12345
F RIEND
Индексы всегда начинаются с нуля, а не с единицы!

Как узнать символ по номеру в строке

Используйте квадратные скобки: переменная[индекс], чтобы обратиться к конкретному символу.

Представьте, что вы хотите найти только первый символ в строке. Для этого напишите start = x[0]. Программа обратится к символу f.

Python
x = 'friend' start = x[0] print(start)

Что такое отрицательные индексы

Иногда удобнее обратиться к элементу с конца. Отрицательные индексы начинаются с -1: -1, -2, -3 и так далее.

FRIEND
-6-5-4-3-2-1
Python
x = 'friend' end = x[-1] print(end)

Программа обратится к символу d, так как написали end = x[-1].

Что такое срезы в Python

Срез — это способ извлечь часть строки. Иногда нужно узнать не конкретный символ, а часть текста. Например, слово из предложения.

Используйте квадратные скобки и двоеточие: [старт:стоп].

  • Старт — индекс, с которого начинается срез, он включается в вывод.
  • Стоп — индекс, на котором заканчивается срез, он не включается в вывод.
Это похоже на то, как считают время: «я делаю ДЗ с 2 до 5» означает, что в 5 уже закончили домашнее задание.

Как записать срез

Укажите два индекса в квадратных скобках через двоеточие, чтобы обратиться к части строки.

Python
word = 'Internet' part = word[0:5] print(part)

Программа возьмёт из слова Internet первые 5 символов и выведет слово Inter.

Как записать срез в сокращённой форме

Программисты часто используют сокращённую форму для записи среза.

Срез с начала [:5]

Срез [:5] записывает в новую переменную все символы с 1 по 5.

word = 'Internet'
part = word[:5]
print(part)

Срез до конца [2:]

Срез [2:] записывает все символы со второго до конца.

word = 'Internet'
part = word[2:]
print(part)

Как скопировать строку целиком

Иногда нужно создать полную копию текста для работы и не изменять оригинальную строку. Для этого используйте срез с пустыми значениями начала и конца.

  1. Оставьте место перед двоеточием пустым: Python начнёт с индекса 0.
  2. Оставьте место после двоеточия пустым: Python дойдёт до самого конца строки.
Python
word = 'Internet' copy = word[:] print(copy)

Как извлечь символы через один

Разработчики часто ускоряют работу с текстом, извлекая символы через один. Чтобы выбирать символы с определённым интервалом, добавьте второе двоеточие и цифру шага: [старт:стоп:шаг].

  1. Укажите шаг 2, чтобы забирать каждый второй символ.
  2. Программа сошлётся на первый символ, пропустит один и запишет следующий.
Python
word = 'Программа' result = word[::2] print(result)

Как развернуть строку

Это помогает, например, проверить, читается ли слово одинаково в обоих направлениях, как слово «шалаш». Если указать отрицательное число в качестве шага, Python начнёт считывать строку справа налево.

  1. Используйте шаг -1.
  2. Оставьте индексы старта и стопа пустыми [::-1].
Python
word = 'Python' new_word = word[::-1] print(new_word)

Программа развернёт слово Python. Вывод: nohtyP.

Частые ошибки при работе со срезами

Ошибка 1. Срез выходит за границы.

Если вы попробуете обратиться к индексу, которого нет, Python выдаст ошибку IndexError: string index out of range.

Это похоже на то, что вы ищете квартиру №10 в доме, где всего 3 квартиры.

text = 'Hi'
text[5]  # Ошибка! Индекса 5 нет. Есть только 0 и 1.

Частые ошибки при работе со срезами

Ошибка 2. Пытаетесь изменить символ.

Если вы создали строку — нельзя обратиться к конкретному индексу и записать новый символ.

Если выполнить код text[0] = "A", программа выдаст ошибку TypeError — строка не поддерживает перезапись отдельных элементов.

text = 'Hello'
text[0] = 'A'  # Ошибка!

Практическое задание: создайте генератор никнеймов

В онлайн-играх игроки часто вступают в кланы. Чтобы все видели, в каком вы клане, перед именем добавьте название клана в квадратных скобках. Например, если название клана ЕДУСОН, а имя игрока VoVan, то игровой никнейм будет:

[ЕДУСОН] VoVan

Практическое задание: генератор никнеймов

Выполните алгоритм из 4 действий, чтобы создать генератор никнеймов.

  1. Создайте переменную clan и запишите в неё название клана в квадратных скобках.
  2. Создайте переменную name и запишите в неё своё имя.
  3. Склейте эти строки через пробел и сохраните результат в новую переменную nickname.
  4. Выведите никнейм на экран.

Изучите решение практического задания

1. Запросите название клана.
2. Запросите имя игрока.
3. Добавьте квадратные скобки к клану и склейте с именем через пробел.
4. Выведите результат.

Python
clan = input('Введите название клана: ') name = input('Введите ваше имя: ') nickname = '[' + clan + '] ' + name print(nickname)

  1. Напиши строку, в которой первые три символа ---. Напиши само слово после этих символов.

Практическое задание: секретный шифр

Выполни алгоритм из пяти действий, чтобы создать программу, которая расшифрует послание.

  1. Создайте переменную secret_message.
  2. Используйте функцию input(), чтобы записать в эту переменную зашифрованный текст.
  3. Примените срез с шагом 2, чтобы извлечь из строки только нужные символы.
  4. Сохраните результат в новую переменную decoded_word.
  5. Выведите расшифрованное слово на экран.

Изучите решение практического задания

1. Примите зашифрованный текст от пользователя.
2. Вырежете каждый второй символ, начиная с первого.
3. Покажите результат.

Python
secret_message = input('Введите зашифрованное слово: ') decoded_word = secret_message[::2] print('Результат расшифровки:', decoded_word)

Домашнее задание: напишите код, который делает никнейм необычным

Представьте, вы хотите, чтобы никнейм или статус выделялся в консоли. Напишите программу, которая берёт любое слово и оборачивает его в рамку из символов #. Рамка подстраивается под длину слова автоматически.

Если ввести MAX, рамка будет короткой:

########
# MAX #
########

А если ввести SUPER_PROGRAMMER, рамка растянется.

Для этой задачи понадобится узнать, сколько букв в слове. Используйте функцию len().

name = 'Alex'
length = len(name)

Изучите алгоритм, чтобы решить задание

  1. Запросите у пользователя никнейм или слово.
  2. Узнайте длину этого слова с помощью len().
  3. Рассчитайте длину верхней и нижней границы. Внутри рамки два пробела слева и справа от слова и две решётки границ. Значит, длина линии = длина_слова + 4.
  4. Создайте линию-границу — умножьте символ # на длину.
  5. Выведите результат.
Python — попробуй!
name = input('Введи никнейм: ') length = len(name) line = '#' * (length + 4) print(line) print('# ' + name + ' #') print(line)
