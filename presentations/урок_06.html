Список хранит несколько значений в одной переменной

Список — это структура данных в Python. Список позволяет хранить несколько значений в одной переменной и упрощает работу с данными — делает код компактным.

Python
# В переменной numbers хранится список чисел numbers = [2, 4, 6, 8, 10] # В переменной fruits хранится список названий фруктов fruits = ['яблоко', 'груша', 'апельсин', 'персик'] print(numbers) print(fruits)

В списке могут находиться данные разных типов

Списки — гибкие структуры данных: в них можно хранить строки, переменные, целые числа и числа с плавающей точкой.

Python
profile = ['Timur', 1992, 61.5] print(profile)

Python объединяет три значения в квадратных скобках в один список, оператор = сохраняет этот список в переменную profile. Команда print() выведет список: ['Timur', 1992, 61.5]

Переменная хранит одно значение, список — несколько

Переменная ссылается на одно значение. В отличие от переменной, список может хранить множество значений одновременно — это удобно, когда нужно работать с большим количеством данных. Благодаря спискам не нужно создавать десятки отдельных переменных.

Python
# Присваиваем переменной x значение 10 x = 10 # Увеличиваем значение x на 5 x = x + 5 # Выводим результат 15 print(x)

У каждого элемента списка есть индекс

Индекс — это номер элемента в списке, который позволяет быстро обращаться к нужному значению. Нумерация начинается с нуля.

Благодаря индексам можно легко получить любой элемент списка: первый, последний или средний, и не перебирать весь список.

Python
# Создаём список из трёх чисел numbers = [2, 4, 6] # Обращаемся к элементу: название_списка[индекс] print(numbers[1])

[2] имеет индекс 0, [4] имеет индекс 1, [6] имеет индекс 2. Если вы запросите элемент списка с индексом 1, в консоли вы увидите 4.

Элементы списка изменяются по индексу

В отличие от переменной, которая хранит только одно значение, в списке можно изменить любой элемент, а остальные оставить прежними. Обратитесь к элементу, который хотите изменить и присвойте ему новое значение.

Python
# Создаём список numbers = [2, 4, 6] # Заменяем его нужный элемент # имя_списка[индекс] = новое_значение numbers[1] = 10 print(numbers)

Обратились к элементу с индексом 1, это 4. Заменили его на 10. В результате вместо [2,4,6] получите [2,10,6].

Элементы строки изменять нельзя

К каждому символу строки можно обратиться по индексу, как к элементу списка. Например, если word = 'мама', то word[0] вернёт символ 'м'. Но вот изменить символ нельзя — команда word[0] = 'п' приведёт к ошибке. Это ключевое отличие строк от списков: строки нельзя менять.

Python
word = 'мама' # Здесь возникнет ошибка, так как строки менять нельзя word[0] = 'п' # Эта команда уже не сработает из-за ошибки выше print(word)

Списки заменяют множество отдельных переменных

  • Представьте, вы создаёте онлайн-игру. Вам нужно хранить имена всех игроков. Например, в начале их 100 человек. Вы можете создать 100 переменных — по одной на каждое имя.
  • Переменные создадут проблемы в будущем — количество игроков увеличится, под каждого нужно создать новую переменную. Вы потратите много времени.
  • С помощью списков вы можете работать с набором данных, которые связаны друг с другом.
Список = коробка для хранения связанных данных. Одна переменная — сколько угодно значений.

Срез списка берёт диапазон элементов

Представьте, что у вас есть список гонщиков, которые дошли до финиша, но наградить нужно только первых трёх призёров. Используйте срез списка, чтобы извлечь часть из списка.

Python
# Список всех гонщиков racers = ['Лёша', 'Дима','Даня', 'Ярик', 'Жора'] # Создаём срез: элементы с индекса 0 до индекса 3 top3 = racers[0:3] # Получаем первых гонщиков: ['Лёша','Дима', 'Даня'] # Выводим список призёров print(top3)

Срез создаёт полную копию списка

Представьте, что у вас есть меню в кафе. В нём есть бургер, пицца и кола. Но один клиент хочет заменить напиток и взять сок.

Если мы исправим это в главном меню, то оно изменится для всех остальных гостей. Поэтому нам нужна отдельная копия. Используйте срез списка, чтобы создать копию.

Python
menu = ['Бургер', 'Пицца', 'Кола'] client_order = menu[:] print(client_order)

Срез создаёт полную копию списка

Python
# Стандартное меню для всех menu = ['Бургер', 'Пицца', 'Кола'] # Делаем копию заказа для клиента с помощью среза [:] client_order = menu[:] # Клиент хочет заменить Колу на Сок client_order[2] = 'Сок' # Оригинал остался целым: ['Бургер', 'Пицца', 'Кола'] print('Меню:', menu) # В копии изменения есть: ['Бургер', 'Пицца', 'Сок'] print('Заказ клиента:', client_order)

Оператор '+' соединяет два списка

Со списками можно выполнять арифметические операции, почти как с обычными числами. Представьте, что вам нужно сложить два списка. Используйте '+', чтобы сложить списки.

Python
# Создаём два списка boys = ['Дима', 'Петя'] girls = ['Аня', 'Маша'] # Складываем два списка friends = boys + girls # Получаем один общий: ['Дима', 'Петя', 'Аня', 'Маша'] print(friends)

Список можно сложить только со списком

Оператор '+' умеет соединять только два списка. Если вы попытаетесь прибавить к списку обычное число или строку, Python выдаст ошибку.

Python
# Создайте список grades = [5, 4, 5] # Python выдаст ошибку. Нельзя складывать список и число new_grades = grades + 5

Чтобы добавить одно значение — оберни его в список: grades + [5]

Умножение на число повторяет список

  • Умножение списка на число повторяет список несколько раз. Используйте оператор '*', чтобы получить новый список, в котором элементы исходного списка идут подряд нужное количество раз.
  • Число после '*' должно быть целым: 2, 3, 0. Если умножить на 0, получится пустой список.
Умножение — быстрый способ создать список с повторяющимися значениями без лишнего кода.

Изучите пример умножения списка на число

Python
# Создайте список students = ['Аня', 'Боря', 'Вика'] # Повторите список 2 раза students_twice = students * 2 # Вывод: ['Аня', 'Боря', 'Вика', 'Аня', 'Боря', 'Вика'] print(students_twice)

Умножение экономит время, когда вы создаёте одинаковые значения

Представьте, вы программируете игру. В матч зашли 5 игроков, каждому нужно выдать по 100 очков здоровья. Используйте оператор '*', чтобы продублировать список.

Python
# Умножьте список на количество игроков health_points = [100] * 5 # Результат: [100, 100, 100, 100, 100] print(health_points)

Многомерные списки хранят другие списки

  • Многомерные списки позволяют хранить сложные структуры данных — внутри них находятся не отдельные значения, а другие списки. Их часто используют, чтобы создавать матрицы и таблицы.
  • Представьте, что обычный список — это улица с частными домами. В каждом доме живёт одна семья — это одно значение.
  • Вложенный список — это многоэтажный дом. В нём есть этажи, а на каждом этаже находится несколько квартир.
Список внутри списка = таблица: строки и столбцы, как Excel или игровое поле.

Теперь создадим многомерный список и посмотрим, что получится.

Python
# Создаем дом — главный список. Внутри него 3 этажа, то есть три списка house = [ ['Кошка', 'Собака'], # 1-й элемент (индекс 0). ['Синица', 'Воробей'],# 2-й элемент (индекс 1). ['Муравей', 'Пчела'] # 3-й элемент (индекс 2). ] # Консоль отобразит весь список целиком: # [['Кошка', 'Собака'], ['Синица', 'Воробей'], ['Муравей', 'Пчела']] print(house)

Как обратиться к вложенному списку по индексу

Используйте индекс, чтобы получить доступ к одному из «этажей». Элементы главного списка — это другие списки.

Когда вы обращаетесь к элементу по индексу, например house[0], Python отобразит не отдельное слово, а целый вложенный список.

Python
house = [ ['Кошка', 'Собака'], ['Синица', 'Воробей'], ['Муравей', 'Пчела'] ] # С помощью индекса [0] обращаемся к вложенному списку # В консоли увидим: ['Кошка', 'Собака'] print(house[0])

Два индекса находят конкретный элемент

  • Вы можете обратиться к конкретному элементу вложенного списка. Используйте '[]' дважды.
  • Первые '[]' — индекс списка, вторые '[]' — индекс элемента.
  • В примере, первые '[]' — это номер этажа, вторые '[]' — номер квартиры.
house[этаж][квартира] — сначала выбираем список, потом элемент внутри него.

Изучите примеры обращения к элементам

Python
house = [ ['Кошка', 'Собака'], ['Синица', 'Воробей'], ['Муравей', 'Пчела'] ] # Нам нужна Кошка. # 1. house[0] — находим первый список ['Кошка', 'Собака'] # 2. [0] — внутри этого списка берем первый элемент print(house[0][0]) # Выведет: Кошка # Нам нужен Воробей. # 1. house[1] — находим второй список ['Синица', 'Воробей'] # 2. [1] — внутри этого списка берем второй элемент print(house[1][1]) # Выведет: Воробей

Выполните практическое задание, чтобы создать программу для игры

Представьте, что вам нужно создать программу, чтобы управлять инвентарём героя. Пользователь вводит названия трёх предметов, которые нашел герой, и программа сохраняет их в список.

Затем на экран выводится весь список собранных вещей. Герой находит «Эликсир здоровья» и заменяет им один из старых предметов. Программа показывает первый и последний предмет в рюкзаке. В конце герой вспоминает, что забыл взять важную вещь, и добавляет пропущенный предмет в конец списка.

Выполните практическое задание

  1. Создайте список с двумя видами оружия, которые вводит пользователь.
  2. Создайте список с двумя припасами, например едой или зельем, который тоже вводит пользователь.
  3. Сложите эти два списка в один общий список inventory.
  4. Спросите у пользователя: «Что вы забыли положить?» — и считайте название предмета.
  5. Добавьте забытый предмет в конец списка inventory, с помощью сложения: список + [предмет].

Выполните практическое задание

  1. Выведите итоговый инвентарь на экран.
  2. Выведите первый предмет и последний предмет.

Подсказка: для последнего элемента используйте индекс -1. Например: inventory[-1] — это всегда последний элемент, независимо от длины списка.
