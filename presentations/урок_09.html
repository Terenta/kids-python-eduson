# Запрашиваем количество баллов (от 0 до 100) score = int(input('Введите количество ваших баллов (целое число от 0 до 100): ')) # Проверяем, в какой диапазон попадает результат ''' 90–100: 90 <= score <= 100 75–89: 75 <= score <= 89 60–74: 60 <= score <= 74 0–59: 0 <= score <= 59 '''

Изучите эталонное решение задачи

Python
# Проверяем диапазон 90–100 баллов if 90 <= score <= 100: print('Отлично') # Проверяем диапазон 75–89 баллов elif 75 <= score <= 89: print('Хорошо') # Проверяем диапазон 60–74 балла elif 60 <= score <= 74: print('Удовлетворительно') # Проверяем диапазон 0–59 баллов elif 0 <= score <= 59: print('Неудовлетворительно') else: print('Ошибка: введено число меньше 0 или больше 100')

На уроке вы узнаете

  1. Что такое условие и зачем оно нужно в программе.
  2. Назначение конструкции if и else.
  3. Значения логического типа: True и False.

Что такое условия

Представьте, вы договариваетесь с другом пойти гулять: «Если на улице будет теплее −30, мы идём». Это и есть условие — утверждение, которое может быть правдой или ложью.

  • На улице −10, т.е. теплее −30. Условие выполняется, оно правдиво, вы идёте гулять. В Python это обозначается True.
  • Если на улице −40, т.е. холоднее −30. Условие не выполняется, оно ложно, вы остаётесь дома. В Python это обозначается False.

Изучите пример кода с условием

Python действует так же. Этот механизм называется ветвлением. Программа доходит до развилки, проверяет условие и выбирает, по какой «ветке» кода пойти дальше.

Python
# Фиксируем температуру temperature = -10 # Проверяем условие: теплее ли на улице, чем -30? if temperature > -30: print("Идём в игровой клуб!") # Условие выполнено else: print("Сидим дома.") # Условие не выполнено

Как с помощью условий проверить домашнюю работу

Представьте, вам нужно сделать программу для проверки своей домашней работы. Если вы введёте правильный ответ, программа напишет «Верно». Если ответ неправильный — «Ошибка».

Python
# Задаём вопрос пользователю и сохраняем его ответ answer = input("Сколько будет 2 + 2? ") # Проверяем условие: если ответ равен "4" if answer == "4": print("Верно") # Выполняем это действие, если условие выполняется else: print("Ошибка") # Иначе выполняем это действие

True и False возвращают результаты проверки

Любое условие даёт результат True (правда) или False (ложь). Условия строятся с помощью операторов сравнения.

Python
print(5 > 3) # В консоли будет True

Как работают операторы сравнения

Программа использует результат, чтобы выбрать, что делать дальше. Существует шесть операторов сравнения:

  1. > — больше.
  2. < — меньше.
  3. >= — больше или равно.
  4. <= — меньше или равно.
  5. == — равно.
  6. != — не равно.

Изучите, как работает оператор >

Представьте, вам нужно написать программу для работы камер наблюдения на дорогах. Камера измеряет скорость автомобиля и фиксирует превышение.

  • Если автомобиль едет быстрее 60 км/ч, камера отмечает, что скорость превышена.
  • Если скорость 60 км/ч или ниже, камера ничего не фиксирует.

Изучите, как работает оператор >

Используйте оператор >, чтобы сравнить скорость движения автомобиля с разрешённой скоростью.

Python
# Это скорость движения автомобиля current_speed = 65 # Это разрешённая скорость на участке дороги speed_limit = 60 # Камера проверяет превышение скорости is_speeding = current_speed > speed_limit # True, будет штраф print(is_speeding)

Изучите, как работает оператор <

Представьте, вам нужно написать программу, которая сообщит, что ваш гаджет скоро разрядится. Используйте оператор <, чтобы проверить заряд гаджета.

Python
# Отмечаем уровень заряда гаджета battery_level = 10 # Проверяем, заряд гаджета меньше 15% или нет low_battery = battery_level < 15 # True, выводим сообщение о низком заряде print(low_battery)

Изучите, как работает оператор >=

Представьте, вы создаёте игру. В вашу игру могут играть люди с 12 лет. Используйте оператор >= — граничное значение входит в диапазон.

Python
# Допустимый возраст для входа в игру game_rating = 12 # Ваш возраст my_age = 12 # Мне ровно 12. Можно ли мне играть? access_allowed = my_age >= game_rating print(access_allowed) # True, доступ открыт, 12 входит в условие

Изучите, как работает оператор <=

Представьте, вы создаёте игру. Нужно следить за весом предметов в рюкзаке героя. Максимум — 50 кг. Используйте <= — граничное значение допустимо.

Python
# Вместимость рюкзака max_weight = 50 # Вес собранных предметов current_loot = 50 # Проверяем, не перегружен ли персонаж can_run = current_loot <= max_weight # True, вес ровно 50, бежать ещё можно print(can_run)

Изучите, как работает оператор ==

Представьте, вы создаёте приложение для проверки промокодов. Используйте ==, чтобы проверить, совпадают ли два значения.

Python
# Правильный код promo_code = "SALE2024" # Код от пользователя user_input = "sale2024" # Проверяем промокод is_valid = promo_code == user_input print(is_valid) # Результат False, так как Python различает регистр букв

Изучите, как работает оператор !=

Представьте, вы делаете мессенджер. Вам нужно показать список друзей, кроме тех, кто сейчас офлайн. Используйте оператор !=, чтобы исключить статус «Offline».

Python
# Ваш друг в сети status = "Online" # Проверяем, что статус друга не равен "Offline" if status != "Offline": print("Друг онлайн, напишите ему!")

Изучите, как работает конструкция if

Конструкция if позволяет программе принимать решение — выполнять или не выполнять команды.

  • Код, который находится внутри блока if, выполняется только если условие истинно — имеет значение True.
  • Если условие ложно — имеет значение False — программа проигнорирует этот блок и пойдёт дальше.

Изучите, как работает конструкция if

Python
# Просим пользователя ввести число num = int(input("Введите число: ")) # Если число больше нуля — условие True if num > 0: # Этот код выполнится только при положительном числе print("Число положительное") # Это выполнится в любом случае, независимо от условия print("Программа завершена")

Используйте == вместо = в условиях

В условии if мы всегда сравниваем, а не приказываем. Использовать одиночное равно нельзя.

Синтаксическая ошибка: здесь нужно использовать ==

x = 5
if x = 5:      # ❌ Ошибка! Нельзя использовать =
    print("Да")

Правильно:

x = 5
if x == 5:     # ✓ Правильно: сравниваем с помощью ==
    print("Да")

Как выделить блок кода

Чтобы обозначить блоки кода, в Python используются отступы. Они показывают вложенность: какие команды относятся к условию, а какие — к основной программе.

  • Блок кода начинается после двоеточия :
  • Стандартный отступ — 4 пробела или 1 нажатие клавиши Tab.
  • Все строки внутри одного блока должны иметь одинаковый отступ.

Изучите пример блока кода

Python
num = 10 if num > 0: # Эта строка имеет отступ в 4 пробела # Она выполнится, только если num больше 0 print("Число положительное") print("Это всё ещё внутри условия") # Эта строка без отступа # Она выполнится в любом случае, проверка на неё не влияет print("Программа завершена")

С отступом — выполняется только если условие True. Без отступа — выполняется всегда, независимо от условия.

Ошибка с потерянным отступом

Если вы не сделаете отступ после двоеточия, Python не поймёт, когда условие выполняется.

Python ожидал блок с отступом после if, но не нашёл его:

num = 10
if num > 0:
print("Число положительное")  # ❌ Нет отступа!
IndentationError: expected an indented block — «Ожидался блок с отступом»

Изучите, как работает конструкция else

Python
# Задаём вопрос пользователю answer = input("Какой язык мы изучаем? ") # Проверяем ответ if answer == "Python": # Этот блок сработает только при точном совпадении print("Верно! Отличный выбор.") else: # Этот блок сработает при любом другом ответе print("Неверно. Попробуй ещё раз.")

Конструкция else работает в паре с if. Если условие в if ложно, выполняется блок else. У else никогда не пишут условие — только действия.

Как работает цепочка сравнений

В математике мы часто записываем диапазоны одной строкой, например 0<x<10. Это называется цепочкой сравнения.

  • Когда Python видит выражение a <= b <= c, он автоматически превращает его в двойную проверку: a <= b and b <= c.
  • Оператор and ставится между двумя условиями и требует, чтобы оба они были правдой одновременно.

Постройте цепочку сравнения для проверки возраста

Python
# Спрашиваем возраст и сразу превращаем ответ в число age = int(input("Введите возраст: ")) # Проверяем диапазон: возраст от 1 до 18 включительно if 1 <= age <= 18: print("Вы ребёнок") # Сработает, если условие верное else: print("Вы взрослый") # Сработает во всех остальных случаях
