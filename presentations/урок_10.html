Используйте логические операторы, чтобы работать со сложными условиями

На прошлом уроке вы проверяли одно условие с помощью операторов сравнения: >, <, ==, >=, <=. Но иногда одного условия недостаточно — нужно проверить сразу несколько.

  • Пустить пользователя в игру, только если он ввёл правильный логин и пароль.
  • Дать скидку, если покупатель студент или пенсионер.
  • Логические операторы объединяют несколько условий в одно.

Существует три логических оператора

  1. and — «и то, и другое»: оба условия должны выполняться.
  2. or — «хотя бы одно»: достаточно одного из условий.
  3. not — «наоборот»: меняет True на False и обратно.

Проверьте условие с помощью and

Оператор and проверяет, выполняются ли несколько условий одновременно. Если оба условия верны — результат True. Если хотя бы одно неверно — результат False.

Python — концерт
# Сохраняем возраст пользователя age = 12 # Проверяем, есть ли билет has_ticket = True # Пускаем, только если оба условия верны if age >= 10 and has_ticket: print("Добро пожаловать!")

Проверьте условие с помощью or

Оператор or проверяет, выполнено ли хотя бы одно условие. Результат False только если оба условия неверны.

Python — выходной или праздник
# Сегодня выходной? is_weekend = False # Сегодня праздник? is_holiday = True # Достаточно одного из двух условий if is_weekend or is_holiday: print("Можно гулять!")

Проверьте условие с помощью not

Используйте not, когда нужно проверить противоположное условие. not True → False, not False → True.

Python — погода
# Идёт ли дождь? is_raining = False # not меняет False на True — значит, дождя нет, идём гулять if not is_raining: print("Идём на прогулку!")

Python работает с операторами по приоритету

Приоритеты между логическими операторами распределяются следующим образом:

  1. not — выполняется первым.
  2. and — выполняется вторым.
  3. or — выполняется последним.

Изучите пример, как работает приоритетность операторов

Это работает как в математике: сначала умножение, потом сложение. По правилам 2 + 3 × 4 = 14, а не 20. С логическими операторами то же самое. Изучите пример программы для доступа к базе данных:

Python — переменные
# Пользователь — администратор? is_admin = True # Пользователь — гость? is_guest = True # Технические работы, сервер недоступен is_available = False

Изучите пример, как работает приоритетность операторов

Если вы не уверены в порядке — ставьте скобки. Код станет понятнее и для вас, и для того, кто будет его читать.

Python — скобки меняют порядок
is_admin = True is_guest = True is_available = False # Python сначала вычислит is_guest and is_available = False, # потом is_admin or False = True print(is_admin or is_guest and is_available) # → True # Скобки меняют порядок: сначала is_admin or is_guest = True, # потом True and is_available = False print((is_admin or is_guest) and is_available) # → False

Используйте логические операторы, чтобы составить сложные условия

Логические операторы позволяют объединить несколько условий в одно, чтобы проверить сразу несколько утверждений. Изучите три способа составить сложное условие:

  1. and — все условия должны быть выполнены.
  2. or — достаточно одного из условий.
  3. not, and и or со скобками — комбинация для сложных правил.

Составьте сложное условие с and

Используйте оператор and, чтобы проверить все условия сразу. Если хотя бы одно False — условие не выполняется.

Python — парк аттракционов
# Возраст посетителя age = 14 # Рост посетителя в сантиметрах height = 150 # Есть ли билет has_ticket = True # Проверяем три условия одновременно: # Если хотя бы одно False — не пускаем if age >= 10 and height >= 120 and has_ticket: print("Добро пожаловать на аттракцион!")

Составьте сложное условие с or

Используйте оператор or, когда достаточно выполнения хотя бы одного из условий.

Python — автосохранение
# Сколько минут прошло? minutes_passed = 12 # Достиг ли игрок нового уровня? reached_new_level = False # Достаточно одного из условий if minutes_passed >= 10 or reached_new_level: print("Игра сохранена!") else: print("Сохранение пока не нужно")

Составьте сложное условие с or, and, not

Представьте, вам нужно написать приложение, чтобы проверять посетителей фитнес-зала. Проверьте, можно ли пустить посетителя в зал и закройте доступ тем, кто в чёрном списке.

  • Используйте комбинацию and, or и not, чтобы написать такое приложение.
  • Посетитель должен быть младше 18, иметь абонемент и не числиться в чёрном списке.

Составьте сложное условие с or, and, not

Python — фитнес-зал
# Возраст посетителя age = 14 # Есть абонемент? has_membership = True # В чёрном списке? is_banned = False # Выполняется «младше 18» И «есть абонемент» И «НЕ в чёрном списке» # not is_banned = True → условие выполняется if age < 18 and has_membership and not is_banned: print("Вход разрешён!") else: print("Вход закрыт")

Используйте and, чтобы проверить диапазон

Диапазон — это проверка, находится ли число между двумя значениями. Чтобы учесть оба края, используйте оператор and.

Python — диапазон
# Получаем число от пользователя num = int(input("Введи число: ")) # Проверяем оба края диапазона через and: # num >= 1 — не меньше левой границы, # num <= 10 — не больше правой границы if num >= 1 and num <= 10: print("Число в диапазоне от 1 до 10")
