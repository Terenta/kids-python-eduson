Свяжите несколько условий через elif

Конструкция if/else проверяет только одно условие. А если условий больше? Используйте elif между if и else.

Python — структура elif
# Первый вариант if условие_1: ... # Второй вариант elif условие_2: ... # Всё остальное else: ...

Запомните правила, которые помогут использовать elif

Изучите три правила, которые важно запомнить.

  1. elif — звучит «иначе если»: нужен, когда условий больше двух.
  2. Выполняется только первая подошедшая ветка — остальные пропускаются.
  3. Условия проверяются сверху вниз.

Изучите как применить elif

Представьте, вы пишете программу умного будильника. Он приветствует пользователя в зависимости от времени суток.

  • До 6:00 — ночь
  • До 12:00 — утро
  • До 18:00 — день
  • Всё остальное — вечер

Изучите как применить elif

Python — умный будильник
# Текущий час hour = 14 # Если меньше 6 — ночь if hour < 6: print("Ночь") # Если меньше 12 — утро elif hour < 12: print("Утро") # Если меньше 18 — день elif hour < 18: print("День") # Во всех остальных случаях — вечер else: print("Вечер")

Разберите типичные ошибки в работе с elif

Нельзя заменить elif на два отдельных if. Если написать несколько if — программа выведет несколько сообщений сразу.

Python — ошибка: два if
# Текущий час hour = 10 # Ошибка: два отдельных if — оба проверятся if hour < 18: print("День") if hour < 12: print("Утро")

Разберите типичные ошибки в работе с elif

Неправильный порядок условий. При hour = 10 сработает hour < 18 — выведет «День», хотя должно быть «Утро». Пишите от самого узкого к самому широкому.

Python — ошибка: порядок условий
# Текущий час hour = 10 # Ошибка: hour < 18 стоит первым — сюда попадёт утро if hour < 18: print("День") elif hour < 12: print("Утро") elif hour < 6: print("Ночь")

Проверьте условие с помощью нескольких if

Разберитесь, чем различаются разные варианты условий и когда использовать каждый из них.

Представьте, Вася написал контрольную и получил 95 баллов. Программа анализирует результат и выводит оценку. Для каждого условия срабатывает свой if — на экран может вывестись сразу несколько сообщений.

Примените отдельный if для каждой отдельной проверки

Каждый if проводит независимую проверку. Программа пройдёт через все условия сверху вниз и выполнит все подходящие. Здесь выведется сразу два сообщения.

Python — несколько if
# Баллы Васи score = 95 # Сработает, если набрал хотя бы 50 баллов if score >= 50: print("Сдал") # Дополнительная проверка внутри первой if score >= 90: print("Отлично")

Выберите один вариант с помощью if, elif, else

Вернитесь к кейсу с контрольной. Теперь нужно выдать одну оценку. Программа проверяет условия сверху вниз и останавливается на первом подходящем.

Используйте этот метод, когда нужно выбрать один вариант из нескольких и варианты не зависят друг от друга.

Изучите пример применения elif

Python — оценка с elif
# Баллы ученика score = 95 # Проверяем первое условие, если оно верно — программа остановится if score >= 90: print("Отлично") # Это условие не выполнится, если первое было верным elif score >= 50: print("Хорошо") # Выполнится, если ни одно условие не подошло else: print("Неудовлетворительно")

Объедините проверки в одну строку с помощью and и or

Представьте, вы пишете программу для пропуска зрителей на концерт. Охранник проверяет: возраст и наличие билета.

Оба условия одинаково важны. Отдельных сообщений для каждого случая нет — разбивать на уровни не имеет смысла.

Используйте этот метод, если нужно проверить несколько условий и они связаны друг с другом.

Изучите, как применить elif

Python — четыре оценки
# Баллы студента score = 75 # Оценка неудовлетворительно: менее 50 баллов if score < 50: print("Не сдал экзамен.") # Оценка удовлетворительно: от 50 до 69 elif score <= 69: print("Оценка удовлетворительная.") # Оценка хорошо: от 70 до 89 elif score <= 89: print("Оценка хорошая.") # Оценка отлично: 90 и больше else: print("Оценка отличная!")

Разбейте проверки на уровни через вложенный if

Вернитесь к задаче допуска на концерт. Теперь программа должна объяснить причину отказа.

Два разных сообщения: не тот возраст — одно, нет билета — другое. Проверки нужно разбить на уровни: сначала возраст, и только если он подошёл — проверить билет.

Изучите пример применения вложенных условий

Python — допуск на концерт
# Данные посетителя (меняй значения и проверяй!) age = 20 ticket_available = "да" # Основная проверка возраста if age < 18: print("Вам отказано: вам меньше 18 лет.") # Дополнительная проверка наличия билета elif ticket_available != "да": print("Вам отказано: у вас нет билета.") # Иначе — проход разрешён else: print("Добро пожаловать на концерт!")
