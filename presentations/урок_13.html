Что такое цикл и зачем он нужен

Представьте, вам нужно написать приветствие для игроков, которые входят в онлайн-игру.

Писать print("Добро пожаловать!") сто раз — это долго. Компьютер умеет повторять одни и те же действия многократно с помощью циклов. Это полезно, если нам необходимо масштабировать проект.

В Python есть два основных вида циклов

  • for — счётный цикл, повторяется заданное количество раз. Применяйте его, когда заранее знаете, сколько раз нужно повторить цикл.
  • while — условный цикл, повторяется пока неизвестно, сколько раз цикл должен повторяться.

Изучите структуру цикла for

Представьте, вам нужно вывести слово «Привет» 10 раз. Используйте для этого цикл for.

Python
for i in range(10): print('Привет')

Изучите, что такое тело цикла и итерация

Тело цикла — это строки с отступом под for. Строка без отступа уже не входит в цикл и выполняется один раз после его завершения. Если тело цикла выполнили один раз — такую ситуацию называют итерацией.

Python
for i in range(5): num = int(input()) # Повторяется 5 раз print('Квадрат числа:', num * num) # Выполнится 1 раз print('Цикл завершён')

Как работает переменная цикла

Переменная цикла, или счётчик отслеживания номера итерации, нужна, чтобы понимать, где находится цикл. При каждой итерации Python увеличивает i на 1.

  • Цикл начинается с 0.
  • Верхняя граница range() всегда не включается в цикл.
  • range(5) даёт числа 0, 1, 2, 3, 4 и не включает 5.

Используйте переменную цикла внутри тела

Переменную цикла можно использовать внутри тела — например, чтобы нумеровать строки.

Python
for i in range(10): print(i + 1, '-- Привет') # Вывод: # 1 -- Привет # 2 -- Привет # ... # 10 -- Привет

Переменная цикла без включения в тело

Используйте _, если переменную цикла вы не хотите включать в тело.

Python
for _ in range(5): print('Python – это круто!') # Вывод: # Python – это круто! # Python – это круто! # Python – это круто! # Python – это круто! # Python – это круто!

Как менять шаг в цикле

Число, на которое цикл увеличивает или уменьшает переменную на каждом повторении в range(), называется шагом.

Иногда не нужно перебирать все числа подряд. Например, вам нужно посчитать только чётные числа или вывести числа через одно.

Python
# start – с какого числа начать # stop – до какого числа идти, не включая его # step – на сколько изменять число каждый раз range(start, stop, step)

Изучите пример: изменить шаг

Если нужно, чтобы цикл пропускал числа, задайте другой шаг. Например, шаг 2.

Python
for i in range(2, 11, 2): print(i) # Консоль отобразит только чётные числа: 2, 4, 6, 8, 10

Функция range() с несколькими параметрами

Представьте, вам нужно найти все числа от 100 до 999, которые заканчиваются на 7. Используйте два параметра: 100 и 999, если нужно проверить конкретный диапазон.

Python
print("Числа, оканчивающиеся на 7:") # Числа от 100 до 999 for i in range(100, 1000): # Последняя цифра = 7 if i % 10 == 7: print(i) # 107, 117, 127, ..., 997

Изучите отрицательный шаг

Иногда нужно считать не вперёд, а назад. Например, в таймерах: сначала идёт счёт 5, 4, 3, 2, 1, а потом событие запускается. Для этого в range() используют отрицательный шаг.

Python
for i in range(5, 0, -1): print(i, end=' ') print('Подъём!!!') # Вывод: 5 4 3 2 1 Подъём!!!
