Изучите для чего нужен цикл while

Представьте, что вы создаёте игру «Угадай число». Компьютер загадал число от 1 до 100. Игрок вводит свой вариант. Программа должна ответить: «Больше!», «Меньше!» или «Угадал».

Один способ написать такую программу — прописать отдельные команды для каждой попытки игрока. Для первого ввода вывести «Больше!», для второго «Меньше!» и так далее. Этот подход неудобен: количество попыток игрока неизвестно заранее.

Изучите для чего нужен цикл while

Цикл while повторяет один и тот же блок команд до тех пор, пока условие остаётся истинным. В игре условием выступает проверка: «Число не угадано?». Пока ответ «да», цикл снова запрашивает ввод, сравнивает его с загаданным числом и выводит подсказку. Когда игрок угадывает, условие становится ложным и цикл завершается.

Цикл while применяют в ситуациях с заранее неизвестным числом повторений.

Какие циклы доступны в Python

Сравните два вида циклов.

for — счётный цикл

Используйте, когда количество повторений определено до запуска. Например, вывести 10 строк, пройти по списку из 5 элементов.

while — условный цикл

Используйте, когда повторения зависят от события: ввод пользователя, изменение переменной или внешний сигнал.

Изучите структуру цикла while

Цикл while включает два элемента: условие и тело. Условие проверяют перед каждым повторением. Если условие верно, цикл делает ещё один шаг. Если условие ложно, цикл заканчивается.

Тело — это команды, которые выполняются внутри цикла. Их пишут с отступом. Команды с отступом выполняются на каждом шаге цикла. Команды без отступа выполняются только один раз, когда цикл уже завершён. Один шаг цикла называют итерацией.

Изучите структуру цикла while

Представьте, что в вашей игре про космос бортовой компьютер должен поздороваться с каждым членом экипажа. На корабле пять человек. Вместо того чтобы писать пять одинаковых строчек кода, вы запускаете цикл while.

# Инициализируем счётчик перед циклом # Счётчик: сколько раз робот поздоровался i = 0 # Пока меньше 5 — продолжайте while i < 5: # Тело: выведите приветствие print(f' Робот: Привет, член экипажа #{i + 1}!') # Обновите счётчик, иначе получится бесконечный цикл i += 1 # Цикл кончился, выводим финал print(' Все на борту! Готовы к старту!')

Чем while отличается от for и if

Используйте for, когда заранее знаете, сколько раз нужно выполнить команду. Например, спутник фотографирует пять секторов галактики — секторов пять, поэтому применяйте for.

Python
print("=== СЪЁМКА ГАЛАКТИКИ ===") # range(1, 6) даёт числа 1, 2, 3, 4, 5 — всего пять итераций for sector in range(1, 6): # Эта строка выполняется ровно 5 раз print(f"Спутник фотографирует сектор #{sector}") # Эта строка вне цикла — выполняется один раз после всех повторений print("Все секторы отсняты. Возвращаемся на базу.")

Используйте условие if для однократной проверки

Условие if не повторяет команды. Оно проверяет условие один раз и выполняет блок кода, только если условие верно. Например, спутник проверяет уровень заряда батареи. Если заряд ниже 10%, программа выдаст предупреждение.

Python
# Запросите уровень заряда и сразу переводим в число battery = int(input("Уровень заряда батареи (%): ")) # Проверка выполняется только один раз if battery < 10: # Сработает, только если заряд меньше 10% print("Критический заряд батареи!") # Эта строка выполняется в любом случае — она вне условия print("Проверка заряда завершена.")

Как избежать бесконечного цикла

Бесконечный цикл возникает, когда условие в while всегда остаётся истинным. Цикл не может остановиться — программа перестаёт отвечать. Посмотрите на код с ошибкой:

i = 0
while i < 10:
    print(i)
    # Ошибка! Забыли увеличить счётчик.
    # Цикл будет бесконечно печатать 0.
Переменная i всегда равна 0. Условие i < 10 истинно на каждой проверке.

Как избежать бесконечного цикла

В этом коде переменная i всегда равна 0. Условие i < 10 истинно на каждой проверке. Цикл будет бесконечно печатать ноль. Программа зависнет.

i = 0
while i < 10:
    print(i)
    # i не меняется — условие никогда не станет ложным
    ...

Чтобы исправить ошибку, добавьте изменение счётчика внутри тела цикла. Без этого цикл никогда не завершится.

Как избежать бесконечного цикла

Python
# Создайте переменную-счётчик и дайте ей начальное значение 0. i = 0 # Пока i меньше 10, выполните тело цикла. while i < 10: # Выведите текущее значение i. print(i) # Увеличьте счётчик на 1. # Без этой строки цикл станет бесконечным. i = i + 1 # Когда i станет равно 10, условие i < 10 станет ложным. # Цикл завершится. Программа продолжит работу отсюда. print("Цикл завершён!")

Изучите пример ошибки с неверным условием

Иногда условие составлено так, что оно никогда не станет ложным, даже если переменная меняется. Переменная number увеличивается и всегда остаётся больше нуля. Условие number > 0 будет истинным всегда. Такой цикл тоже бесконечный.

Правило: условие while должно обязательно стать ложным когда-нибудь. Иначе — бесконечный цикл.

Изучите пример ошибки с неверным условием

    # Условие никогда не станет ложным. Цикл бесконечный.
