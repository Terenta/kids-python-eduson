Как использовать оператор break

Оператор break используют, чтобы немедленно прервать цикл. Он останавливает ближайший цикл for или while, и выполняется команда, которая идёт после цикла. break часто используют вместе с флагами — переменными-метками вида flag = False / True.

Представьте, что вы разрабатываете игру. В ней есть закрытый магический сундук, который открывается только паролем. Пароль — это число. Простое число — это число, которое делится без остатка только на 1 и на само себя. Например: 2, 3, 5, 7, 11.

Как оператор break работает с бесконечными циклами

В Python можно создать бесконечный цикл while True:. Такой цикл продолжается, пока его не прервут. Оператор break ставят внутри тела цикла при выполнении какого-либо условия — например, ввод команды exit или обнаружение ошибки.

Представьте, что в вашей игре есть страж-программа. Она круглые сутки ждёт команд от игрока. Страж обрабатывает запрос и снова ждёт следующего. Если игрок вводит команду exit, страж прекращает работу с помощью break.

Как оператор break работает с бесконечными циклами

    if query == "exit":

Код после цикла выполнится только тогда, когда сработает break — иначе цикл никогда не закончится.

Как работать с оператором continue

Оператор continue позволяет перейти к следующей итерации цикла for или while, не выполняя оставшийся код внутри тела цикла. Его используют, когда нужно пропустить определённые значения и продолжить обработку остальных.

В игре герой идёт по коридору с сотней дверей. Некоторые двери заперты — для них нужен более высокий уровень. Список закрытых комнат: 7, 17, 29, 78. Если герой видит закрытую дверь, он просто проходит мимо и идёт дальше.

Как работать с оператором continue

# Герой проходит мимо ста дверей
for room_number in range(1, 101):
    # Если дверь закрыта, т.е. номер в списке недоступных
    if room_number == 7 or room_number == 17 or room_number == 29 or room_number == 78:
        # Герой проходит мимо, не заходит
        continue

    # Эта строка выполнится только для доступных комнат
    print(f"Герой зашёл в комнату №{room_number}")

print("Герой прошёл весь коридор.")

Как работать с оператором else

После цикла for или while в Python можно написать блок else. В циклах else работает по-другому: он выполняется, только если цикл не был прерван командой break.

Герой проходит коридор из трёх комнат. В одной может быть ловушка. Если герой найдёт ловушку — он пострадает и награду не получит. Если осмотрел все комнаты и ловушки нет — испытание пройдено, герой получает награду.

Ловушка есть — срабатывает break, блок else не выполняется

Блок else не выполнился, потому что цикл был прерван оператором break.

# Герой проходит три комнаты. Ловушка находится во второй комнате.
for room in range(1, 4):
    print(f"Герой входит в комнату {room}")

    # Условие: если комната номер 2, то в ней ловушка
    if room == 2:
        print("Ловушка! Герой покидает испытание.")
        # Прервите цикл, дальше комнаты не проверяем
        break
...

for room in range(1, 4):

В игре герой находит артефакт-сканер кодов. Артефакт умеет определять, есть ли в коде цифра семь. Семёрка — символ удачи.

Если артефакт находит в коде хотя бы одну семёрку, он сразу объявляет об удаче и прекращает проверку. Нуль артефакт пропускает, потому что они не несут магического смысла.

  • разбирает число на отдельные цифры;
  • пропускает цифры 0 — continue;
  • ищет цифру 7 — при нахождении break;
  • если цифра 7 не найдена — блок else сообщает, что код обычный.
