Проблема: копипаста убивает код

Что если нужно поменять формат карты? Придётся менять в 3 местах...

❌ До: дублирование

# Ход 1 — печать карты
for row in maze:
    print("".join(row))

# После выстрела — снова!
for row in maze:
    print("".join(row))

# В конце — ещё раз!
for row in maze:
    print("".join(row))

✅ После: функция

def show_map():
    for row in maze:
        print("".join(row))

# Ход 1
show_map()

# После выстрела
show_map()

# В конце
show_map()

Правило инженера EdisonGames: если ты скопировал код второй раз — это сигнал написать функцию. Копипаста = баги в 3 местах вместо 1.

Анатомия функции

Шесть частей — каждая важна

Рецепт vs Приготовление

def создаёт рецепт. Вызов greet() — готовит по нему

📝

Объявление = рецепт

Код в теле функции НЕ выполняется сразу. Он просто записывается.

def greet():
    print("Привет!")
    print("Как дела?")
# ← здесь ничего не выведется
🍳

Вызов = готовим

Только когда пишешь greet() — функция выполняется.

greet()   # Привет! Как дела?
greet()   # Привет! Как дела?
greet()   # Привет! Как дела?
# 3 раза по рецепту!

Мнемоника: def greet: — "Я записал рецепт". greet() — "Приготовь по этому рецепту!". Скобки () — это команда "пошёл!". Без скобок функция не запускается.

Алгоритм: 5 шагов написания функции

Каждый раз, когда нужно написать функцию — иди по шагам

  1. Назови задачу — что функция должна делать? Одно действие = одна функция. Например: «напечатать меню».
  2. Придумай глагол-имя — print_menu, show_score, draw_board. snake_case, маленькие буквы.
  3. Напиши заголовок — def имя(): Не забудь двоеточие! Пока без параметров — просто пустые скобки.
  4. Напиши тело — с отступом 4 пробела. Тело — это всё, что функция делает. Можно начать с одного print().
  5. Вызови и проверь — напиши имя() ниже тела. Запусти. Работает? Вызови ещё раз!

⚡ Совет инженера: если функция делает больше одного дела — разбей на две. Функция должна быть маленькой и понятной.

Как называть функции

Хорошее имя = понятный код без комментариев

snake_case
Слова разделяются подчёркиванием: show_menu, draw_board, calc_score
глагол
Функция что-то делает, поэтому имя — действие: show_, draw_, print_, get_, calc_
строчные
Только маленькие буквы. show_map ✅ · ShowMap ❌ (это стиль классов) · SHOWMAP ❌
по смыслу
f() — плохо. do_stuff() — плохо. render_game_screen() — отлично.

❌ Плохо

def f():
def doStuff():
def MENU():

✅ Хорошо

def print_menu():
def show_score():
def start_new_game():

Типичные ошибки с функциями

Встретишь эти ошибки — теперь знаешь, что делать

❌ Забыл () при вызове

greet  # не вызов!
# Выведет: <function greet>
# Нужно:
greet()  # ← скобки!

❌ Нет двоеточия

def greet()   # ← SyntaxError!
    print("Привет")
# Нужно:
def greet():  # ← двоеточие

❌ Нет отступа в теле

def greet():
print("Привет")  # IndentationError!
# Нужно 4 пробела:
    print("Привет")  ✅

❌ Объявил, но не вызвал

def greet():
    print("Привет")
# Вывода нет! Надо вызвать:
greet()  # ← вот теперь работает
