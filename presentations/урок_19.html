    for ch in text:

    return count

Чем print отличается
от return?

print vs return

print — «сказал вслух». return — «отдал в руку»

print — выводит и забывает

def add_print(a, b):
    print(a + b)  # кричит: 8

add_print(3, 5)   # видим: 8
result = add_print(3, 5)
print(result)  # None! Потеряли

return — передаёт значение

def add(a, b):
    return a + b  # отдаёт: 8

result = add(3, 5)  # ловим: 8
print(result)  # 8
print(add(3, 5) * 2)  # 16!
Аналогия: print — громкоговоритель. Все слышат «8», но никто не может взять «8» в руки. return — передать листочек с ответом. Его можно сложить, умножить, передать дальше.

Как работает return

Значение летит обратно к вызывающему коду

  • После return функция немедленно завершается — код ниже не выполняется
  • Значение «летит» обратно и может быть сохранено в переменную или использовано в выражении

Ранний выход: guard clause

return в начале функции — проверь условия до основной работы

Без guard — глубокое вложение

def divide(a, b):
    if b != 0:
        if isinstance(b, (int, float)):
            result = a / b
            return result
        else:
            return "Не число"
    else:
        return "Деление на 0"

С guard clause — плоский код

def divide(a, b):
    if b == 0:
        return "Деление на 0"
    if not isinstance(b, (int, float)):
        return "Не число"
    return a / b  # основная логика

print(divide(10, 2))   # 5.0
print(divide(10, 0))   # Деление на 0
Guard clause = «выйти пораньше». Проверяй граничные случаи сначала, а основную логику пиши без вложений.

return внутри цикла — линейный поиск

def min_max(lst): """Возвращает (минимум, максимум) за один проход.""" mn = lst[0] mx = lst[0] for item in lst: if item < mn: mn = item if item > mx: mx = item return mn, mx # кортеж из двух значений! def divmod_custom(a, b): """Возвращает (частное, остаток).""" return a // b, a % b # Распаковка: scores = [78, 91, 55, 88, 100, 63] low, high = min_max(scores) print(f"Мин: {low}, Макс: {high}") print(f"Разброс: {high - low}") q, r = divmod_custom(17, 5) print(f"\n17 / 5 = {q} остаток {r}") # Можно и так: result = min_max(scores) print(f"\nКак кортеж: {result}")

Словарь урока 19

return
Возвращает значение из функции. После return — функция сразу завершается.
функция-действие
Делает что-то (выводит, меняет) и не возвращает значение. Например: show_map().
функция-вычислитель
Вычисляет и возвращает результат через return. Например: add(a, b).
None
Если функция без return — Python возвращает None. Частая ловушка: x = func() где func только печатает.
guard clause
Ранний return в начале функции для проверки граничных условий. Делает код плоским.
предикат
Функция, возвращающая True/False. Пример: is_even(n), is_alive(hp).
