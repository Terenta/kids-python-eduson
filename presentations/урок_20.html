is_prime(n)

Возвращает True если n простое. Делители проверяются до √n.

is_prime(7) → True
is_prime(9) → False

average(nums)

Возвращает среднее значение списка. Важно: проверить, что список не пустой.

average([4,8,6]) → 6.0

roll_dice(n=1)

Бросает n кубиков, возвращает список результатов. Параметр по умолчанию n=1.

roll_dice(3) → [4, 1, 6]
Ключевой вопрос: return — функция отвечает на вопрос. Без return функция отвечает None.

Блок 2: расстановка и выстрел

place_ships() и shoot() — ядро игровой механики

Python
import random def create_board(size): return [["." for _ in range(size)] for _ in range(size)] def place_ships(board, count): size = len(board) placed = 0 while placed < count: y = random.randint(0, size - 1) x = random.randint(0, size - 1) if board[y][x] == ".": board[y][x] = "S" placed += 1 def shoot(board, y, x): cell = board[y][x] if cell == "S": board[y][x] = "X" return "hit" elif cell == ".": board[y][x] = "O" return "miss" return "repeat" def is_defeated(board): for row in board: if "S" in row: return False return True board = create_board(5) place_ships(board, 3) result = shoot(board, 0, 0) print(f"Выстрел в [0][0]: {result}") print(f"Все потоплены? {is_defeated(board)}")

place_ships — пошаговая трассировка

Как алгоритм гарантирует расстановку ровно N кораблей

Алгоритм retry loop

  1. Генерируем случайные y, x через random.randint
  2. Проверяем: клетка свободна (== ".")?
  3. Если да — ставим "S", увеличиваем placed
  4. Если нет — пробуем снова (while продолжается)
  5. Стоп: placed == count

Трассировка для 3×3, 2 корабля

Попытка 1: y=1, x=2 → "." → S ✓ placed=1
Попытка 2: y=1, x=2 → "S" → пропуск
Попытка 3: y=0, x=0 → "." → S ✓ placed=2
placed==count → выход из while
Если count больше size×size — бесконечный цикл! Всегда проверяй: count < size*size.

Карта состояний клетки

Каждая клетка поля может быть в одном из четырёх состояний

.

Вода (начальное)

Неисследованная клетка. Выстрел возможен.

S

Корабль (скрытое)

Стоит корабль. Скрыт от соперника. Уязвим.

X

Попадание (финальное)

Корабль потоплен. shoot() вернула "hit". Необратимо.

O

Промах (финальное)

Выстрел в воду. shoot() вернула "miss". Необратимо.

Переходы состояний

. ──place_ships──► S
. ──shoot→miss──► O
S ──shoot→hit───► X

O и X — финальные. Назад пути нет.

Типичные ошибки в «Морском бое»

Три ошибки, которые встречает каждый — и как их исправить

IndexError

board[5][0]  # ❌ поле 5×5
# IndexError: list index
#             out of range
# Исправление:
if 0 <= y < size and \
   0 <= x < size:
    ...

Off-by-one

# Ввод "A1" → row=1
row = int(s[1:])     # ❌
# A1 → строка 0, не 1!
row = int(s[1:]) - 1 # ✓
# всегда -1 для перевода

Aliasing

row = ["."] * 5
board = [row] * 5  # ❌
# все строки — один объект!
board = [["."]*5
         for _ in range(5)] # ✓
Видишь IndexError: list index out of range — сразу проверяй границы. Aliasing: изменение одной строки меняет все.
