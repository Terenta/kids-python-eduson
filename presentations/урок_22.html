Алгоритм: работа с файлом

5 шагов — работает для любого файлового задания

  1. Выбери режим: "r" — читать, "w" — писать заново, "a" — дописывать в конец.
  2. Открой файл через with: with open("файл.txt", "режим", encoding="utf-8") as f:
  3. Выполни операцию: f.read(), f.write("текст\n"), или for line in f:
  4. Обработай данные: распечатай, сохрани в переменную, обработай строки через .strip()
  5. Закрытие — автоматически: блок with закрывает файл сам. Ничего дополнительно делать не нужно.

Память vs файл

Почему данные исчезают и как их сохранить навсегда

🧠

Переменная = голова

  • Быстрая и удобная
  • Хранится в RAM (оперативная память)
  • Когда выключил компьютер — забыл
  • При закрытии программы — исчезает
📓

Файл = тетрадка

  • Медленнее, но надёжнее
  • Хранится на диске (SSD/HDD)
  • Выключил компьютер — осталась
  • Можно открыть через год
Любая игра, любое приложение, любой сайт — всё хранит данные в файлах или базах данных. Ты учишься как настоящий разработчик!

# Симуляция сохранения настроек в settings.txt settings = { "volume": 80, "brightness": 65, "fullscreen": True, "language": "ru", "difficulty": "medium", } def save_settings(settings): """Симулируем запись в settings.txt""" lines = [] for key, value in settings.items(): lines.append(f"{key}={value}") print("=== Сохранение settings.txt ===") for line in lines: print(f" {line}") return lines def load_settings(lines): """Симулируем чтение settings.txt""" loaded = {} for line in lines: key, value = line.split("=", 1) loaded[key] = value return loaded # Сохраняем saved = save_settings(settings) # Загружаем обратно print("\n=== Загрузка settings.txt ===") loaded = load_settings(saved) print(f"Громкость: {loaded['volume']}%") print(f"Яркость: {loaded['brightness']}%") print(f"Язык: {loaded['language']}") print(f"Сложность: {loaded['difficulty']}") print("\nНастройки загружены успешно!")

open() и три режима

r — читать, w — писать с нуля, a — дописывать

"r" — read

Открыть для чтения. Файл должен существовать. Если нет — FileNotFoundError.

with open("f.txt", "r") as f:
    content = f.read()
    print(content)

"w" — write

ОПАСНО: удаляет старое содержимое и пишет заново!

with open("f.txt", "w") as f:
    f.write("Новый текст\n")
# Старое ИСЧЕЗЛО!

"a" — append

Дописывает в конец. Старое сохраняется. Безопасно!

with open("f.txt", "a") as f:
    f.write("Ещё строка\n")
# Старое НЕ тронуто

Всегда указывай encoding="utf-8" при работе с текстом на кириллице. Иначе получишь кракозябры.

with open() — золотой стандарт

Автоматически закрывает файл — никогда не забудешь

Без with — опасно

f = open("f.txt", "r")
data = f.read()
# если здесь ошибка...
process_data(data)
f.close()  # может не выполниться!

Если возникнет исключение, f.close() не вызовется — файл останется открытым.

С with — безопасно

with open("f.txt", "r") as f:
    data = f.read()
    process_data(data)
# файл закрыт АВТОМАТИЧЕСКИ
# даже если была ошибка

Блок with гарантирует закрытие файла в любом случае.

Три способа прочитать файл

read(), readline(), for line in f — разные ситуации

f.read()

Читает весь файл одной строкой. Удобно для небольших файлов.

with open("f.txt", "r",
         encoding="utf-8") as f:
    all_text = f.read()
    print(all_text)

f.readline()

Читает одну строку за вызов. Курсор двигается вперёд.

with open("f.txt", "r",
         encoding="utf-8") as f:
    first = f.readline()
    second = f.readline()
    print(first, second)

for line in f

Читает построчно. Идеально для больших файлов. Самый популярный способ.

with open("f.txt", "r",
         encoding="utf-8") as f:
    for line in f:
        print(line.strip())
line.strip() — убирает символ \n в конце каждой строки. Без него вывод будет с лишними пустыми строками.

Типичные ошибки с файлами

Предупреждён — значит вооружён

"w" уничтожает данные

# Первый запуск — всё хорошо
with open("f.txt", "w") as f:
    f.write("Важные данные")

# Второй запуск — данные СНЕСЕНЫ!
with open("f.txt", "w") as f:
    f.write("Новое")
# "Важные данные" — нет!

Решение: используй "a" для дозаписи!

Забыл encoding

# Плохо — кракозябры!
with open("f.txt", "r") as f:
    print(f.read())

# Правильно:
with open("f.txt", "r",
          encoding="utf-8") as f:
    print(f.read())

Правило: ВСЕГДА encoding="utf-8"

FileNotFoundError

with open("no_file.txt", "r") as f:
    # FileNotFoundError!
    # Файл не существует

Решение: проверь путь или используй try/except (урок 23)

Нет \n в конце строки

with open("f.txt", "a") as f:
    f.write("Строка 1")
    f.write("Строка 2")
# В файле: "Строка 1Строка 2"
# Нужно: f.write("Строка 1\n")

Всегда заканчивай строку символом \n.

5 вопросов — проверь что усвоил на этом уроке

  1. Вопрос 1. Какой режим нужно использовать чтобы дописать строку в конец файла не удалив старое содержимое?
    Ответ: режим "a" (append)
  2. Вопрос 2. Зачем нужна конструкция with open()? Что произойдёт с файлом если её не использовать и программа упадёт с ошибкой?
    Ответ: with автоматически закрывает файл — даже при ошибке. Без него файл может остаться открытым и занятым.
  3. Вопрос 3. Зачем вызывать .strip() при чтении строк из файла?
    Ответ: убирает \n и пробелы по краям, иначе вывод будет с лишними пустыми строками.
  4. Вопрос 4. Какая ошибка возникнет если открыть несуществующий файл в режиме "r"?
    Ответ: FileNotFoundError
  5. Вопрос 5. Почему важно писать encoding="utf-8" при работе с текстовыми файлами содержащими кириллицу?
    Ответ: без явного encoding Python может использовать системную кодировку Windows (cp1251) и текст превратится в кракозябры.

# ★★ Менеджер задач с приоритетами # Симуляция работы с файлом tasks.txt tasks = [] # имитирует содержимое файла def add_task(text, priority="normal"): """Добавляем задачу (режим 'a' в реальном коде)""" entry = f"[{priority.upper()}] {text}" tasks.append(entry) print(f" + Добавлено: {entry}") def show_tasks(filter_priority=None): """Читаем задачи (режим 'r' в реальном коде)""" print(f"\n=== Задачи {'(все)' if not filter_priority else '(' + filter_priority + ')'} ===") found = 0 for i, task in enumerate(tasks, 1): if filter_priority is None or filter_priority.upper() in task: print(f" {i}. {task}") found += 1 if found == 0: print(" (нет задач)") print(f" Итого: {found} задач") def complete_task(number): """Отметить выполненной — перезаписать файл (режим 'w')""" if 1 <= number <= len(tasks): old = tasks[number - 1] tasks[number - 1] = old.replace("[", "[DONE_").rstrip() + " ✓" print(f" Выполнено: {tasks[number-1]}") else: print(f" Ошибка: задача #{number} не существует") def stats(): high = sum(1 for t in tasks if "[HIGH]" in t) done = sum(1 for t in tasks if "[DONE_" in t) print(f"\n=== Статистика ===") print(f" Всего: {len(tasks)}") print(f" Срочных: {high}") print(f" Выполнено: {done}") print(f" Осталось: {len(tasks) - done}") # Заполняем задачи print("=== Заполнение tasks.txt ===") add_task("Написать функцию save_hero()", "high") add_task("Изучить режимы r / w / a", "normal") add_task("Сделать ДЗ по файлам", "high") add_task("Добавить таблицу рекордов в игру", "normal") add_task("Прочитать про CSV формат", "low") # Показываем все show_tasks() # Только срочные show_tasks("high") # Выполняем первую complete_task(1) # Итоговая статистика stats()

  2. Счётчик строк — прочитай любой .txt файл построчно (for line in f) и посчитай сколько строк. Выведи: «В файле N строк».
  3. Пронумерованный вывод — прочитай todo.txt, выведи каждую задачу с номером: «1. Купить хлеб», «2. Написать код». Используй enumerate().
  4. Бонус: Рекордсмен — создай scores.txt, запиши 5 имён с очками (режим "a"), прочитай назад и найди максимум. Выведи: «Рекордсмен: Имя — N очков».
  5. Бонус: Очистка дневника — создай программу-меню: «1 — добавить запись, 2 — прочитать, 3 — очистить». При выборе 3 перезапиши файл пустой строкой через режим "w".
