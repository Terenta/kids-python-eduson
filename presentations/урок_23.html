try/except - ремень безопасности

Программа продолжает работу даже если что-то пошло не так

Синтаксис try / except

Структура блока обработки ошибок

Минимальная версия

try:
    # Рискованный код
    result = 10 / 0
except ZeroDivisionError:
    # Что делать при ошибке
    print("Нельзя делить на 0!")

С несколькими except

try:
    f = open("data.txt")
except FileNotFoundError:
    print("Файл не найден")
except PermissionError:
    print("Нет доступа")
else:
    print("Всё хорошо!")
  • except без типа ошибки поймает любую ошибку - используй осторожно
  • Можно написать несколько except для разных типов ошибок

readlines() vs for line in f

Два способа читать построчно - разные возможности

readlines() - список

Читает ВСЕ строки сразу. Можно индексировать.

with open("f.txt", "r",
         encoding="utf-8") as f:
    lines = f.readlines()

first = lines[0].strip()
last  = lines[-1].strip()
count = len(lines)
print("Строк: " + str(count))

for line in f - по одной

Читает строки по одной. Экономит память на больших файлах.

count = 0
with open("f.txt", "r",
         encoding="utf-8") as f:
    for line in f:
        count += 1
        print(line.strip())
# Весь файл не в памяти
Когда что: readlines() - когда нужен весь список сразу (сортировка, индексы). for line in f - когда файл большой или нужно только пройти по нему.

json - четыре функции

Запомни разницу: со строкой и с файлом

json.dumps(obj)
Словарь/список - в JSON-строку. "dump string" - сохранить в строку.
json.loads(str)
JSON-строка - в словарь/список. "load string" - загрузить из строки.
json.dump(obj, f)
Словарь/список - запись в файл. Второй аргумент - файловый объект.
json.load(f)
Чтение из файла - в словарь/список. Аргумент - файловый объект.
Правило: если в названии есть s в конце - работа со строкой. Без s - работа с файлом.

os.path - шпаргалка

Главные функции для работы с путями файловой системы

os.path.exists(p)
Возвращает True если файл или папка существует. Используй перед open().
os.path.join(a, b)
Собирает путь из частей. Умно ставит / или \ в зависимости от операционной системы.
os.path.basename(p)
Имя файла из пути: "/a/b/file.py" - "file.py"
os.path.dirname(p)
Папка из пути: "/a/b/file.py" - "/a/b"
os.path.splitext(p)
Разбивает имя и расширение: "file.py" - ("file", ".py")

import json save_system = {"slot_1": None, "slot_2": None, "slot_3": None} def save_to_slot(slot, player, level, score): if slot not in save_system: print("Слот " + slot + " не существует!") return False save_system[slot] = {"player": player, "level": level, "score": score} print("Сохранено в " + slot + ": " + player + " (ур. " + str(level) + ", " + str(score) + " очков)") return True def load_from_slot(slot): data = save_system.get(slot) if data is None: print("Слот " + slot + " пуст") return None print("Загружено из " + slot + ": " + data["player"]) return data def show_all_saves(): print("=== Все сохранения ===") for slot, data in save_system.items(): if data: print(" " + slot + ": " + data["player"] + " - ур." + str(data["level"]) + ", " + str(data["score"]) + " очков") else: print(" " + slot + ": [пусто]") def get_best_save(): saves = [(s, d) for s, d in save_system.items() if d] if not saves: return None return max(saves, key=lambda x: x[1]["score"]) save_to_slot("slot_1", "Зорро", 7, 4200) save_to_slot("slot_2", "Аня", 12, 8900) save_to_slot("slot_3", "Боря", 3, 1500) show_all_saves() result = get_best_save() best_slot, best_data = result print("\nЛучшее: " + best_slot + " - " + best_data["player"] + " (" + str(best_data["score"]) + " очков)") print("\nJSON:") print(json.dumps(save_system, ensure_ascii=False, indent=2))

Практика: менеджер файлов

Объединяем os.path + JSON для отчёта о файлах

import os, json def file_info(path): return { "path": path, "exists": os.path.exists(path), "basename": os.path.basename(path), "extension": os.path.splitext(path)[1], "directory": os.path.dirname(path) } def check_files(file_list): report = {"found": [], "missing": []} for f in file_list: info = file_info(f) if info["exists"]: report["found"].append(info["basename"]) else: report["missing"].append(info["basename"]) return report files_to_check = [ "/home/user/save.json", "/home/user/todo.txt", "/tmp/game_log.txt", "C:/Games/config.ini" ] report = check_files(files_to_check) print("=== Отчёт о файлах ===") print("Найдено: " + str(len(report["found"])) + " файлов") print("Отсутствует: " + str(len(report["missing"])) + " файлов") if report["missing"]: print("\nОтсутствующие файлы:") for f in report["missing"]: print(" - " + f) print("\nJSON-отчёт:") print(json.dumps(report, ensure_ascii=False, indent=2))
