Список — шкаф, кортеж — сейф

Список [ ] — шкаф открыт

  • данные можно менять
  • добавляем через .append()
  • меняем: items[0] = "new"
  • удаляем: .remove()
  • инвентарь героя, список врагов

Кортеж ( ) — сейф закрыт

  • менять нельзя — на замке
  • только читаем: pos[0]
  • pos[0] = ... → ошибка!
  • быстрее и безопаснее списка
  • координаты (x, y), размер экрана
«Круглые скобки — замок закрыт. Квадратные — шкаф открыт.»

Как создать кортеж

Python
# Координаты точки — классический кортеж spawn = (10, 20) print(spawn) # Дни недели — неизменяемый список days = ("пн", "вт", "ср", "чт", "пт", "сб", "вс") print(days) # Разные типы в одном кортеже — можно! hero = ("Маг", 100, True, (15, 30)) print(hero) # Одинарный кортеж — нужна запятая! single = (5,) # кортеж из одного элемента not_tup = (5) # это просто число 5 print(type(single), type(not_tup))
(5) = число 5. (5,) = кортеж. Запятая говорит Python: «это контейнер!»

Индексы — как у списка, с нуля

Python
days = ("пн", "вт", "ср", "чт", "пт", "сб", "вс") print(days[0]) # пн — первый print(days[1]) # вт print(days[-1]) # вс — последний print(len(days)) # 7 # Проверка наличия print("пт" in days) # True print("вос" in days) # False

Читаем — можно

days[0] → "пн"

days[-1] → последний элемент

Менять — нельзя

days[0] = "воскресенье"

→ TypeError!

Срезы — вырезаем кусок кортежа

Python
days = ("пн", "вт", "ср", "чт", "пт", "сб", "вс") # Срез — как у списка и строки! print(days[0:3]) # первые три: пн, вт, ср print(days[5:]) # с 6-го до конца: сб, вс print(days[:2]) # до второго: пн, вт print(days[::2]) # каждый второй # Рабочие дни vs выходные weekdays = days[:5] weekend = days[5:] print("Работа:", weekdays) print("Отдых:", weekend)
Срез кортежа возвращает новый кортеж — не список! Синтаксис [start:stop:step] одинаков для строк, списков и кортежей.

Два метода кортежа: count и index

Python
scores = (90, 75, 90, 88, 90, 60) # count() — сколько раз встречается print(scores.count(90)) # 3 # index() — на какой позиции первый раз print(scores.index(90)) # 0 print(scores.index(75)) # 1 # Остальное — через встроенные функции print(len(scores)) # 6 print(min(scores)) # 60 print(max(scores)) # 90 print(sum(scores)) # 493

count(значение)

Возвращает, сколько раз значение встречается в кортеже.

index(значение)

Возвращает индекс первого вхождения значения.

Что кортеж НЕ умеет

append, remove, sort, pop — этих методов нет. Кортеж неизменяем!

Цикл for работает как со списком

Python
days = ("пн", "вт", "ср", "чт", "пт", "сб", "вс") # Простой перебор for day in days: print("Сегодня:", day) print("---") # С номером через enumerate for i, day in enumerate(days, start=1): print(f"{i}. {day}")

Кортеж — вернуть несколько значений из функции

Python
# Python упаковывает несколько return-значений в кортеж! def get_stats(scores): return min(scores), max(scores), sum(scores) // len(scores) results = (90, 75, 88, 60, 95, 70) # Получаем три значения сразу через распаковку low, high, avg = get_stats(results) print(f"Минимум: {low}") print(f"Максимум: {high}") print(f"Среднее: {avg}") # Без распаковки — получаем кортеж stats = get_stats(results) print(type(stats)) # print(stats) # (60, 95, 79)
return a, b, c → Python сам делает кортеж (a, b, c). Распаковка: x, y, z = func().

zip() — сшиваем кортежи в пары

Python
heroes = ("Маг", "Воин", "Лучник") scores = (2400, 3100, 1850) levels = (7, 9, 5) # zip сшивает три кортежа в тройки for hero, score, lvl in zip(heroes, scores, levels): print(f"{hero:10} Уровень {lvl} Очки: {score}") print("---") # Координаты точек xs = (1, 3, 5, 7) ys = (2, 4, 6, 8) points = tuple(zip(xs, ys)) print("Точки:", points)

Ловушки для новичков

(5) — не кортеж!

Это просто число 5 в скобках. Одинарный кортеж: (5,) — нужна запятая.

Путаю ( ) и [ ]

Мнемоника: скобка КРУГЛАЯ — ЗАКРЫТАЯ (кортеж). КВАДРАТНАЯ — ОТКРЫТАЯ (список).

Индекс с нуля

days[1] — это ВТОРНИК, не понедельник. Считаем с нуля, как хакеры!

.append() не работает

У кортежа нет методов изменения — они не существуют. Это не баг, это фишка!

Когда кортеж, когда список?

Кортеж — данные постоянны

  • координаты точки (x, y)
  • размер экрана (800, 600)
  • RGB цвет (255, 0, 128)
  • дни недели
  • константы уровня игры

Список — данные меняются

  • инвентарь героя (берём/кладём предметы)
  • список врагов (они умирают)
  • угаданные буквы в игре
  • очередь заданий
  • результаты с сервера

Бонус: именованные кортежи — кортеж+

Кортеж — это сейф

Создаётся один раз через (). Данные нельзя изменить — это гарантия надёжности.

hero = ("Маг", 40, True)
🔢

Индекс и срез

Читаем по номеру от 0. Срез берёт часть. Метод .count() и .index() — весь инструментарий.

hero[0]  # "Маг"
hero[1:] # (40, True)
⚡

Когда использовать

Константы, координаты, RGB, возврат нескольких значений из функции — всё это кортежи.

def info(): return "Маг", 40
name, hp = info()
Правило EdusonGames: кортеж — когда данные должны быть «заморожены»; список — когда они живут и меняются.

ДЗ бонус: координаты для PyGame 🎮

Кортежи — любимый тип данных игровых разработчиков. Точки, цвета, размеры окон — всё хранится в кортежах.

# === EdusonGames: настройки уровня === SCREEN = (800, 600) # ширина и высота окна PLAYER_START = (100, 300) # стартовая позиция героя # Точки появления врагов (кортеж кортежей) SPAWN_POINTS = ( (750, 50), (750, 200), (750, 400), (750, 550), ) # Цвета героев (R, G, B) COLORS = { "Маг": (124, 58, 237), "Воин": (6, 182, 212), "Лучник": (245, 158, 11), } print(f"Окно: {SCREEN[0]}×{SCREEN[1]}") print(f"Старт игрока: {PLAYER_START}") print(f"\nТочки появления врагов:") for i, point in enumerate(SPAWN_POINTS): x, y = point # распаковка кортежа print(f" Враг {i+1}: x={x}, y={y}") print(f"\nЦвет Мага: {COLORS['Маг']}") r, g, b = COLORS["Маг"] print(f" R={r}, G={g}, B={b}")
  • — SCREEN, PLAYER_START — кортежи-константы, менять нельзя
  • — SPAWN_POINTS — кортеж из кортежей: координаты четырёх врагов
  • — Распаковка x, y = point — читаем поля без индексов
