Инструмент для всех этих задач — множество (set).

Какой контейнер выбрать?

Быстрое сравнение

list — порядок ✓, дубли ✓, индексы ✓
tuple — порядок ✓, дубли ✓, неизменяем
set — порядка нет, дубли нет, быстрый in
dict — ключ→значение, ключи уникальны

Когда set?

Нужна уникальность. Нужно быстро проверить «есть ли X». Нужны операции пересечения/разности.

Когда не set?

Важен порядок. Нужен доступ по индексу. Нужны дубликаты (счётчик очков).

Множество — мешок с уникальными конфетами

Мешок Деда Мороза

В мешке каждой конфеты — ровно по одной. Бросишь вторую «Мишку» — она не удвоится. Мешок знает!

Порядка нет

Конфеты перемешаны. Нельзя сказать «первая конфета» — индексов нет. Только: «Есть ли Мишка?»

Python
# Создаём множество — дубли исчезают! candies = {"Мишка", "Белочка", "Мишка", "Кис-кис"} print("Конфеты:", candies) candies.add("Гулливер") candies.add("Мишка") # дубль — ничего! print("После add:", candies) print("Мишка есть?", "Мишка" in candies) print("Всего:", len(candies))

Итерация по множеству: for … in set

Python
achievements = {"Первый старт", "Спидран", "Без смертей"} # Итерируем — порядок не гарантирован! print("Ачивки игрока:") for ach in achievements: print(" •", ach) # Если нужен порядок — sorted() print("\nПо алфавиту:") for ach in sorted(achievements): print(" •", ach) # Нельзя: achievements[0] → TypeError!

Работает ✓

  • for x in s: — перебор
  • x in s — проверка
  • len(s) — размер
  • sorted(s) — сортированный список

Не работает ✗

  • s[0] — нет индексов!
  • s[-1] — тоже нет!
  • s[1:3] — срезы невозможны

Подмножество и надмножество: issubset / issuperset

Python
all_perms = {"read", "write", "delete", "admin"} user_perms = {"read", "write"} guest_perms = {"read"} # Проверяем права print("user < all?", user_perms.issubset(all_perms)) print("all > user?", all_perms.issuperset(user_perms)) # Непересекающиеся? a = {"Python", "Go"} b = {"Java", "C++"} print("Общие языки?", not a.isdisjoint(b)) # False = нет общих # Оператор-синоним print(user_perms <= all_perms) # issubset print(all_perms >= user_perms) # issuperset

.issubset(B) / A <= B

Все элементы A есть в B? «A полностью входит в B»

.issuperset(B) / A >= B

Все элементы B есть в A? «A содержит B целиком»

.isdisjoint(B)

Нет ни одного общего элемента? Возвращает True если пересечение пустое.

Диаграмма Эйлера–Венна

| Объединение — A | B

Все, кто есть хотя бы в одном наборе.

& Пересечение — A & B

Только те, кто есть в обоих.

- Разность — A - B

Есть в A, но нет в B.

Операции над множествами в Python

Python
a = {"Саша", "Катя", "Петя"} b = {"Катя", "Лена", "Миша"} print("Объединение |:", a | b) print("Пересечение &:", a & b) print("Только A:", a - b) print("Только B:", b - a) print("Симм. разность ^:", a ^ b) # Методы — то же самое print("---") print("union:", a.union(b)) print("intersection:", a.intersection(b))

Операции с присваиванием: |= &= -=

Python
online = {"Катя", "Петя"} print("До:", online) # Добавить новых игроков new_players = {"Миша", "Оля", "Петя"} online |= new_players # = online.update(new_players) print("После |=:", online) # Оставить только тех, кто в обоих premium = {"Катя", "Миша"} online &= premium # = online.intersection_update(premium) print("После &=:", online) # Удалить плохих игроков banned = {"Миша"} online -= banned # = online.difference_update(banned) print("После -=:", online)
|= — добавить элементы из другого множества (как extend для списка, но без дублей).

set vs frozenset

set — изменяемое
frozenset — неизменяемое

Когда frozenset?

  • Ключ словаря
  • Элемент другого множества
  • Константа — изменять нельзя

Методы: add, discard, remove

Python
guessed = set() guessed.add("а") guessed.add("е") guessed.add("а") # дубль — ничего! print(guessed) # {'а', 'е'} # discard — тихо если нет guessed.discard("ё") # молчит print(guessed) # remove — шумит если нет! # guessed.remove("ё") # KeyError! print("а есть?", "а" in guessed) print("Размер:", len(guessed))

.add(x)

Добавляет. Если уже есть — молчит.

.discard(x)

Удаляет. Если нет — молчит. Безопаснее!

.remove(x)

Удаляет. Если нет — KeyError!

Почему set быстрее для проверки in

Python
import time # Создаём большие коллекции big_list = list(range(100000)) big_set = set(range(100000)) target = 99999 # Список — ищет с начала до конца t0 = time.time() for _ in range(1000): _ = (target in big_list) t1 = time.time() print(f"list: {(t1-t0)*1000:.1f} мс") # Множество — мгновенно! t0 = time.time() for _ in range(1000): _ = (target in big_set) t1 = time.time() print(f"set: {(t1-t0)*1000:.1f} мс")

Список — O(n)

Проверяет каждый элемент по очереди. 100 000 элементов — 100 000 проверок.

Множество — O(1)

Хэш-таблица. Знает, где искать, сразу. 100 000 или 100 000 000 элементов — почти одинаково быстро!

Проверьте себя: множества

  1. Как создать пустое множество?  → set(), НЕ {}
  2. Что произойдёт при s.add("а"); s.add("а")?  → Множество не изменится, дубль игнорируется

scores = [85, 90, 78, 85, 90, 100, 78, 95] # List comprehension — с дублями above_list = [s for s in scores if s >= 85] print("list:", above_list) # Set comprehension — без дублей, фигурные скобки! above_set = {s for s in scores if s >= 85} print("set: ", above_set) # Уникальные первые буквы слов words = ["питон", "программа", "переменная", "цикл", "список"] first_letters = {w[0] for w in words} print("Первые буквы:", first_letters) # Уникальные длины слов lengths = {len(w) for w in words} print("Длины:", lengths)

Типичные ошибки с множествами

❌ Неправильно:

empty = {}       # это словарь!
s = {1, 2, 3}
print(s[0])      # TypeError!
s.append(4)      # AttributeError!

✓ Правильно:

empty = set()    # пустое множество
s = {1, 2, 3}
print(1 in s)    # проверка через in
s.add(4)         # добавляем через add
Python

Словарь урока: множества

set

Изменяемое множество — без дубликатов, без порядка.

frozenset

Неизменяемое множество — можно хранить в dict или set.

Хэш-таблица

Структура данных set под капотом — делает поиск O(1).

Операции | & - ^

Объединение, пересечение, разность, симметричная разность.

Set comprehension

{expr for x in iterable} — генератор множества.

Диаграмма Венна

Визуализация отношений между множествами через пересекающиеся круги.

Итог урока: 3 факта о множествах

Без дубликатов

Каждый элемент — один раз. set() — пустое. Не {}!

Без порядка

Нет [0], нет индексов. Проверяй: x in s.

Операции | & -

Объединение, пересечение, разность. Диаграмма Венна!

Множество — мешок, в котором каждой вещи ровно по одной. Индексов нет — ищи через in. Скорость — O(1)!
