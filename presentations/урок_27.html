Список, множество, словарь — когда что?

Список []

  • Порядок сохраняется
  • Дубли разрешены
  • Доступ по индексу
  • Инвентарь, история ходов

Множество {}

  • Нет дублей
  • Нет порядка
  • Быстрая проверка
  • Угаданные буквы, теги

Словарь {k:v}

  • Ключ → значение
  • Ключи уникальны
  • Быстрый поиск
  • Карточка героя, настройки

Словарь — телефонная книга

В настоящем словаре каждое слово (ключ) имеет своё объяснение (значение). В Python — то же самое: каждый ключ указывает на своё значение.

Телефонная книга

"Мама" → "+7-900-1234"
"Антон" → "+7-900-5678"
"Катя" → "+7-900-9999"

Карточка персонажа

"name" → "Маг"
"hp" → 100
"damage" → 25

Правила словаря

  • Ключи — уникальны
  • Значения — любые
  • Порядок сохраняется

Создание и чтение словаря

Python
# Карточка персонажа — словарь hero = { "name": "Маг", "hp": 100, "mp": 80, "damage": 25, "level": 5 } # Читаем по ключу print(hero["name"]) # Маг print(hero["hp"]) # 100 # Изменяем hero["hp"] = 90 # получил урон hero["level"] += 1 # повысился уровень print(hero["hp"], hero["level"]) # Добавляем новое поле hero["weapon"] = "посох молний" print(hero["weapon"])

.get() — безопаснее чем [ ]

Python

# Подсчёт голосов votes = ["Маг", "Воин", "Маг", "Лучник", "Маг", "Воин", "Маг"] counter = {} for vote in votes: counter[vote] = counter.get(vote, 0) + 1 print("Результаты голосования:", counter) # Найти победителя winner = max(counter, key=counter.get) print(f"Победитель: {winner} ({counter[winner]} голосов)") # Подсчёт букв в слове word = "python" letters = {} for ch in word: letters[ch] = letters.get(ch, 0) + 1 print("Буквы в 'python':", letters)

3 факта о словарях

Ключ → Значение

Создаём через { } с двоеточием. Ключи уникальны! Значения — любые: число, строка, список, даже словарь.

.get() безопаснее

d["x"] падает с KeyError. d.get("x", 0) возвращает 0. Всегда используй .get()!

for key, val in .items()

Глоссарий: словари от А до Я

dictСловарь — структура данных ключ:значение в фигурных скобках
ключУникальный идентификатор элемента (строка, число, кортеж)
значениеДанные по ключу — любого типа: число, строка, список, словарь
.get(k, d)Безопасное чтение — возвращает d если ключ k не найден
.items()Пары (ключ, значение) — используй в цикле for k, v in d.items()

.setdefault()Установить значение ТОЛЬКО если ключа нет

Бонус: Какое слово самое длинное?

Python
# Задача: посчитать длины слов и найти самое длинное words = ["python", "словарь", "переменная", "цикл", "функция", "список"] # Шаг 1: словарь слово -> длина lengths = {} for word in words: lengths[word] = len(word) print("Длины слов:", lengths) # Шаг 2: самое длинное longest = max(lengths, key=lengths.get) print(f"Самое длинное: '{longest}' ({lengths[longest]} букв)") # Шаг 3: слова длиннее 6 букв long_words = {w: l for w, l in lengths.items() if l > 6} print("Длинные слова:", long_words)
