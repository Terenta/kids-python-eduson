  • Константные наборы (слова, координаты)
  • Быстрее списка при чтении

WORDS = ("python", ...) — кортеж гарантирует, что список слов никто не изменит случайно в процессе игры.

Функция show() — сердце игры

def show(word, guessed): """Возвращает строку с угаданными буквами и _""" return " ".join(c if c in guessed else "_" for c in word) # Тестируем secret = "питон" guessed = {"п", "т"} result = show(secret, guessed) print(result) # п _ т _ н # Проверяем победу guessed2 = {"п", "и", "т", "о", "н"} print(show(secret, guessed2)) # п и т о н print("Победа?", "_" not in show(secret, guessed2))

Генераторное выражение — разбор

c if c in guessed else "_"  for  c  in  word

  1. for c in word — берём каждый символ слова по очереди
  2. if c in guessed — проверяем, есть ли буква в множестве угаданных
  3. c — если да, показываем букву
  4. "_" — если нет, показываем подчёркивание
  5. " ".join(...) — соединяем всё через пробел: п _ т _ н

Трассировка: следим за кодом

Слово: "питон" · Угаданы: {"п", "т"}
  1. c = "п" → "п" in {"п","т"} → True → показываем "п"
  2. c = "и" → "и" in {"п","т"} → False → показываем "_"
  3. c = "т" → "т" in {"п","т"} → True → показываем "т"
  4. c = "о" → "о" in {"п","т"} → False → показываем "_"
  5. c = "н" → "н" in {"п","т"} → False → показываем "_"
  6. join(["п","_","т","_","_"]) → "п _ т _ _"
Python
def show(word, guessed): return " ".join(c if c in guessed else "_" for c in word) # Тест трассировки word = "питон" guessed = {"п", "т"} print(show(word, guessed)) # п _ т _ _ # Проверка победы — нет ни одного "_" won = "_" not in show(word, guessed) print(f"Победа? {won}") # Добавим все буквы guessed2 = set("питон") print(show(word, guessed2)) # п и т о н print(f"Победа? {'_' not in show(word, guessed2)}")

Виселица — полный код

Python
import random # Кортеж слов — неизменяемый! WORDS = ("python", "kortezh", "mnozhestvo", "slovar", "viselitsa", "programma") def show(word, guessed): return " ".join(c if c in guessed else "_" for c in word) def play(): secret = random.choice(WORDS) guessed = set() # множество угаданных букв lives = 6 print(f"\nСлово из {len(secret)} букв. Жизни: {lives}") while lives > 0: shown = show(secret, guessed) print(f"\nСлово: {shown}") print(f"Жизни: {lives}/6") if "_" not in shown: print(f"POBEDA! Слово: {secret}") return True letter = input("Буква: ").lower().strip() if not letter or len(letter) != 1: print("Введи одну букву!"); continue if letter in guessed: print("Уже вводил!"); continue guessed.add(letter) if letter in secret: print(f"'{letter}' есть в слове!") else: lives -= 1 print(f"'{letter}' нет. Жизни: {lives}") print(f"PORAZHENIE! Слово было: {secret}") return False # Статистика — словарь! stats = {"победы": 0, "поражения": 0} if play(): stats["победы"] += 1 else: stats["поражения"] += 1 print(f"Счёт: {stats}")

Напиши свой главный цикл

  1. Выбрать случайное слово: random.choice(WORDS)
  2. Создать guessed = set() и lives = 6
  3. Цикл while lives > 0:
  4. Внутри: показать слово, ввести букву, проверить повтор
  5. Если буква в слове → guessed.add()
  6. Если нет → lives -= 1
  7. Проверить победу: "_" not in shown

Частые баги

  • Забыл .lower() → «А» и «а» разные
  • Нет проверки повтора → теряются жизни зря
  • Бесконечный цикл → нет условия победы!
Золотое правило: сначала план на бумаге, потом код. Всегда рисуй поток данных перед написанием!

Пользователь нажал Enter или вставил слово. Решение:

Генераторное выражение

Компактный способ создать список или строку: x for x in iterable if условие. Работает внутри join(), sum(), list().

Трассировка (trace)

Мысленное выполнение кода по шагам — отслеживание значений переменных. Главный инструмент отладки без дебаггера.

Капстоун-проект

Финальный проект, объединяющий несколько тем. Виселица = кортеж + множество + словарь + функции + цикл.

ASCII-арт

Рисунки из символов: O, /, |, \. В нашей Виселице — 7 стадий виселицы из текстовых символов.

Четыре контейнера Python

Список [ ]

Порядок важен. Можно менять. Инвентарь, список врагов, очередь действий.

Кортеж ( )

Порядок важен. Нельзя менять. Координаты, константы, параметры.

Множество set()

Порядка нет. Только уникальные. Угаданные буквы, ачивки, теги.

Словарь { : }

Ключ → значение. Карточка персонажа, настройки, счётчик.

Теперь ты знаешь, когда использовать каждый контейнер — это профессиональный навык разработчика.

Когда какой контейнер?

  1. Нужен порядок, буду менять? → list [ ]
    Инвентарь, история ходов, очередь
  2. Нужен порядок, менять не буду? → tuple ( )
    Список слов, координаты, константы
  3. Нужна только уникальность? → set()
    Угаданные буквы, достижения, теги
  4. Нужен поиск по имени? → dict { : }
    Счёт, карточка героя, настройки

# Сохранение рекорда между сессиями import json def load_record(filename="record.json"): try: with open(filename) as f: return json.load(f) except: return {"лучший_счёт": 0, "игр": 0} def save_record(data, filename="record.json"): with open(filename, "w") as f: json.dump(data, f, ensure_ascii=False) # Симуляция использования record = load_record() record["игр"] += 1 new_score = 150 if new_score > record["лучший_счёт"]: record["лучший_счёт"] = new_score print(f"Новый рекорд! {new_score} очков!") save_record(record) print(f"Статистика: {record}")
