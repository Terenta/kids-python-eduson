Атрибуты и методы — в чём разница?

Атрибуты — что объект ИМЕЕТ

Это данные, характеристики. Существительные.

self.name = "Маг"
self.hp = 100
self.mp = 80
self.damage = 25

Методы — что объект УМЕЕТ

Это действия, поведение. Глаголы.

def attack(self): ...
def heal(self): ...
def level_up(self): ...
def is_alive(self): ...
«Атрибут — что у объекта ЕСТЬ. Метод — что объект УМЕЕТ делать. Как карточка персонажа и список способностей.»

Первый класс: Player

Python
class Player: def __init__(self, name, hp, damage): self.name = name self.hp = hp self.damage = damage self.level = 1 def attack(self, enemy): """Атакуем врага — уменьшаем его HP""" enemy.hp -= self.damage print(f"{self.name} бьёт {enemy.name} на {self.damage}!") def is_alive(self): return self.hp > 0 def show_stats(self): status = "живой" if self.is_alive() else "мёртв" print(f"{self.name} [{status}] HP={self.hp} DMG={self.damage} LVL={self.level}") # Создаём персонажей mage = Player("Маг", 100, 25) goblin = Player("Гоблин", 40, 10) mage.show_stats() goblin.show_stats() # Бой! mage.attack(goblin) goblin.show_stats() if not goblin.is_alive(): print("Гоблин побеждён!")

Класс vs Словарь — что выбрать?

Словарь — если только данные

Просто хранить пары ключ-значение. Нет методов. Например: настройки игры, конфигурация.

config = {"width": 800, "fps": 60}

Класс — если данные + действия

Данные и методы вместе. Несколько экземпляров. Например: персонаж, враг, снаряд.

class Bullet:
def __init__(self, x, y, speed): ...
def move(self): ...
«Словари — хорошо, но классы — ещё лучше, когда у вещи есть действия. Персонаж умеет атаковать — это класс!»

Первый бой: Герой vs Монстр

Python
class Character: def __init__(self, name, hp, damage): self.name = name self.hp = hp self.damage = damage def attack(self, other): other.hp -= self.damage print(f" {self.name} -> {other.name}: -{self.damage} HP") def is_alive(self): return self.hp > 0 def status(self): hearts = "hp" * max(0, self.hp // 10) print(f"{self.name}: {hearts} ({self.hp} HP)") # Создаём бойцов hero = Character("Маг Арин", 100, 20) monster = Character("Огр", 60, 15) print("=== НАЧАЛО БОЯ ===") round_num = 1 while hero.is_alive() and monster.is_alive(): print(f"\n--- Раунд {round_num} ---") hero.attack(monster) if monster.is_alive(): monster.attack(hero) hero.status() monster.status() round_num += 1 winner = hero.name if hero.is_alive() else monster.name print(f"\nПобедитель: {winner}!")

3 факта об ООП

1. Класс = чертёж

Описывает структуру. По одному классу — много объектов с разными значениями.

2. Объект = конкретная вещь

rex = Dog("Рекс", 3) — создаём объект по классу. Это экземпляр.

3. self = «я»

Первый параметр каждого метода. Указывает на конкретный объект.

«Ты пишешь класс один раз, а объектов можешь сделать хоть сто. Скоро ты напишешь Тамагочи — реально живого питомца в коде!»

Магический метод __str__

Когда пишешь print(объект), Python ищет метод __str__. Если его нет — выводит адрес памяти. Если есть — твою строку!

class Hero: def __init__(self, name, hp, level): self.name = name self.hp = hp self.level = level def __str__(self): bar = "❤️" * (self.hp // 20) return f"[Ур.{self.level}] {self.name} | HP: {bar} ({self.hp})" def level_up(self): self.level += 1 self.hp += 10 print(f"⬆️ {self.name} повысил уровень!") hero = Hero("Артур", 80, 5) print(hero) # вызывает __str__ hero.level_up() print(hero)

Метод с параметрами: герой атакует

class Hero: def __init__(self, name, hp, attack_power): self.name = name self.hp = hp self.attack_power = attack_power def attack(self, enemy, multiplier=1): damage = self.attack_power * multiplier enemy.hp -= damage print(f"⚔️ {self.name} атакует {enemy.name} на {damage} урона!") if enemy.hp <= 0: print(f"💀 {enemy.name} побеждён!") else: print(f" {enemy.name} остаток HP: {enemy.hp}") def heal(self, amount): self.hp += amount print(f"💊 {self.name} восстановил {amount} HP (итого: {self.hp})") hero = Hero("Артур", 100, 30) enemy = Hero("Дракон", 90, 50) hero.attack(enemy) hero.attack(enemy, multiplier=2) # критический удар

Атрибуты класса vs атрибуты экземпляра

Атрибут класса

Один для всех объектов. Задаётся вне __init__. Например, счётчик созданных объектов.

Атрибут экземпляра

У каждого объекта свой. Задаётся через self.x = ... в __init__.

class Hero: count = 0 # атрибут класса — общий для всех def __init__(self, name, hp): self.name = name # атрибут экземпляра — у каждого свой self.hp = hp Hero.count += 1 # увеличиваем общий счётчик h1 = Hero("Артур", 100) h2 = Hero("Аза", 60) h3 = Hero("Брут", 120) print(f"Создано героев: {Hero.count}") # 3 print(f"HP Артура: {h1.hp}") print(f"HP Азы: {h2.hp}")

YandexGPT объясняет self 🤖

Промпт ученика:

"Объясни простыми словами — зачем нужен self в Python? Я пишу класс Hero и не понимаю, почему self всегда первый параметр."

Ответ YandexGPT:

Представь, что self — это ярлык «я сам». Когда ты пишешь hero.attack(), Python за кулисами делает Hero.attack(hero) — то есть передаёт объект первым аргументом. self — это и есть тот самый первый аргумент. Через self метод знает, чей именно HP уменьшать, чьё имя выводить.

→ Можно назвать его this или me, но все договорились писать self.

class Hero: def __init__(self, name, hp): self.name = name self.hp = hp def heal(self, amount): self.hp += amount print(f"{self.name}: HP восстановлен до {self.hp}") hero = Hero("Артур", 50) # Два способа вызвать один и тот же метод: hero.heal(30) # обычный способ Hero.heal(hero, 20) # явный способ (Python делает это за кулисами)

Добавь герою инвентарь. Класс должен уметь добавлять предметы, удалять и показывать список.

class Inventory: def __init__(self): self.items = [] def add(self, item): self.items.append(item) print(f"➕ Добавлено: {item}") def remove(self, item): if item in self.items: self.items.remove(item) print(f"➖ Удалено: {item}") else: print(f"❌ {item} не найден в инвентаре") def show(self): if self.items: print("🎒 Инвентарь:", ", ".join(self.items)) else: print("🎒 Инвентарь пуст") class Hero: def __init__(self, name): self.name = name self.inventory = Inventory() hero = Hero("Артур") hero.inventory.add("Меч") hero.inventory.add("Щит") hero.inventory.add("Зелье лечения") hero.inventory.show() hero.inventory.remove("Меч") hero.inventory.show()
