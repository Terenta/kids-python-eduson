Без наследования

Пишем name, age, eat(), sleep() отдельно для Dog, Cat и Bird — 3 раза одно и то же

Принцип DRY

Синтаксис наследования

Родительский класс (базовый)

class Animal:
    def __init__(self, name, age):
        self.name = name
        self.age  = age

    def eat(self):
        print(f"{self.name} кушает")

    def speak(self):
        print("...")

Дочерний класс (наследует)

class Dog(Animal):   # Animal в скобках!
    def __init__(self, name, age, breed):
        super().__init__(name, age)
        self.breed = breed   # своё поле

    def speak(self):         # переопределяем
        print(f"{self.name}: Гав!")
class Dog(Animal) Имя родителя в скобках — обязательно. Без этого нет наследования
super().__init__() Вызываем конструктор родителя — иначе name и age не создадутся

Dog получает автоматически

eat() и speak() от Animal — без единой строки кода!

super() — вызов родительского конструктора

Без super() — ОШИБКА

class Cat(Animal):
    def __init__(self, color):
        # super().__init__() забыли!
        self.color = color

murka = Cat("рыжая")
print(murka.name)
# AttributeError: 'Cat' object
# has no attribute 'name'

name и age никогда не были созданы — super().__init__() их создаёт!

С super() — правильно

class Cat(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age)
        # ↑ Animal.__init__ вызван!
        self.color = color

murka = Cat("Мурка", 3, "рыжая")
print(murka.name)   # Мурка ✓
print(murka.age)    # 3 ✓
print(murka.color)  # рыжая ✓
Правило super().__init__() должен быть первой строкой в __init__ дочернего класса

isinstance() и issubclass()

class Animal: pass
class Cat(Animal): pass
class Dog(Animal): pass

murka = Cat()

# isinstance — учитывает иерархию
isinstance(murka, Cat)     # True
isinstance(murka, Animal)  # True!
isinstance(murka, Dog)     # False

# issubclass — проверяет классы
issubclass(Cat, Animal)    # True
issubclass(Dog, Animal)    # True
issubclass(Cat, Dog)       # False

# type — точный тип, без иерархии
type(murka) == Cat         # True
type(murka) == Animal      # False!
isinstance(obj, Cls) → obj это Cls или любой его потомок?
issubclass(A, B) → класс A наследует B?
type(obj) == Cls → точно этот класс (иерархию игнорирует)

Множественное наследование и MRO

Python — multiple_inherit.py
class Flyable: def fly(self): print("Летим!") def describe(self): print("Я умею летать") class Swimmable: def swim(self): print("Плывём!") def describe(self): print("Я умею плавать") # Множественное наследование class Duck(Flyable, Swimmable): def quack(self): print("Кря-кря!") donald = Duck() donald.fly() # от Flyable donald.swim() # от Swimmable donald.quack() # своё donald.describe() # от Flyable (первый!) # MRO — порядок поиска методов for cls in Duck.__mro__: print(cls.__name__)

MRO — Method Resolution Order

Python ищет метод по цепочке: Duck → Flyable → Swimmable → object. Порядок — слева направо.

class Duck(Flyable, Swimmable)

Порядок в скобках важен! Flyable стоит первым — его describe() побеждает.

Посмотреть MRO Duck.__mro__ — кортеж классов в порядке поиска методов

Абстрактные классы — обязательный контракт

Python — abstract.py
from abc import ABC, abstractmethod class Shape(ABC): def __init__(self, color): self.color = color @abstractmethod def area(self): # ОБЯЗАТЕЛЕН в ребёнке! pass @abstractmethod def perimeter(self): pass def describe(self): # обычный метод print(f"Фигура цвета {self.color}") class Circle(Shape): def __init__(self, color, radius): super().__init__(color) self.radius = radius def area(self): return 3.14 * self.radius ** 2 def perimeter(self): return 2 * 3.14 * self.radius class Rectangle(Shape): def __init__(self, color, w, h): super().__init__(color) self.w, self.h = w, h def area(self): return self.w * self.h def perimeter(self): return 2 * (self.w + self.h) c = Circle("красный", 5) r = Rectangle("синий", 4, 6) c.describe() print(f"Круг: площадь={c.area():.1f}") print(f"Прямоугольник: площадь={r.area()}")

from abc import ABC

Стандартная библиотека Python. ABC — базовый класс для всех абстрактных классов.

@abstractmethod

Декоратор — помечает метод как обязательный. Забудешь реализовать — TypeError при создании объекта.

Shape() — нельзя! s = Shape("red")
TypeError: Can't instantiate abstract class Shape

Частые ошибки при наследовании

ОШИБКА 1 — забыл super().__init__()

    def __init__(self, color):
        self.color = color  # нет super()!
# murka.name → AttributeError

ИСПРАВЛЕНИЕ 1

class Cat(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age)
        self.color = color  # всё OK

class Cat(Animal):  # заглавная 'A'

Самопроверка — 5 вопросов

1. Как объявить, что Dog наследует Animal?

А) class Dog extends Animal
Б) class Dog(Animal) ✓
В) class Dog inherits Animal
Г) Dog = Animal.child()

2. Для чего нужен super().__init__()?

А) Создать новый класс
Б) Удалить родителя
В) Вызвать конструктор родителя ✓
Г) Скопировать методы

3. isinstance(murka, Animal) если Cat(Animal)?

А) False — murka это Cat
Б) True — Cat наследует Animal ✓
В) Ошибка
Г) None

4. Что такое полиморфизм?

А) Много классов без наследования
Б) Один метод — разное поведение в разных классах ✓
В) Копирование кода
Г) Скрытие данных

5. Можно ли создать объект абстрактного класса?

А) Да, всегда
Б) Да, если нет abstractmethod
В) Нет, если есть хоть один abstractmethod ✓
Г) Нет, никогда

Ответы 1-Б   2-В   3-Б   4-Б   5-В
