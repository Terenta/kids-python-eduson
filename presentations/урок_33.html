Иерархия ИИ → ML → DL

Три уровня — от широкого понятия к конкретной технологии

ИИ (Artificial Intelligence)

Любая система, имитирующая интеллект. Включает шахматные движки, рекомендательные системы, навигаторы.

ML (Machine Learning)

Программы, которые учатся на примерах. Сортировка спама, предсказание цен, распознавание изображений.

Deep Learning (нейросети)

Многослойные нейронные сети. ChatGPT, Midjourney, Алиса, Google Translate — это здесь.

Три типа машинного обучения

Supervised, Unsupervised, Reinforcement — как учится ИИ

👨‍🏫

Обучение с учителем

Supervised Learning
Данные с правильными ответами. Нейросеть учится соответствию «вход→выход».

Примеры: распознавание лиц, фильтр спама, предсказание цен
🔍

Обучение без учителя

Unsupervised Learning
Данные без меток. ИИ сам ищет паттерны и группирует похожее.

Примеры: рекомендации YouTube, сегментация игроков, аномалии
🎮

Обучение с подкреплением

Reinforcement Learning
ИИ пробует действия, получает награду/штраф, учится побеждать.

Примеры: AlphaGo, OpenAI Five (Dota2), боты в Starcraft

В нашем курсе: Мы будем использовать уже обученные модели через API. Обучение с нуля требует мощных серверов и месяцев работы — это задача для больших компаний.

Как нейросеть учится?

Данные → Паттерны → Предсказание — три шага обучения

Пример: 1 млн фото кошек с подписью «кошка» → нейросеть запоминает: вертикальные зрачки, острые уши, мягкая шерсть

Итог: Показываем новое фото — нейросеть угадывает «кошка» с точностью 99%

Важно: Нейросеть не «думает» как человек. Она ищет математические паттерны в числах

Нейросеть в Python: перцептрон

Простейшая нейросеть — без библиотек, только математика

# Простейшая нейросеть: перцептрон # Учится определять: число > 0 или нет? def activate(x): """Функция активации: 1 если x>=0, иначе 0.""" return 1 if x >= 0 else 0 def predict(inputs, weights, bias): """Перцептрон: взвешенная сумма + активация.""" total = sum(x * w for x, w in zip(inputs, weights)) return activate(total + bias) def train(data, labels, epochs=10, lr=0.1): """Обучение: корректируем веса на ошибках.""" weights = [0.0] * len(data[0]) bias = 0.0 for epoch in range(epochs): errors = 0 for inputs, label in zip(data, labels): pred = predict(inputs, weights, bias) error = label - pred # Обновляем веса weights = [w + lr * error * x for w, x in zip(weights, inputs)] bias += lr * error errors += abs(error) print(f"Эпоха {epoch+1}: ошибок = {errors}") return weights, bias # Задача: определить знак числа # Входные данные: [число], метка: 1 если>0, 0 иначе data = [[5], [-3], [8], [-1], [2], [-7]] labels = [ 1, 0, 1, 0, 1, 0 ] print("Обучаем...") w, b = train(data, labels, epochs=5) print("\nПроверяем:") for x in [3, -2, 10, -5]: r = predict([x], w, b) print(f" {x} → {'положительное' if r else 'отрицательное'}")

Галлюцинации ИИ

Когда ИИ уверенно выдаёт красивую ложь — и не знает, что врёт

⚠️

Что такое галлюцинация

ИИ «дорисовывает» ответ на основе паттернов, даже если не знает правды. Он не понимает, что врёт — просто генерирует «похожий на правду» текст.

🧪

Эксперимент

Спроси ИИ: «Расскажи об учёном Иване Петрове, который открыл теорему Петрова в 1834 году». Смотри, как уверенно появится целая биография несуществующего человека!

Где врёт часто: исторические факты, цифры, имена, даты, формулы, последние события

Где врёт редко: объяснения концепций, переводы, написание кода, творческие задачи

Как проверять: Perplexity даёт ссылки. Важные факты — гугли отдельно. Код — запускай и проверяй!

Эксперимент: поймай галлюцинацию

Задай ИИ эти вопросы — и проверь ответы

  1. Несуществующий учёный: «Расскажи об учёном Иване Сергееве, который открыл формулу пространственной волны в 1812 году»
  2. Ложная дата: «Когда именно Пушкин написал "Войну и мир"?» (это Толстой!)
  3. Математика: «Чему равно 17 × 23 × 41?» — посчитай сам и сравни
  4. Последние события: «Кто выиграл Чемпионат мира по футболу в 2026 году?»

Что фиксируем

Уверен ли ИИ в ответе?
Правильный ли ответ?
Есть ли ссылки на источники?
Как понять что это ложь?

Вывод

ИИ говорит уверенно даже когда врёт. Перцептрон не чувствует стыда за ошибку. Твоя критическая проверка — единственная защита.

Три правила работы с ИИ

Запомни как формулу — она поможет всю карьеру

  1. ИИ угадывает, а не знает точно

    Калькулятор вычисляет. Нейросеть предсказывает. Результат ИИ — это его «лучшее предположение», не истина в последней инстанции.

  2. Важное всегда проверяй

    Код из ИИ — запускай и тестируй. Факты — гугли дополнительно. Perplexity даёт ссылки — кликай по ним. Не верь слепо никогда.

  3. ИИ — помощник, не замена твоего мозга

    Сначала 5 минут думай сам. Потом — спрашивай ИИ. Если получил код от ИИ — пойми его прежде, чем использовать. Иначе учёбы нет.

Критическое мышление: когда использовать ИИ?

ИИ — как молоток. Он хорош для гвоздей, но не для шурупов

✅

ИИ отлично помогает

  • Объяснить концепцию простыми словами
  • Найти ошибку в коде и объяснить
  • Сгенерировать идеи и черновики
  • Перевести текст
  • Написать шаблонный код
⚠️

ИИ опасен без проверки

  • Точные исторические даты и имена
  • Математические вычисления (может ошибиться)
  • Медицинские советы
  • Последние события (данные устаревают)
  • Готовый «финальный» код без тестирования
