Формула промпта КРФЗ

Четыре компонента — и ИИ поймёт тебя с первого раза

📍

К

Контекст

Кто ты? Что делаешь? «Я учусь Python, мне 12 лет, пишу игру»

🎭

Р

Роль

Кем должен быть ИИ? «Ты — добрый учитель программирования для детей»

🎯

Ф

Задача

Что конкретно нужно? «Объясни ошибку IndexError простыми словами»

📋

З

Формат

Как оформить ответ? «5 строк максимум. Сначала объяснение, потом пример»

КРФЗ = Контекст + Роль + задача + формат. Это формула профессионального prompt engineering, которую используют разработчики в больших компаниях.

КРФЗ — три примера для Python

Посмотри как формула работает в реальных задачах

Пример 1 — объяснение ошибки
Я учусь Python, мне 12 лет. Ты — добрый учитель. Объясни ошибку: IndexError: list index out of range. Сначала простыми словами с метафорой, потом покажи пример кода с ошибкой и без. Максимум 8 строк.
Пример 2 — генерация кода
Я пишу игру в Python. Ты — Python-разработчик. Напиши функцию is_prime(n), которая проверяет, простое ли число. Добавь комментарий к каждой строке. Только код, без объяснений.
Пример 3 — идеи для проекта
Я 12 лет, делаю игру «поймай яблоко» на Python. Ты — геймдизайнер. Придумай 5 способов усложнить игру. Список, одна строка на пункт. Идеи должны быть реализуемы для новичка в Python.

Итерация: улучшаем ответ ИИ

Плохой первый ответ — не повод сдаваться. Продолжи диалог!

❌ Плохой ответ ИИ

Промпт: «Объясни цикл for»
Ответ: длинная лекция на 3 абзаца без примера кода

Как продолжить диалог?

  • «Дай только код, без слов»
  • «Объясни за 3 предложения максимум»
  • «Добавь пример для 12-летнего»
  • «Переделай — используй игровую метафору»

✅ Стратегия итерации

  1. Получи первый ответ — оцени
  2. Если плохой — уточни: «Сделай [конкретнее / короче / с примером]»
  3. Повтори 1-2 раза максимум
  4. Если после 3 попыток всё плохо — перефразируй весь промпт

def is_prime(n): # Числа меньше 2 не простые if n < 2: return False # Проверяем делители от 2 до sqrt(n) for i in range(2, int(n**0.5) + 1): if n % i == 0: return False return True # Проверка print(is_prime(7)) # True print(is_prime(12)) # False print(is_prime(2)) # True print(is_prime(1)) # False

ИИ для идей и брейнштормов

Один из лучших сценариев использования ИИ — генерация вариантов

Промпт: идеи для проекта
Я 12 лет, написал игру Тамагочи на Python. Ты — опытный Python-разработчик для детей. Придумай 5 функций, которые можно добавить. Каждая должна требовать только базовый Python. Формат: список 1–5, одна строка на пункт.

Пример ответа ИИ:

  1. Сохранять состояние в файл (pickle)
  2. Добавить болезнь — питомец может заболеть
  3. Мини-игра «угадай число» для поднятия радости
  4. Дни рождения питомца — особое приветствие
  5. Система достижений: «Покормил 10 раз»

Как выбрать из идей?

  1. Интересно ли это лично тебе? ИИ предлагает варианты — ты выбираешь.
  2. Ты понимаешь как реализовать? Если нет — спроси ИИ объяснение.
  3. Сколько времени займёт? Выбирай посильное.

Важно: ИИ предлагает идеи, но код ты пишешь сам. Это развивает тебя, а не ИИ.

Анти-паттерны: когда ИИ врёт в коде

Три ситуации, когда нельзя доверять ИИ без проверки

👻

Несуществующий метод

# ИИ предложил:
lst.find(5)
# Но такого нет в Python!

Проверяй: dir(list) покажет все реальные методы

⏰

Устаревший синтаксис

# Python 2 (устарело):
print "Hello"
# Python 3 (правильно):
print("Hello")

ИИ может смешивать Python 2 и 3. Всегда уточняй версию в промпте

📦

Неверный импорт

# ИИ написал:
from random import shuffle_list
# Нет такой функции!
# Правильно:
from random import shuffle

Запускай код сразу — ошибка ImportError покажет проблему

Главное правило: любой код от ИИ — запускай в IDE немедленно. Если ошибка — это НЕ значит, что ты виноват. Это означает, что ИИ ошибся. Сообщи ему об ошибке!

Находим галлюцинации ИИ

Запусти код — если ошибка, ИИ выдумал метод. Найди и исправь!

Код от ИИ (с ошибкой)

ИИ предложил такой код для работы со списком. Найди галлюцинацию!

Метод поиска:

  1. Запусти код → смотри на ошибку
  2. Проверь: print(dir(list)) — есть такой метод?
  3. Замени несуществующий метод на правильный
  4. Запусти снова — работает?
Python
# Код предложил ИИ — запусти и найди галлюцинацию! heroes = ["Арчер", "Маг", "Воин", "Вор"] # ИИ написал этот метод — существует ли он? index = heroes.find("Маг") # галлюцинация! print(f"Маг на позиции: {index}") # Подсказка: какой метод у list для поиска? # Исправь строку выше — запусти снова! # print(dir(list)) # раскомменти, чтобы увидеть методы

Диалог с ИИ: сообщи об ошибке

Если ИИ ошибся — скажи ему об этом. Он исправится!

😊
Ты пишешь ИИ:
Ты предложил heroes.find("Маг"), но в Python у списков нет метода .find(). Это вызвало ошибку AttributeError. Как правильно найти индекс элемента в списке?
🤖
ИИ отвечает (правильно):

«Извините за ошибку! У списков Python есть метод .index(), а не .find(). Правильно: heroes.index("Маг"). Метод .find() существует только у строк (str).»

Диалог с ИИ — это не слабость. Профессионалы всегда уточняют и исправляют ИИ. Это и есть грамотная работа с ассистентом.

Правила профессионала
