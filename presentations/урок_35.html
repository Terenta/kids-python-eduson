❌ До ИИ-ревью

Python
def check(x): if x > 0: return True else: return False def calc(a, b, c): res = a + b res2 = res * c return res2 print(check(5)) print(calc(2, 3, 4))

✅ После ИИ-ревью

Python
def is_positive(number: int) -> bool: """Возвращает True если число положительное.""" return number > 0 def calculate_total(base: int, addition: int, multiplier: int) -> int: """Считает (base + addition) * multiplier.""" return (base + addition) * multiplier print(is_positive(5)) print(calculate_total(2, 3, 4))
ИИ-ревью улучшает: имена переменных, type hints, docstrings, убирает лишние else.

ИИ-автодополнение — это T9 для кода

Только намного умнее. T9 предсказывал следующее слово. ИИ-IDE предсказывает следующие 20 строк кода — с правильной логикой и синтаксисом.

📱

T9 (телефон)

Предсказывает следующее слово. Часто ошибается.

💻

ИИ-IDE (GigaIDE)

Предсказывает следующий блок кода. Понимает контекст файла.

🚀

GitHub Copilot

Может дописать целую функцию по комментарию. Профессиональный уровень.

Как работает ИИ-автодополнение

Что происходит за 0.3 секунды от твоего набора до подсказки

Когда принимать (Tab)

  • Прочитал — понял — согласен
  • Код делает именно то, что тебе нужно
  • Синтаксис выглядит правильным

Когда отклонять (Esc)

  • Не понял, что предлагает ИИ
  • Логика не та, что нужна
  • Используется незнакомый метод

# Задание: напиши 3 варианта комментария для функции подсчёта очков # Вариант 1 (плохой): # функция # Вариант 2 (средний): # считает очки игрока # Вариант 3 (хороший — заполни сам!): # Принимает список попаданий (list of bool), возвращает итоговый счёт. # Каждое True = +10 очков. Правило: Чем точнее комментарий описывает ВХОД и ВЫХОД функции — тем лучше предложение ИИ. Используй типы: list of bool, returns int.

Попробуй сам: 3 функции с комментарием-промптом

Напиши сначала подробный комментарий, потом начни def — смотри на подсказку GigaIDE

Python
# Функция 1: Конвертер температур # Принимает celsius (float), возвращает fahrenheit (float) # Формула: F = C * 9/5 + 32 def celsius_to_fahrenheit(celsius: float) -> float: return celsius * 9 / 5 + 32 # Функция 2: Калькулятор ИМТ # Принимает weight (кг, float) и height (м, float) # Возвращает ИМТ = weight / height**2, округлённый до 1 знака def calc_bmi(weight: float, height: float) -> float: return round(weight / height ** 2, 1) # Функция 3: Счётчик гласных # Принимает text (str), возвращает количество гласных (int) # Гласные: а е ё и о у ы э ю я (русские и английские) def count_vowels(text: str) -> int: vowels = "аеёиоуыэюяaeiouy" return sum(1 for c in text.lower() if c in vowels) print(celsius_to_fahrenheit(100)) # 212.0 print(calc_bmi(70, 1.75)) # 22.9 print(count_vowels("Привет мир")) # 4

Мини-квиз: что ты сделаешь?

ИИ предложил код — выбери правильное действие

  1. Ситуация: ИИ дополнил функцию целиком (15 строк). Ты понимаешь только половину. Что делаешь?
    ✅ Нажимаю Esc, пишу сам или прошу объяснить каждую строку
  2. Ситуация: ИИ предложил ровно то что ты хотел написать — простой print() со своими данными. Что делаешь?
    ✅ Нажимаю Tab — понимаю, всё верно
  3. Ситуация: ИИ предложил код с незнакомой функцией os.remove(). Твоя задача — просто вывести текст. Что делаешь?
    ✅ Нажимаю Esc — это опасная функция, не имеет отношения к задаче
  4. Ситуация: ИИ дополнил цикл for — логика правильная, переменные понятные. Что делаешь?
    ✅ Нажимаю Tab — понимаю код, он верный
  5. Ситуация: ИИ предложил код сразу после того как ты начал печатать имя переменной. Ты ещё не закончил мысль. Что делаешь?
    ⚠️ Читаю предложение — если совпадает с задумкой, Tab. Иначе — Esc

Когда доверять ИИ?

ИИ ускоряет — ты контролируешь. Это правильный баланс.

✅

Принимай если

  • Прочитал весь предложенный код
  • Понимаешь каждую строку
  • Логика соответствует задаче
  • Запустил и результат верный
⚠️

Осторожно если

  • Длинный блок кода (10+ строк)
  • Используются незнакомые функции
  • Сложная логика с условиями
  • Код изменяет файлы или данные
🚫

Никогда не принимай

  • Не читая вообще
  • Если не понимаешь ни строки
  • Если задача другая, а код похожий
  • Просто «потому что быстрее»

Главный принцип: ИИ не заменяет понимание — оно ускоряет набор. Если ты не понимаешь принятый код, ты учишь ИИ, а не себя. Это провал обучения.

Типичные ошибки с ИИ-автодополнением

5 ошибок новичков — и как их избежать

❌ Ошибка 1

Tab без чтения — принял 20 строк незнакомого кода. Код «работает» но делает не то. Потратил час на поиск бага.

✅ Всегда читай весь принятый блок до запуска

❌ Ошибка 2

Плохой комментарий-промпт — написал «# функция» и удивился, что ИИ предложил что-то рандомное.

✅ Пиши конкретно: параметры, тип результата, пример

❌ Ошибка 3

Принял похожий код — задача была посчитать среднее, ИИ предложил код для суммы. Выглядело похоже — принял.

✅ Проверяй результат на конкретных числах

❌ Ошибка 4

Зависимость от ИИ — перестал думать самостоятельно, сразу ждёт подсказки. Перестал учиться.

✅ Сначала думай 2 минуты сам, потом смотри на ИИ

Cursor: Ctrl+K и Ctrl+L

Две команды, которые меняют подход к программированию

Ctrl+K — рефакторинг

Python
# В Cursor: выдели эту функцию, нажми Ctrl+K # Напиши: "добавь проверку типа и docstring" # ИИ предложит улучшенную версию прямо здесь def calc(x, y, op): if op == "+": return x + y if op == "-": return x - y if op == "*": return x * y if op == "/": return x / y print(calc(10, 3, "+")) print(calc(10, 3, "/")) print(calc(10, 0, "/")) # Что будет?

Ctrl+L — чат о коде

  • «Объясни что делает эта функция»
  • «Почему здесь ошибка ZeroDivisionError?»
  • «Добавь обработку деления на ноль»
  • «Перепиши более Pythonic»

GigaIDE vs Cursor: GigaIDE предугадывает следующий код. Cursor обсуждает и рефакторит. Оба полезны в разных ситуациях — выбирай правильный инструмент для задачи.
