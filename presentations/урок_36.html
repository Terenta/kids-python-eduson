SEO-основы: заставь Google найти тебя

Промпт для SEO в Lovable

«Добавь SEO мета-теги в head:
title: "Петя Иванов — Python разработчик"
description: "Сайт-портфолио Пети Иванова,

OG-теги (Open Graph) — это превью в Telegram и VK когда делишься ссылкой. Красивая картинка = больше кликов!

Что делает каждый тег

  • title — заголовок вкладки браузера и строка в Google
  • description — описание под ссылкой в поиске
  • og:image — картинка при шаринге в соцсетях
  • og:title — заголовок при шаринге

Проверка мета-тегов

Сайт: metatags.io — вставь ссылку и увидишь как сайт выглядит в Google, Telegram, VK, Twitter.

Версионирование: откат за секунду

Lovable помнит все версии — можно вернуться к любой

  1. Каждый промпт создаёт новую версию
  2. Нажми History (иконка часов) в боковой панели
  3. Выбери любую прошлую версию — увидишь предпросмотр
  4. Нажми Restore — возврат к этой версии
Это как Ctrl+Z, но для всего сайта. Экспериментируй смело — ничего не потеряешь!

Когда это спасает

  • Промпт испортил красивый дизайн
  • Хочешь сравнить старый и новый вариант
  • Случайно удалил нужную секцию
  • Хочешь показать «было/стало»

❌ Шаблонные тексты

Промпт: «В секции Обо мне замени текст на: [твои конкретные предложения]»

❌ Плохой адаптив

Промпт: «Исправь мобильную версию. На телефоне карточки должны быть в один столбец.»

❌ Аватар не загружается

Загрузи на Яндекс.Диск → скопируй прямую ссылку → промпт: «Вставь изображение по ссылке [url] вместо аватара»

Универсальное правило: если что-то не нравится — напиши промпт с конкретным описанием проблемы. Lovable понимает «почему это неправильно» и исправляет.

Что такое PyGame

Библиотека Python для создания 2D-игр. Настоящих — с графикой, звуком, физикой и управлением. Не консольных, а оконных.

  • Sprites — персонажи и объекты
  • Collision detection — столкновения
  • Sound — музыка и эффекты
  • FPS — контроль скорости игры

import random words = ['python', 'site', 'prompt', 'avatar', 'design'] word = random.choice(words) guessed = [] tries = 6 print('Guess the word! Letters:', len(word)) while tries > 0: display = ' '.join(c if c in guessed else '_' for c in word) print(display) if '_' not in display: print('You win! Word was:', word) break letter = input('Enter a letter: ').lower() if letter in word: guessed.append(letter) print('Correct!') else: tries -= 1 print('Wrong! Tries left:', tries) else: print('Game over! Word was:', word)

Python — статистика сайта
# Симулируем статистику сайта за неделю import random days = ['Пн', 'Вт', 'Ср', 'Чт', 'Пт', 'Сб', 'Вс'] visitors = [random.randint(5, 50) for _ in days] print("📊 Статистика сайта за неделю:") print("-" * 30) for day, count in zip(days, visitors): bar = '█' * (count // 5) print(f"{day}: {bar} {count}") print("-" * 30) print(f"Всего посетителей: {sum(visitors)}") print(f"Лучший день: {days[visitors.index(max(visitors))]}")
