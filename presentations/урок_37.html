PyGame Zero vs PyGame

Почему мы выбрали PyGame Zero для обучения

PyGame (сложный)

15 строк просто для пустого окна.

import pygame
pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    screen.fill((0, 0, 0))
    pygame.display.flip()
    clock.tick(60)

Игровой цикл: draw() и update()

Два лучших друга — каждый делает своё дело, 60 раз в секунду

draw(): «Нарисуй небо синим. Нарисуй корзинку на позиции (400, 520). Нарисуй счёт в углу.» — только рисование!

update(): «Сдвинь яблоко вниз на 2 пикселя. Проверь столкновение. Обнови счёт.» — только логика!

Типичные ошибки новичков

Найди ошибку — объясни, почему это неправильно

❌ Логика в draw():

def draw():
    screen.fill('skyblue')
    basket.x += 2  # ОШИБКА! Движение в draw()!
    basket.draw()

def update():
    pass  # update() пустой

draw() вызывается для рисования, НЕ для обновления состояния. При высоком FPS корзинка полетит слишком быстро!

❌ Рисование в update():

def draw():
    pass  # draw() пустой!

def update():
    screen.fill('skyblue')  # ОШИБКА!
    basket.draw()           # ОШИБКА!

screen и actor.draw() работают только в draw(). В update() вызов screen.fill() вызовет ошибку AttributeError.

Правило навсегда: draw() — только рисование. update() — только изменение переменных. Никогда не смешивай!

Симулируем падение яблока — считаем позиции в Python

Python
# Симулируем движение яблока WIDTH = 800 HEIGHT = 600 apple_x = 400 # центр по горизонтали apple_y = 50 # начинаем сверху apple_speed = 3 # скорость падения # Симуляция первых 10 шагов print("Шаг | apple_y | Статус") print("-" * 30) for step in range(10): apple_y += apple_speed status = "падает" if apple_y > HEIGHT: status = "вышло за экран!" print(f" {step+1} | {apple_y:3d} | {status}")

Что происходит в PyGame

  • update() вызывается 60 раз/сек
  • каждый раз apple_y += speed
  • draw() рисует яблоко на новой позиции
  • когда y > 600 — яблоко «потеряно»

Важно про images/

Порядок рисования

  • Всегда рисуй фон первым — он стирает предыдущий кадр

Скорость и направление

Меняй speed — меняй поведение объекта

WIDTH = 800
HEIGHT = 600

basket = Actor('basket')
basket.pos = (400, 520)

# Скорости по осям
speed_x = 3   # движение вправо (+ = вправо)
speed_y = 0   # нет вертикального движения

def draw():
    screen.fill('skyblue')
    basket.draw()

def update():
    basket.x += speed_x  # горизонтальное движение
    basket.y += speed_y  # вертикальное движение

# Примеры значений speed_x и speed_y:
# (3, 0)  — вправо
# (-3, 0) — влево
# (0, 2)  — вниз (падение)
# (2, -1) — по диагонали вверх-вправо

Таблица направлений

→ движение ВПРАВО

← движение ВЛЕВО

↓ движение ВНИЗ

↑ движение ВВЕРХ

Ограничение краями экрана

Как не дать корзинке «улететь» за пределы окна

❌ Без ограничений — улетает:

def update():
    basket.x += 3  # уедет за экран!

✓ С ограничением — остаётся:

def update():
    basket.x += 3
    # Ограничиваем краями
    half_w = basket.width // 2
    if basket.x < half_w:
        basket.x = half_w
    if basket.x > WIDTH - half_w:
        basket.x = WIDTH - half_w

Функция clamp (удобно)

def clamp(value, min_val, max_val):
    return max(min_val, min(value, max_val))

def update():
    basket.x += 3
    basket.x = clamp(
        basket.x,
        40,       # минимум (левый край)
        WIDTH-40  # максимум (правый край)
    )
Python
def clamp(v, lo, hi): return max(lo, min(v, hi)) WIDTH = 800 x = 400 for step in range(8): x += 60 # быстро едем вправо x = clamp(x, 40, WIDTH-40) print(f"x = {x}")
