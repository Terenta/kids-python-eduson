sounds против music

Два разных объекта для двух разных задач

💥

sounds — короткие эффекты

  • Хруст, щелчок, взрыв, монетка
  • Длина: 0.1–3 секунды
  • Форматы: .wav, .ogg
  • Папка: sounds/ рядом с game.py
  • Вызов: sounds.имя.play()
  • Можно играть несколько одновременно
🎵

music — фоновый трек

  • Тема, эмбиент, атмосфера
  • Длина: 1–5 минут, зацикливается
  • Форматы: .ogg, .mp3
  • Папка: music/ рядом с game.py
  • Вызов: music.play('имя')
  • Только один трек в любой момент
Никогда не клади минутный трек в папку sounds/ — PyGame Zero загружает все звуки в память при старте. Это съест ОЗУ и замедлит запуск.

Откуда взять звуки?

Как PyGame Zero находит звуки

Магия имён — никакого open(), только соглашения

Правило именования

sounds/catch.wav
→ sounds.catch.play()
sounds/game_over.wav
→ sounds.game_over.play()
music/bg.ogg
→ music.play('bg')
music/menu.ogg
→ music.play('menu')

Что происходит внутри

  1. При старте pgzrun сканирует папку sounds/
  2. Загружает все файлы в память как объекты
  3. Создаёт атрибуты объекта sounds с именами файлов
  4. При вызове .play() — мгновенное воспроизведение из памяти
Это паттерн «Convention over Configuration» — PyGame Zero знает что делать, если ты следуешь соглашению. Django, Ruby on Rails работают так же.

API звуков: sounds

Все методы, которые понадобятся

sounds.catch.play()
Воспроизвести звук один раз. Имя файла без расширения.
sounds.catch.stop()
Остановить воспроизведение этого звука.
sounds.catch.volume
Громкость от 0.0 (тишина) до 1.0 (максимум). Устанавливается как атрибут.
sounds.catch.play(-1)
Играть бесконечно (зациклить). Аргумент -1 = бесконечное повторение.
# При ловле яблока
sounds.catch.play()

# Настройка громкости (делаем тише)
sounds.catch.volume = 0.8
sounds.lose.volume = 1.0  # потеря жизни — полная громкость

# При клике на кнопку в меню
sounds.click.play()

API музыки: music

Фоновая музыка — это атмосфера и погружение

music.play('bg')
Играть файл music/bg.ogg с зацикливанием. Имя без расширения.
music.play_once('jingle')
Сыграть один раз, без зацикливания. Хорошо для джинглов победы.
music.set_volume(0.3)
Установить громкость музыки. 0.3 — 30%, оптимально для фона.
music.pause()
Поставить на паузу (запоминает позицию).
music.unpause()
Продолжить с того же места.
music.stop()
Полностью остановить. При следующем play() начнёт сначала.

Музыка и состояния игры

В каждом состоянии — своя логика музыки

Таблица состояний

menu
music.play('menu') — лёгкая мелодия
playing
music.play('bg') или unpause()
paused
music.pause() — запоминает позицию!
game_over
music.stop() + play_once('lose')

Правило переходов

def on_key_down(key):
    if key == keys.SPACE:
        if state == 'menu':
            state = 'playing'
            music.play('bg')
        elif state == 'playing':
            state = 'paused'
            music.pause()    # ← не stop!
        elif state == 'paused':
            state = 'playing'
            music.unpause()  # ← не play()!

Баланс громкостей

Звуковой дизайн — это наука и искусство одновременно

Фон (music)

Самый тихий уровень — музыка не должна отвлекать

0.25–0.35

Обычные эффекты

Ловля яблок, шаги, кнопки

0.70–0.80

Важные события

Потеря жизни, game over, победа

0.90–1.00

Проверка: включи игру и попроси кого-то другого сыграть. Если они не слышат, что поймали яблоко — музыка слишком громкая. Если музыка раздражает через 30 секунд — тоже слишком громко.

            apples.remove(apple)
            score += 1
            sounds.catch.play()  # ЗВУК ЛОВЛИ

            lives -= 1
            sounds.lose.play()   # ЗВУК ПОТЕРИ

                game_state = 'gameover'
                music.stop()     # СТОП МУЗЫКИ

# === В on_key_down(): при старте из меню ===
def on_key_down(key):
    global game_state
    if key == keys.SPACE:
        if game_state == 'menu':
            game_state = 'playing'
            sounds.click.play()  # ЗВУК КЛИКА
            music.play('bg')     # ПЕРЕЗАПУСК МУЗЫКИ
        elif game_state == 'paused':
            game_state = 'playing'
            music.unpause()      # ПРОДОЛЖИТЬ МУЗЫКУ
        elif key == keys.P:
            if game_state == 'playing':
                game_state = 'paused'
                music.pause()    # ПАУЗА МУЗЫКИ

Алгоритм: добавить звук за 7 шагов

Чёткий план — без паники и пропущенных шагов

  1. Найди звуки на freesound.org (фильтр CC0): catch.wav, lose.wav, click.wav
  2. Создай папку sounds/ рядом с game.py. Переложи файлы туда.
  3. Запусти игру без изменений кода — убедись, что запускается без ошибок.
  4. Добавь один звук: sounds.catch.play() при ловле яблока. Проверь.
  5. Добавь остальные эффекты по одному, каждый раз проверяя.
  6. Добавь музыку: music.play('bg') в начале, pause/unpause в состоянии паузы.
  7. Настрой баланс громкостей: музыка 0.3, обычные эффекты 0.7–0.8, важные события 0.9–1.0.

Частые ошибки со звуком

Три ситуации, с которыми столкнётся каждый

❌ Звук не играет

Проверь имя файла: sounds.catch.play() ищет файл sounds/catch.wav. Без расширения в коде. Без заглавных букв.

✅ catch.wav
❌ Catch.wav
❌ catch.wav.wav

❌ Задержка

Файл слишком большой. Оптимально: catch.wav ≤ 100 КБ. Сожми через онлайн-конвертер или Audacity.

Правило: короткий звук = маленький файл.

❌ Музыка дважды

Вызов music.play('bg') дважды подряд — трек перезапускается. Добавь проверку:

if not music.is_playing():
    music.play('bg')

Диагностика по симптому

Музыка перезапускается

❌ vs ✅

elif state == 'paused':
    state = 'playing'

# ✅ Правильно
elif state == 'paused':
    state = 'playing'

# ❌ Расширение в имени

# ✅ Правильно

class SoundManager: def __init__(self): self.volumes = { 'catch': 0.8, 'lose': 1.0, 'click': 0.7, } self.music_volume = 0.3 self.music_playing = False self.music_paused = False def play(self, name): vol = self.volumes.get(name, 1.0) print(f" Звук: [{name}] громкость={vol:.1f} -> ИГРАЕТ") def music_play(self, track): self.music_playing = True self.music_paused = False print(f" Музыка: [{track}] громкость={self.music_volume:.1f} -> ИГРАЕТ (зациклено)") def music_pause(self): self.music_paused = True print(f" Музыка: пауза (запомнена позиция)") def music_unpause(self): self.music_paused = False print(f" Музыка: продолжение с той же позиции") def music_stop(self): self.music_playing = False print(f" Музыка: остановлена") sounds = SoundManager() sounds.music_play('bg') print() print("=== Игрок поймал яблоко ===") sounds.play('catch') print() print("=== Игрок потерял жизнь ===") sounds.play('lose') print() print("=== Игрок нажал Паузу ===") sounds.music_pause() print() print("=== Игрок продолжил ===") sounds.music_unpause() print() print("=== Игра окончена ===") sounds.music_stop() sounds.play('lose')

Где взять звуки: freesound.org

Пошаговая инструкция для поиска бесплатных звуков

  1. Открой freesound.org в браузере. Создай бесплатный аккаунт (нужен для скачивания).
  2. Введи запрос по-английски: «apple crunch», «coin collect», «game over», «button click».
  3. Фильтр Creative Commons: нажми «CC0» в левом меню. Это лицензия «без ограничений» — можно везде.
  4. Фильтр по длине: до 3 секунд для эффектов, до 3 минут для музыки.
  5. Прослушай прямо на сайте, выбери лучший.
  6. Скачай в формате .wav, переименуй в нужное имя.
  7. Положи в папку sounds/ рядом с game.py.

Музыка с OpenGameArt.org

Лучший источник бесплатной игровой музыки

  1. Открой opengameart.org в браузере
  2. Фильтр по типу: Music
  3. Фильтр по лицензии: CC0 или CC-BY
  4. Поиск: «platformer», «chiptune», «ambient», «loop», «arcade»
  5. Скачай в формате .ogg (лучше для PyGame Zero)
  6. Переименуй в bg.ogg, положи в папку music/

Рекомендуемые теги

  • «8-bit» — ретро-пиксельный звук
  • «chiptune» — синтезатор старых игр
  • «upbeat» — весёлая быстрая музыка
  • «loop» — трек уже зациклен
  • «casual game» — лёгкая атмосфера
CC-BY = укажи автора. CC0 = полная свобода. Для учебных проектов оба подходят!
