Что такое UX?

User Experience — то, как игрок чувствует твою игру, а не только видит

💡

Правило 1: Ясность

Игрок должен понять, что делать, за первые 5 секунд. Без инструкций — только по экрану.

«Если непонятно — закроет.»

⚡

Правило 2: Отклик

После каждого действия — видимая реакция за 100 мс. Кнопка мигнула? Звук? Очко?

«Тишина в ответ = ошибка.»

🚪

Правило 3: Выход

Всегда должен быть способ выйти, поставить паузу, перезапустить.

«Пауза = уважение к игроку.»

Game Feel (Juice) — это маленькие детали: тряска экрана при ударе, вспышка при попадании, частицы при взрыве. Они создают «сок» игры.

Game Feel: что такое juice?

Juice = слой ощущений поверх механики. Не меняет правила — меняет восприятие

Без juice

  • Шарик падает, очко прибавляется
  • Враг исчезает без эффекта
  • Кнопки — серые прямоугольники
  • Музыка не прерывается на события

С juice

  • Шарик падает + звук + вспышка + +10 летит вверх
  • Враг взрывается + частицы + тряска
  • Кнопки светятся при наведении
  • Музыка замедляется при конце игры

Правило «обратной связи»

Каждое действие игрока должно вернуть хотя бы один сигнал: звук, анимацию, изменение цвета или текст.

Примеры: Flappy Bird (звук хлопка), Minecraft (звук блока), Candy Crush (анимация взрыва).

Подсказка для новичков

Появляется в первые 3 секунды, потом исчезает — не мешает опытным

show_hint = False  # флаг видимости подсказки

def start_game():
    global game_state, show_hint
    game_state = 'playing'
    show_hint = True
    clock.schedule(hide_hint, 3.0)  # через 3 сек исчезает

def hide_hint():
    global show_hint
    show_hint = False

def draw():
    if game_state == 'playing':
        # ... рисуем игру ...

        if show_hint:
            screen.draw.text(
                "Двигай мышкой и лови яблоки!",
                center=(WIDTH // 2, HEIGHT - 60),
                color=(255, 255, 255, 180),
                fontsize=28,
                shadow=(1, 1)
            )
Важно: clock.schedule(hide_hint, 3.0) вызывай только при переходе в 'playing', не в draw()! Иначе таймер будет сбрасываться каждый кадр.

Game Feel: тряска экрана

Screen shake — сигнал «что-то важное произошло»

import random

shake_timer = 0       # сколько кадров ещё трясти
shake_intensity = 6   # сила тряски (пиксели)
shake_offset = (0, 0) # текущее смещение

def trigger_shake():
    """Вызывать при потере жизни или ударе"""
    global shake_timer
    shake_timer = 12  # трясти 12 кадров = 0.2 сек

def update():
    global shake_timer, shake_offset
    if shake_timer > 0:
        shake_timer -= 1
        intensity = shake_intensity * shake_timer / 12
        shake_offset = (
            random.randint(-int(intensity), int(intensity)),
            random.randint(-int(intensity), int(intensity))
        )
    else:
        shake_offset = (0, 0)

def draw():
    screen.fill('black')
    ox, oy = shake_offset
    basket.draw()  # Actors рисуются со своей pos
Вызови trigger_shake() когда игрок теряет жизнь. Это создаёт физическое ощущение удара.

Game Feel: вспышка при ударе

Hit flash — мгновенный визуальный сигнал о попадании

flash_timer = 0

def trigger_flash():
    """Вспышка при потере жизни"""
    global flash_timer
    flash_timer = 6  # 6 кадров = 0.1 сек

def update():
    global flash_timer
    if flash_timer > 0:
        flash_timer -= 1
        basket.image = 'basket_hit'
    else:
        basket.image = 'basket'

def draw():
    screen.fill('black')
    basket.draw()

    # Или: полупрозрачный оверлей
    if flash_timer > 0:
        screen.draw.filled_rect(
            Rect(0, 0, WIDTH, HEIGHT),
            (255, 255, 255)
        )

Почему это работает?

Мозг игрока ожидает визуальный отклик. Без него кажется, что «ничего не произошло» — даже если счёт изменился.

Другие juice-эффекты

  • Увеличение при сборе (scale up)
  • Частицы-точки при взрыве
  • Замедление на 0.05 сек при ударе
  • Цифры «+1» летят вверх от предмета

Типичные ошибки UX

Что мешает игроку наслаждаться игрой

❌ Ошибка 1

Нет экрана «Игра окончена»

Игра просто зависает или перезапускается без объяснений. Игрок не знает, он проиграл или это баг.

❌ Ошибка 2

Нельзя перезапустить без закрытия

Игрок закрывает окно, снова открывает. Каждый раз. Это катастрофа удержания.

❌ Ошибка 3

Текст «Нажми пробел для старта»

Белый текст на белом фоне. Мелкий шрифт. Никто не читает — просто нажимают что попало.

❌ Ошибка 4

Очки обновляются без звука

Число меняется, но игрок не замечает. Без звука «динь» сбор монеты — скучный.

❌ Ошибка 5

Одна и та же музыка вечно

Бесконечный loop 30-секундного трека. Через 5 минут игрок выключает звук навсегда.

✓ Решение

Каждая ошибка — чек-лист пункт

Прогони свою игру по UX-аудиту и исправь нули. Даже один исправленный пункт делает игру лучше.

Звёздная задача: fade-in

Экран проявляется из чёрного за 0.5 секунды при старте

Python
# Fade-in логика (симуляция без PyGame Zero) # В реальной игре: pygame.Surface + set_alpha + screen.blit fade_alpha = 255 # начинаем с полностью чёрного fade_speed = 8.5 # снижаем на ~8.5 за кадр (255/30 = 8.5) fading_in = True def update_fade(): global fade_alpha, fading_in if fading_in: fade_alpha -= fade_speed if fade_alpha <= 0: fade_alpha = 0 fading_in = False def draw_fade(): if fade_alpha > 0: opacity = fade_alpha / 255 print(f" Чёрный оверлей: прозрачность={opacity:.0%} (alpha={fade_alpha:.0f})") else: print(" Fade завершён — игра полностью видна") print("Старт fade-in:") for frame in range(35): update_fade() if frame % 5 == 0: print(f"Кадр {frame:2d}: ", end="") draw_fade()
