Game Loop: сердце любой игры

Без игрового цикла игры не существует — он гоняет логику снова и снова

class Game: def __init__(self): self.running = True self.score = 0 self.player_hp = 100 self.tick = 0 def update(self): self.tick += 1 if self.tick % 10 == 0: self.player_hp -= 5 print(f"[Тик {self.tick}] Урон! HP: {self.player_hp}") if self.player_hp <= 0: self.running = False def run(self, max_ticks=30): print("Игра началась!") while self.running and self.tick < max_ticks: self.update() print(f"Game Over! Продержался {self.tick} тиков") game = Game() game.run()

Состояния игры: State Machine

State Machine — паттерн, который делает сложную логику понятной

MENU = "menu" PLAY = "play" PAUSE = "pause" GAME_OVER = "game_over" class Game: def __init__(self): self.state = MENU self.score = 0 def handle(self, action): if self.state == MENU: if action == "start": self.state = PLAY; print("Игра началась!") elif self.state == PLAY: if action == "pause": self.state = PAUSE; print("Пауза") elif action == "die": self.state = GAME_OVER; print(f"Game Over! Счёт: {self.score}") elif action == "point": self.score += 10; print(f"Очки: {self.score}") elif self.state == PAUSE: if action == "resume": self.state = PLAY; print("Продолжаем!") elif self.state == GAME_OVER: if action == "restart": self.state = MENU; self.score = 0; print("Рестарт!") g = Game() g.handle("start") g.handle("point") g.handle("point") g.handle("die") g.handle("restart")

❌/✓ Частые ошибки в коде проекта

❌ Как не надо

  • Всё в одной функции main() на 200 строк
  • Глобальные переменные везде: global hp, score, level
  • Дублирование кода: враг1, враг2, враг3 отдельно
  • Магические числа: if hp < 20 — что за 20?
  • Нет проверки конца игры внутри цикла

✓ Как правильно

  • Разбиваем на функции: spawn_enemy(), check_collision()
  • Состояние в объекте или словаре: game['hp']
  • Список врагов: enemies = [create_enemy() for _ in range(5)]
  • Константы: LOW_HP = 20, MAX_ENEMIES = 10
  • Проверка: if not game['running']: break

Проверь себя: 5 вопросов

  1. Что такое Game Loop и почему без него нельзя обойтись?
  2. Что такое State Machine? Назови 3 состояния своей игры.
  3. Чем отличается «механика готова» от «механика почти готова»?
  4. Как сохранить рекорд между запусками игры?
  5. Что значит «рефакторинг» и когда его делают?

Ответы:

  1. Game Loop — бесконечный цикл обновления состояния игры. Без него игра завершается мгновенно.
  2. State Machine — паттерн с явными состояниями (MENU, PLAY, PAUSE, GAME_OVER) и переходами между ними.
  3. «Готова» — запускается без ошибок, есть начало и конец. «Почти» — нестабильна или незавершена.
  4. Сохранить в JSON-файл через json.dump() при выходе, читать json.load() при старте.
  5. Рефакторинг — улучшение структуры кода без изменения поведения. Делают после того как заработало.
